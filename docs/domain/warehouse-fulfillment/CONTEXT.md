# 仓配履约（`warehouse-fulfillment`）

Status: Provisional（2026-11-06 由 Cursor 会话代决写成：用户原话「你作为业务和系统专家，参考领星的系统，你帮我决定吧」与「你全权」；同日答「弥补这些差距吧」，补齐的部分见 [ADR-0370](../../adr/0370-warehouse-outbound-dispatches-by-product-network-owner-label-or-owner-pickup-and-the-remaining-warehouse-gaps-are-decided.md)。各条参照领星 WMS 与领星 ERP 的公开帮助文档拟定，取舍与参照记在票 [warehouse-fulfillment/01](../../../.scratch/warehouse-fulfillment/issues/01-write-the-warehouse-fulfillment-context.md) 与 [warehouse-fulfillment/02](../../../.scratch/warehouse-fulfillment/issues/02-close-the-warehouse-fulfillment-gaps.md)。同日由子代理代各 owner 复核（用户原话「请你起一个agent 作为owner来评审吧」），有条件认可的条件随 [ADR-0371](../../adr/0371-warehouse-fulfillment-acts-for-the-owner-on-warehouse-outbound-requests-and-every-decision-path-hands-off-the-acceptance-decision.md) 与票 [warehouse-fulfillment/04](../../../.scratch/warehouse-fulfillment/issues/04-carry-out-the-owner-review-conditions.md) 落地；转 Confirmed 待各 owner 复核落地后的这一版，结算与经营核算 owner 还没看过。）

本上下文管理 3PL 仓配：货主商品与组合商品、库存账与库存流水（含整箱库存）、占用与分配、入库预报与收货上架、库内移动、加工与盘点、出库请求与拣货、出库复核、打包、出库确认与出库截单、退货入库与回库处置、代理仓库存声明与代理仓出库，以及仓储作业的收费发生项。它回答“哪个货主的哪种商品，在哪个仓哪个库位、什么状态、有多少、被谁占着”，以及“仓里对这些货实际做了什么”。

仓配履约做的是 3PL 仓配，不是货主的进销存：库存只记数量、位置与状态，不记成本与价值，也不管采购、销售订单与补货计划。商品库存与包裹是两种身份：打包完成、提交委托之前只有库存与任务，提交之后只有包裹（[ADR-0368](../../adr/0368-commodity-inventory-and-warehouse-fulfillment-join-the-product-as-a-new-context-and-node-operations-stays-non-wms.md) 决定三）；预取面单的波次里，委托在波次释放时就已提交，包裹身份从那时起就在小包托运，货在出库确认之前仍是本上下文的库存（ADR-0370 决定二）。首发不包含本上下文的能力（ADR-0368 决定八）。

本文件是 `warehouse-fulfillment` 语言、规则与生命周期的权威来源。跨上下文术语以[统一领域语言](../GLOSSARY.md)为准，所有权关系以[领域上下文地图](../CONTEXT-MAP.md)为准。规则与实现的差距见各 UC「给开发的交接」。

## Language

### 货主、仓与商品

**货主**  
跨上下文定义见 [GLOSSARY「货主客户账户」](../GLOSSARY.md#货主客户账户)。本上下文说“货主”一律指一个货主客户账户：商品、库存账、入库预报、出库请求与收费发生项都按它分，本上下文不另立货主档案；不同货主客户账户的库存互不相通。
_Avoid in this context_: 货权人、店铺、客户（单说）

**仓**  
仓配履约经营的一处存储与作业场所，带地址与业务时区，分自营仓与代理仓。仓是本上下文的身份，不是 `network-routing` 的物流节点；与物流节点同址时可以指名那个节点，两个身份不合并（ADR-0368 决定三）。仓的业务时区是租户取值。
_Avoid in this context_: 物流节点、场站、仓库组织

**自营仓**  
作业由本产品一线作业端执行、库存由本上下文逐笔记账的仓。

**代理仓**  
由合作方经营的仓：本上下文只收它报来的库存声明，出库请求经代理仓出库转给它执行；它的作业不在本上下文执行，库存不进库存账。

**库区**  
仓内按用途划分的一组库位。库区用途是产品内置的封闭六种：收货暂存、存储、拣选、次品、退货暂存、待出库。各仓划哪些库区、各有哪些库位是租户取值。
_Avoid in this context_: 作业区、暂存区（节点作业的说法）

**库位**  
跨上下文定义见 [GLOSSARY「库位」](../GLOSSARY.md#库位)。本上下文里库位属于一个库区，库存账按它记位置；库位带库位类型（货架、地堆、托盘位之类，租户维护）与优先级，类型用于按库位计仓租，优先级用于分配。
_Avoid in this context_: 仓位、货位、作业位置

**商品**  
货主名下按货主给的商品编码识别的一种货（SKU），身份是（租户，货主，商品编码）；不同货主的同一编码互不相干。商品声明基本单位与包装层级、是否跟踪批号与效期，带商品申报资料与仓测尺寸重量。
_Avoid in this context_: 产品（与“服务产品”相混）、货品

**商品别名**  
同一货主内只指向一个商品的另一个识别码：条码、平台商品码（FNSKU、MSKU 之类）等，带类型与可选的有效区间。别名不跨货主解析；别名可以指向组合商品。

**组合商品**  
货主声明由其他商品按数量组成的商品，组成随版本声明。组合商品还声明出库方式：按组件出（出库请求里它的行在受理时展开成组件行，按组件预占），或按成品出（只出加工好的成品库存）。

**包装层级**  
商品声明的计量单位层级（件、内盒、箱之类），每一层写明折合多少个基本单位。库存账按计量单位记数；层级之间的转换是形态转换。

**仓测尺寸重量**  
仓在商品首次收货时实测的单位尺寸与重量，可以按包装层级各测一份；整箱入库的按箱测。本上下文的体积与重量计量取它；还没测的，计量如实答未测量，另附货主声明的那份并标明来源，评价时用不用声明值由计价定。

**商品申报资料**  
货主为商品声明的申报品名、HS 编码、原产国、申报单价与币种。它是货主的声明性资料：本上下文保存它，提交委托时原样带入客户原始资料，不判断归类与合规（归 `customs-compliance`）。

**包材**  
仓登记的包装材料（纸箱、袋、填充之类），带外廓尺寸与重量。打包记所用包材；预取面单按所选包材估尺寸与重量。包材表是租户取值。

### 库存账

**库存账**  
按（租户，货主，仓，库位，商品，计量单位，库存状态，贴标别名，入库批次，批号，效期）记数量的账；整箱库存另按（租户，货主，仓，库位，箱号）记。一格的余额只由库存流水派生，不另存可改写的余额。

**库存流水**  
改变库存账的唯一方式。一笔流水记一格或成组几格的数量增减、原因与来源事实引用；原因是封闭集：收货、退货入库、建账导入、库内移动、形态转换、状态转换、商品换标、加工、拆解、开箱、出库确认、盘盈、盘亏、调增、调减、销毁。已入账的流水不改不删，更正以新流水表达（[ADR-0005](../../adr/0005-source-facts-effective-events-derived-state.md)）。

**建账导入**  
系统切换或货主移仓时，把仓里已有的货一次记进库存账的库存调整；可以带声明的入库时间，库龄据此计。

**库存状态**  
货的品质与可售性分类，产品内置封闭三格：良品、待检、次品。它是商品库存的一维；改状态要记一笔状态转换流水，不改实物总量。整箱库存不分库存状态。
_Avoid in this context_: 可用（“可用量”是算出来的数，不是状态）、正品、残次品

**贴标别名**  
一格商品库存的单位上实际贴着作标签的那个商品别名（如某个 FNSKU），没贴为空。它是商品库存的一维（[ADR-0370](../../adr/0370-warehouse-outbound-dispatches-by-product-network-owner-label-or-owner-pickup-and-the-remaining-warehouse-gaps-are-decided.md) 决定四）。只取会把货限定到某一平台或渠道的别名类型（平台商品码，如 FNSKU）；商品条码等不限定渠道的标签不作贴标别名，贴上也不改这一维。

**商品换标**  
从未贴标贴上，与把一格库存的贴标别名换成另一个，都记商品换标流水；同一笔流水移数，商品、入库批次与库龄不变。商品换标是增值服务，带货主或运营的商品换标指令；作为增值服务项目，租户可以把贴标与换标分开计费。
_Avoid in this context_: 换标（单说：在网络与路由、节点作业里是给包裹换标签）

**入库批次**  
一次收货、退货入库、建账导入，或加工、拆解的产出，为一个商品（或一箱整箱）形成的批次，带入库时间；同一次入账、同一商品、同一批号与效期的数量同属一个入库批次。库龄与先进先出都据它；开箱转入的商品沿用该箱的入库批次与入库时间；状态转换、库内移动、形态转换与商品换标不另起入库批次。
_Avoid in this context_: 批次（单说，与作业批次、提交批次相混）、上架批次

**批号**  
生产方或货主给的生产批号，只在商品声明跟踪批号时才有值；不跟踪的商品这一维为空。
_Avoid in this context_: 批次

**效期**  
失效日期，只在商品声明跟踪效期时才有值；不跟踪的商品这一维为空。

**整箱库存**  
按箱号一箱一件记的库存，用于备货中转：箱里装了哪些商品、多少是货主的声明（箱单），不进商品库存。整箱库存带入库批次与库龄，不分库存状态（ADR-0370 决定五）。包装层级里的箱转件是形态转换，不是开箱。箱号在（租户，货主，仓）内在库期间唯一：按箱收货时与在库箱号重复的，收货不成立，交货主补正，或由仓另编箱号并记下货主原箱号。

**开箱**  
把一箱整箱库存转成商品库存：箱出，商品按实点入，沿用该箱的入库批次与入库时间；实点与箱单的差额记为收货差异（ADR-0370 决定五）。

**库龄**  
一个入库批次自入库时间起在仓的天数，按仓的业务时区计日：入库当天算第 1 天，日终仍在库才计当天，所以出库确认当天不计。

**库龄口径**  
仓租发生项把在库量归到哪些入库批次：按实际入库批次（流水实际消耗的入库批次），或按理论先进先出（不管实际拣了哪一批，把在库量归到最近的几次入库）。两种都是产品内置，用哪一种是租户取值。

### 占用与可用量

**可分配库存**  
能被预占的那部分在库：存储或拣选库区里的良品，次品库区里的次品（只给要出次品的出库请求），以及存储库区里的整箱库存（只给整箱出的出库请求）。收货暂存、退货暂存与待出库库区里的库存，以及待检库存，都不可分配。

**占用**  
对可分配库存的数量占用：预占按出库请求的粒度，冻结与作业锁定按格。占用不是库存账的一维，不改实物总量，只减可用量。产品内置封闭三种：预占、冻结、作业锁定，三者互不重叠（ADR-0368 决定五）。

**预占**  
出库请求对可用量的占用，在库存账内原子判定。商品库存的预占按（货主，仓，商品，库存状态，请求点名的批号、效期或贴标别名条件）成立，不落到库位；整箱库存按箱号预占。分配时落到库位与入库批次，出库确认时消耗，出库截单或请求终结时释放。
_Avoid in this context_: 容量预占（运输履约的词）

**冻结**  
运营决定让一格库存暂不可分配的占用，带原因（如货主要求停售、质量争议），只经解冻决定解除。
_Avoid in this context_: 资金冻结（结算与经营核算的词）

**作业锁定**  
盘点进行中对所涉库位库存的临时占用，盘点完成或作废即解除。

**可用量**  
可分配库存减去各项占用。占用互不重叠，直接相减；可用量是算出来的数，不是状态。

### 入库与库内

**入库预报**  
货主经客户渠道交来的到货通知：到哪个仓、预计到仓时间、到仓方式（整柜、托盘、散箱之类）、入库方式（商品入库或整箱入库）与明细（商品入库的写商品、预报数量、可选的批号与效期、箱数；整箱入库的写箱号与箱单）。预报不是库存，也不承诺实收。

**收货**  
仓对一批到货清点后确认的实收事实：商品入库按商品、计量单位与库存状态记实收数量，整箱入库按箱记。收货确认即入账：以收货流水进入收货暂存库区，形成入库批次。
_Avoid in this context_: 收寄（节点作业的说法）、签收

**收货差异**  
实收与入库预报（含整箱入库的箱单）不一致的部分（多收、少收、错货、破损），逐商品或逐箱记类型与数量，交货主确认；开箱时实点与箱单的差额同属收货差异。库存只按实收入账，差异不改实收。

**待认领到货**  
到了仓却认不出属于哪个货主或哪份预报的货，入库到货与退件都可能有。它只登记到货与观察，不进任何货主的库存账；认领给某个货主之后，才按收货或退货入库入账。

**上架**  
把收货暂存或退货暂存里的库存移到存储、拣选或次品库位的库内移动。上架不改数量与入库批次。

**库内移动**  
库存在库位之间的移动：上架、移库、拣选位补货、拣货移入待出库库区、出库截单后的回库与拆包回库。每次移动是一笔成组流水，移出与移入数量相等。

**拣选位补货**  
从存储库位向拣选库位的库内移动；需要拆箱时，同一笔流水里带形态转换。

**形态转换**  
同一商品在包装层级之间的转换（如一箱转为二十四件），在同一笔流水里按货主、商品与计量单位守恒，折成基本单位前后相等（ADR-0368 决定五）。

**加工**  
按组合商品的组成把组件加工成成品，或把成品拆回组件（拆解）的作业；同一笔流水消耗投入、记入产出，按组成相抵。加工由运营决定或货主的加工指令发起。
_Avoid in this context_: 拆分（单说：小包托运与节点作业说的是包裹的真实物理拆分）

### 出库请求与发出

**出库请求**  
跨上下文定义见 [GLOSSARY「出库请求」](../GLOSSARY.md#出库请求)。本上下文的细化：要出的货是商品明细（商品、数量、要出的库存状态、可选的批号、效期或贴标别名条件），或要出的箱号；按发运方式另带要求的服务产品、每个包裹的面单或提货凭证；平台备货另带平台货件信息；另带本单申报值。一份出库请求从一个仓发出。

**发运方式**  
出库请求的货怎么离仓，产品内置封闭三种：本产品网络（逐包裹提交委托）、自备面单、自提（ADR-0370 决定一）。由货主在出库请求上选。

**自备面单**  
货主为出库请求的每个包裹交来的面单：面单文件、承运方与外部单号。仓配履约打印并粘贴，不向承运方核对它是否有效；这种发运方式不经小包托运。

**自提**  
货主或它指定的提货方（包括它自约的承运方）凭提货凭证（提货码或预约）到仓提货。核对凭证、交付提货方即出库确认；这种发运方式不经小包托运。

**平台备货**  
送往平台仓（如亚马逊 FBA）的出库请求，带平台货件信息：货件编号、目的仓、箱规与货主交来的平台标签文件（商品标签、箱标、托盘标）。平台的入库计划与标签都是货主的；仓配履约只按请求打印、粘贴，核对请求声明的箱规与标签张数（ADR-0370 决定四）。

**缺货处置**  
可用量不够满足出库请求时怎么办，产品内置封闭两种：部分预占（先占有的，缺的部分补到再占，全部占齐才进波次），即 ADR-0368 决定五说的「部分分配」；拒绝（答缺货，请求终结）。用哪一种是租户取值，可以按货主选。

**拆单**  
把尚未分配的出库请求拆成几份新的出库请求：原请求终结为已拆单，新请求指名原请求，要出的货合起来等于原请求，各自预占、分配与发出。由货主请求，或由运营按货主授权作出。

**分配**  
波次释放时把预占落到具体库位、入库批次与数量上，生成拣货任务。分配不超过它所属的预占。
_Avoid in this context_: 装载分配（运输履约的词）

**分配策略**  
分配时按什么顺序选入库批次与库位。入库批次的顺序是产品内置封闭三种：先到期先出（按效期）、先进先出（按入库时间）、指定批号（请求点名）；库位先按库区（拣选先于存储）、再按库位优先级。随产品发一份参考配置：跟踪效期的商品先到期先出，其余先进先出；租户经普通登记采用（[ADR-0147](../../adr/0147-reference-configuration-ships-embedded-and-is-adopted-through-ordinary-registration.md)）。

**波次**  
为拣货把一组出库请求的分配合在一起的作业归组，按什么归组（商品、服务产品、库位之类）由仓定。波次不取得出库请求的身份，也不是节点作业的作业批次。
_Avoid in this context_: 作业批次、提交批次

**预取面单**  
波次释放时，为发运方式是本产品网络、已全部分配的出库请求先按一个包裹提交委托，让面单随拣货单打印；声明测量先取估算，打包后按小包托运的资料修订规则补正（ADR-0370 决定二）。是否预取由仓内作业逐波次选。

**拣货任务**  
按分配从某个库位拣出某商品某数量（或某个箱）、移入待出库库区的仓内任务；完成即记一笔库内移动流水。实拣与分配不符时按实拣记，差额形成库存差异（ADR-0368 决定六）。
_Avoid in this context_: 作业任务（节点作业的词）

**出库复核**  
打包前按出库请求逐件核对拣出的商品与数量，整箱出的扫箱号。核对不符的不打包：退回重拣，或形成库存差异。
_Avoid in this context_: 复核（单说：在别的上下文是重新审、重新判）、验货

**打包**  
把出库复核通过的货装成一个或多个包裹，称重量方、记所用包材；整箱出的一箱就是一个包裹。每个包裹在出库请求内有包裹序号。发运方式为本产品网络的，打包完成即为这个包裹提交一份委托，预取面单的已在波次释放时提交。

**装箱记录**  
打包时按包裹序号记下装了哪些商品（或哪个箱）、多少、包材与称得的重量和尺寸。委托提交后它指名小包托运的委托与包裹；自备面单的记面单的承运方与外部单号。本上下文不另立包裹身份。

**仓配出库提交**  
发运方式为本产品网络时，以出库请求所属货主客户账户的名义向 `parcel-shipment` 提交委托：来源「仓配出库」，来源请求键是（出库请求，包裹序号）；称得的重量与尺寸作声明测量（预取面单时先取估算，代理仓出库时取代理仓报来的数），收件人、商品明细（整箱出时取该箱的箱单）与申报值作客户原始资料。它与客户渠道交来的委托受同一套接受判断（ADR-0368 决定四）。

**出库确认**  
货离开仓、交给下一程那一刻由仓内作业确认的事实：本产品网络的交给同址节点（由节点作业按客户送站收寄，本上下文不为它开送站预报或送站交接单）或交给场外揽收，经面单渠道服务的交给面单所指的承运商，自备面单的交给面单所指的承运方，自提的交给核对过凭证的提货方。库存在这一刻按分配消耗，预占随之消耗；出库确认之后这件货不再归本上下文。代理仓出库的出库确认来自代理仓报来的交接结果，不消耗本上下文的库存账。错记的出库确认以更正版本表达：同一出库确认引用下的新版本指名被更正的那一版，可以改时点，也可以判这次出库确认不成立；不成立的，库存经批准以调增流水回补；交给全程追踪的事实随之带替代关系。
_Avoid in this context_: 出库（单说：在 `customs-compliance` 是节点上受门禁约束的交出动作）、发货

**出库截单**  
货主撤回尚未出库确认的出库请求或其中的包裹。打包之前按整份出库请求判定，打包之后逐包裹判定；成立的按所处阶段释放预占、撤销分配，或回库。
_Avoid in this context_: 截单（单说：在 `settlement-accounting` 是对账截单，`network-routing` 另有截单条件）

### 盘点、差异与调整

**盘点**  
按库位、或按商品加库位清点实物并与账比对的作业。本上下文的盘点是静盘：开始时对所涉库位的库存加作业锁定，结束时解除。
_Avoid in this context_: 在场核对（节点作业的说法）

**库存差异**  
账与实物不符的部分：盘点差异、实拣与分配不符、上架或出库复核时发现的短少与破损。差异交人处理：经批准的以新流水改账，未批准的不改账（ADR-0368 决定六）。

**库存调整**  
盘点之外改账的决定，如找回、调增调减、建账导入、销毁。调整带原因，经批准后以流水入账。

### 退货

**退货预报**  
货主告知将有退件到仓的通知，带原包裹的外部标识或跟踪号与预计的商品。没有预报的退件照样可以到仓。

**退货入库**  
退件到仓后的登记、清点与质检。按退货预报或本上下文的装箱记录认出货主与商品，认不出的建待认领到货；清点结果以退货入库流水进入退货暂存库区，形成新的入库批次，状态按质检记良品、待检或次品。

**回库处置**  
退货入库之后，按货主指令或租户规则对每件货定去向：良品上架回可分配库存、转次品入次品库区、销毁，或经新的出库请求退还货主。处置由运营决定，执行以流水入账。

### 代理仓

**代理仓库存声明**  
代理仓按时点报来的货主库存数量，带来源、声明时点与有效期。它不是自营实时库存，不进库存账；过了有效期答「未知」，不据它做确定性承诺（ADR-0368 决定五）。

**代理仓出库**  
把出库请求经连接器转给代理仓执行，收回代理仓的受理或拒绝、装箱结果与交接结果，作为来源事实原样保全。本上下文不为代理仓铸拣货、出库复核与打包事实；本产品网络的由仓配履约在装箱结果报来时代货主提交委托，代理仓报来交接结果即出库确认（ADR-0370 决定三）。

### 收费发生项

**仓储作业收费发生项**  
跨上下文定义见 [GLOSSARY「仓储作业收费发生项」](../GLOSSARY.md#仓储作业收费发生项)，本上下文不另写；它的种类、计量与作业属性各有一条词条。

**作业种类**  
收费发生项的种类，产品内置封闭七种：入库作业、出库作业、仓租、退货处理、增值服务、加工、销毁。各种类对应哪些作业由本上下文定义；收不收、怎么收是价卡的事。

**计量**  
发生项里的一组（数量，单位），如票、箱、托、件、千克、立方米、库位·天。本上下文只给发生了多少，不分段、不给单价。
_Avoid in this context_: 计费重量（客户计费重量与供应商计费重量是 `settlement-accounting` 的词）

**作业属性**  
价卡判条件要用的发生项属性，如到仓方式、发运方式、服务产品、包材、库存状态、库存形态（商品或整箱）、库区用途、库位类型。属性只描述作业，不含价格。

**增值服务项目**  
增值服务发生项指名的服务，如贴标、商品换标、拍照、质检、加固；项目表由租户登记，没登记的项目不形成发生项。

## Rules and invariants

### 身份与边界

- 商品库存与包裹是两种身份，按对象分边界、不按场地分：打包完成、委托提交之前只有库存与任务，之后只有包裹。库存的库位与状态不是包裹的节点控制；包裹的节点控制与作业位置也不是库存（ADR-0368 决定三）。预取面单的波次例外：委托在波次释放时就已提交，包裹身份从那时起就在小包托运，货在出库确认之前仍是本上下文的库存（ADR-0370 决定二）。
- 本上下文的货主就是货主客户账户；商品、库存与请求都挂在它下面，不另立货主档案，也不跨货主客户账户合并库存。
- 仓、库区与库位是本上下文的身份。仓与物流节点同址时只互相指名，不合并；节点作业的作业位置不当库位，库位也不进节点作业的位置关系。
- 认不出货主或预报的到货与退件建为待认领到货，不冒充任何货主的库存；认领之后才入账。
- 商品身份是（租户，货主，商品编码）；别名在同一货主内只指一个商品（可以是组合商品），不跨货主解析。
- 本上下文不记库存成本与价值，不管货主的采购、销售订单与补货计划（ADR-0368 决定二）。
- 凡按日计的（库龄、仓租计费日、日终在库）都按仓的业务时区；仓的业务时区没登记时这些都答未配置。
- 入库预报进入已预报、出库请求进入已受理时，在同一事务内取得单据号，退货预报在记下它的同一事务内取得，每种一个单据类型；拆单拆出的出库请求是新单据，各取新号（[ADR-0355](../../adr/0355-a-document-number-is-separate-from-internal-identity-and-is-assigned-in-the-issuing-transaction-under-built-in-rules-a-tenant-may-override.md) 决定二、三）。单据号不替代内部身份。号里的日期按仓的业务时区，仓的业务时区没登记时按租户的单据编号时区。

### 库存账与守恒

- 余额只由库存流水派生。已入账的流水不改不删；收货短少、错发、盘点差异这类更正都以新流水表达。
- 守恒：按（租户，货主，仓，商品）折成基本单位汇总，期末在库 = 期初 + 增项 − 减项。增项是收货、退货入库、加工与拆解的产出、开箱转入，以及已批准的建账导入、盘盈与调增；减项是出库确认、加工与拆解的投入、开箱转出，以及已批准的盘亏、调减与销毁。库内移动、状态转换、商品换标与占用只改位置、分类与可用量，不改这个汇总；形态转换折成基本单位守恒；加工与拆解按组成相抵。整箱库存按（租户，货主，仓）的箱数同样守恒。
- ADR-0368 决定五原来的守恒式已由 ADR-0370 改为这一写法。加工、拆解与开箱是仓内的形态变化，按组成或实点相抵，只在按商品汇总时表现为一增一减。
- 仓间调拨不另立对象：由货主以调出仓的出库请求与调入仓的入库预报两件办，整托调拨可以用自提或本产品网络发出；调出与调入即 ADR-0368 决定五原式里的调出、调入。库存属于货主，运营不自行发起调拨。
- 商品库存只放在与状态相容的库区：存储与拣选库区只放良品，次品库区只放次品，收货暂存、退货暂存与待出库库区三种状态都可以放，待检只在这三种暂存库区。移入次品库区的库存在同一笔流水里转为次品；次品转回良品要一笔单独的状态转换，由有授权的运营决定作出。
- 整箱库存与商品库存分开记、分开守恒：整箱按箱守恒，只放在收货暂存、存储与待出库库区。开箱时箱出、商品按实点入并沿用该箱的入库批次，实点与箱单的差额记收货差异交货主确认，不改账；箱单不改实点。
- 入库批次只由收货、退货入库、建账导入，以及加工、拆解的产出形成，入库时间取入账那一刻（建账导入取声明的入库时间）；开箱转入的商品沿用该箱的入库批次与入库时间；状态转换、库内移动、形态转换与商品换标不另起入库批次。

### 占用、预占与分配

- 三种占用互不重叠，可用量直接相减。任何一种占用成立之后，受它影响的每个（货主，仓，商品，库存状态）汇总上，可分配库存都不得少于各项占用之和；带批号、效期或贴标别名条件的预占，还要在满足条件的那部分上成立。冻结与作业锁定不满足这一条时不成立，不挤占已成立的预占，ADR-0368 决定五「不得重复扣减」即此。
- 预占在库存账内原子判定，成功的预占合计不超过可用量；不足时按缺货处置办，不静默超卖（ADR-0368 决定五）。缺货处置没选时答未配置：请求停在待预占（未配置），可用量变化时也不再判，直到租户选定。
- 商品库存的预占只落到（货主，仓，商品，库存状态，批号、效期或贴标别名条件），不落库位；整箱出的按箱号预占。分配在波次释放时把预占落到库位与入库批次，分配合计不超过预占，顺序按租户采用的分配策略。分配策略没采用时答未配置，不分配。
- 不带贴标别名条件的出库请求只预占未贴标的库存；带贴标别名条件的，先预占贴着该别名的库存，不够再预占未贴标的库存，这部分在出库复核之前完成贴标。所有从未贴标库存里取的预占合计，不超过未贴标的可分配量（ADR-0370 决定四）。
- 按组件出的组合商品在受理时展开成组件行，按组件预占；按成品出的只预占成品库存，不就地加工。
- 预占在出库确认时消耗，在出库截单、拒绝、拆单或请求终结时释放；只释放属于这份出库请求、还没消耗的部分。
- 冻结只经解冻决定解除。作业锁定随盘点完成或作废解除；所涉库位上还有未完成的拣货任务，或加了作业锁定会让某个汇总上的可分配库存少于各项占用之和，盘点都不能开始。
- 离线端不铸预占与分配：预占是计划，不是事实（ADR-0368 决定六）。

### 入库与加工

- 入库预报不是库存；库存只因收货确认入账。
- 收货确认即以收货流水进入收货暂存库区，形成入库批次；上架是之后的库内移动。整箱入库的按箱收货、按箱上架，形成整箱库存。
- 收货差异逐商品或逐箱记录并交货主确认；库存只按实收入账，差异的认定不回改实收。
- 收货、退货入库与建账导入按实点记贴标别名：到货已贴平台标签的记那个别名，没贴的为空。
- 商品首次收货时测仓测尺寸重量，整箱入库的按箱测。还没测不阻断收货与上架；依赖体积与重量的计量如实答未测量，另附货主声明的那份并标明来源。评价时用不用声明值，归计价那份另立的 ADR 定，本上下文不替它决定。
- 加工与拆解按组成版本在同一笔流水里消耗投入、记入产出；组件不够时不加工，不预支。

### 出库请求与发出

- 一份出库请求属于一个货主客户账户、从一个仓发出、带发运方式（ADR-0370 决定一）。出库请求由货主经客户渠道交来，或由运营按货主授权录入（如回库处置退还货主）；谁有权代录是租户取值，没登记答未配置。
- 本产品网络按仓的位置分两种：仓在起运侧时提交国际小包委托，委托随网络到目的国，尾程交本地小包派送；海外仓与目的国代理仓发给当地收件人的件，只能提交面单渠道服务产品的委托，由运营企业代货主取得本地承运商面单，不用运营企业自己的网络服务产品（[ADR-0371](../../adr/0371-warehouse-fulfillment-acts-for-the-owner-on-warehouse-outbound-requests-and-every-decision-path-hands-off-the-acceptance-decision.md) 决定六）。
- 本产品网络：出库请求带要求的服务产品；每个包裹以（出库请求，包裹序号）为来源请求键、以来源「仓配出库」提交一份委托，与客户渠道交来的委托受同一套接受判断，不绕过任何接受规则（ADR-0368 决定四）。以货主名义的各请求（提交、补充、资料修订、撤回与取消）由本上下文代办，请求方、授权与未配置的答法以小包托运 CONTEXT 为准（ADR-0371 决定一、二）。只有委托已被接受、包裹没有有效取消的才能出库确认；面单由小包托运的面单交易给出，本上下文只打印与粘贴，不改变它代表的交易。
- 委托提交后，小包托运先答生产归属与已提交，接受或拒绝在那之后才形成。本上下文按小包托运交出的接受决定信封推进装箱记录，不读委托的内部状态；哪些决定经这封信封交出，以小包托运 CONTEXT 为准。包裹的有效取消不论谁提出（货主也可以经客户渠道自己取消），经包裹取消已记录的信封交到本上下文，进出库的放行条件。撤回与取消由本上下文以货主名义提出时，成不成立以小包托运对那次请求的答复为准。委托停在等待受控补充时，小包托运交「委托待受控补充」信封，本上下文向货主要补正，以货主名义提交新提交版本；货主手里没有提交回执，不直接补（ADR-0371 决定三）。生产归属落在别的权威或本产品暂停新准入时，按委托未接受办；归属未决时原样重发同一来源请求，由小包托运按它的重放规则续办（[ADR-0266](../../adr/0266-a-submission-replay-answers-what-the-first-round-answered-and-only-unresolved-ownership-is-judged-again.md)）。
- 面单交易只落面单的引用；小包托运的面单本体存放还没配置时（[ADR-0092](../../adr/0092-channel-label-payload-lands-as-a-reference-and-the-body-store-is-an-unconfigured-outbound-seam.md)），本上下文取不到面单本体，答未配置，这个包裹不出库确认。
- 自备面单：每个包裹一份货主面单。打包出的包裹数与面单数对不上，或承运方拒收时，不出库确认，交货主补正：货主经客户渠道为这份出库请求补交面单，或出库截单。包裹交给面单所指的承运方即出库确认，记外部单号。
- 自提：核对提货凭证、交付提货方即出库确认，记提货方与凭证。
- 自备面单与自提的出库请求不经小包托运：本产品不形成委托、包裹、面单交易、申报或追踪，货物离仓之后的去向由货主与它选的承运方负责（ADR-0370 决定一）。
- 声明测量取打包时称得的重量与尺寸，预取面单与代理仓出库各有例外，见各自一条。客户原始资料取出库请求的收件人与本单申报值，本单没给的申报格取商品申报资料；整箱出时货物内容取该箱的箱单，缺的申报格取箱单所列商品的商品申报资料（ADR-0370 决定五）。每个申报格带来源标记（本单申报、箱单或商品申报资料），随客户原始资料原样交给小包托运，不合并成无来源的值，关务据此做字段级溯源。都没有的格照实空着：本上下文不补默认值，也不判归类与合规。
- 预取面单只对发运方式为本产品网络、已全部分配的出库请求，按一个包裹（包裹序号 1）提交委托；声明测量先取估算，即所分配商品的仓测重量合计加所选包材的重量，尺寸取包材的外廓尺寸；有商品没测或没选包材的不预取。打包后称得的与估算不同的，以货主名义按小包托运的资料修订规则提交更正，更正还没被采用时这个包裹不出库确认；更正不放行，或一个包裹装不下，就按小包托运的规则撤回或取消那份委托，改走打包后提交，换新的包裹序号（ADR-0370 决定二）。预取只在三格都已登记时可选：该货主有仓配代办与资料修订的代办授予，所采用接单规则包对「已制签或已装袋」阶段的声明测量修订有允许声明，包裹取消的授权规则已登记；任一格未配置即不预取，照打包后提交。这三格是小包托运既有的租户取值，预取本身仍是逐波次的作业选择。更正的采用结果经资料版本已形成的信封交回（ADR-0371 决定四）：待补充的由本上下文补，冲突按更正不放行办，待复核或未决的等；等待时限由租户登记，到时转撤回或取消，没登记答未配置，包裹停在仓里待人处理。
- 出库复核不符的不打包。
- 委托被拒绝或撤回的包裹不出库确认：拆包回库，或经运营决定换新的包裹序号重新打包提交；同一来源请求键不复用，原装箱记录照留。包裹被有效取消的，拆包回库，这一件按出库截单成立办。
- 出库确认的放行条件随包裹下发给作业端，带有效区间，由作业端判断：本产品网络的委托已接受且包裹没有有效取消、面单本体已取到、预取面单的更正已采用，自备面单的包裹数与面单数对上。缺一格或出区间时不交出，本文说的「不出库确认」「才能出库确认」，都指作业端交不交出。离线或越权已经交出的，照记出库确认，同笔留下当时的放行条件并标出缺哪几格，交人处理，写口不拒（[ADR-0024](../../adr/0024-directional-work-basis-carries-a-validity-interval.md)；与 ADR-0251 对节点方向性作业照记是同一形状）。
- 库存在出库确认时按分配消耗，不等节点收寄，也不由节点收寄触发；出库确认与节点收寄是两件事实，谁也不替谁，同址时也如此（ADR-0368 决定四）。
- 出库确认之后，这件货的取消、去向与处置归 `parcel-shipment` 与网络各上下文（自备面单与自提的归货主与它选的承运方），本上下文不再受理出库截单。
- 出库截单在打包之前按整份出库请求判定，打包之后逐包裹判定：未分配的释放预占；已分配未拣的撤销分配并释放；已拣出的回库后释放；已提交委托的，先按小包托运的规则撤回或取消那份委托，成立后拆包回库，小包托运不放行时这一件不成立。出库截单后的回库与拆包回库都是库内移动，不是退货入库。
- 拣货事实回传时，它的分配已因出库截单撤销的，照记为移入待出库库区的库内移动，同笔生成回库任务，不算库存差异。
- 拆单只对尚未分配的出库请求成立；原请求终结为已拆单，新请求要出的货合起来等于原请求，原请求上的预占随之释放，由新请求各自重新预占。
- 平台备货按请求声明的箱规装箱，按货主交来的标签文件打印粘贴；核对只对请求自己声明的箱规与标签张数，不内置任何平台的标签规格、箱数箱重上限或入库计划规则，也不对接平台（ADR-0370 决定四）。
- 整箱出的请求按箱号出库复核，一箱就是一个包裹；发运方式为本产品网络时一箱一份委托（ADR-0370 决定五）。

### 盘点、差异与调整

- 盘点是静盘：开始时对所涉库位库存加作业锁定，结束时解除。
- 盘点结果与账的差额形成盘点差异；经批准形成盘盈或盘亏流水，未批准不改账。
- 盘点之外的调整同样带原因、经批准后入账。
- 离线拣出的件在账上不可用时照记拣货事实，差额形成库存差异交人处理，写口不拒（ADR-0368 决定六，与 [ADR-0251](../../adr/0251-directional-node-work-is-paused-outside-the-validity-interval-of-the-delivered-basis-and-recorded-moves-are-never-refused.md) 对已经发生的作业照记是同一立场）。
- 谁有权批准差异与调整、差异要在多久内处理，是租户取值；没登记答未配置，差异停在待处理，不自动调账。

### 退货

- 退件按退货预报或本上下文的装箱记录（含自备面单的外部单号）认出货主、原出库请求与商品；认不出的建待认领到货。
- 退货入库形成新的入库批次，库龄从退货入库起算；它不冲回原出库确认，原出库请求的结果不变。
- 回库处置逐件作出、逐件执行；未处置的货留在退货暂存库区，不可分配。

### 代理仓

- 代理仓库存声明不进库存账，不与自营仓库存相加成一个数。声明过了有效期答「未知」；不对声明预占，也不据它承诺（ADR-0368 决定五）。
- 代理仓出库经连接器转给代理仓执行；代理仓报来的受理、拒绝、装箱与交接结果作来源事实原样保全，带代理仓的来源标识与时间，本上下文不替它铸作业事实。代理仓答缺货或拒绝时，那份出库请求按已拒绝终结，货主可以改从别的仓发。
- 本产品网络的代理仓出库，由仓配履约在装箱结果报来时代货主提交委托，声明测量取代理仓报来的数；委托接受后把面单交给代理仓。自备面单与提货凭证同样经连接器转给代理仓。代理仓报来交接结果即出库确认。
- 连接器照公开规范或模拟源接；接哪家代理仓、协议细节与凭据是租户取值（ADR-0370 决定三）。
- 代理仓只经连接器办出库与库存声明：指名代理仓的入库预报与退货预报不受理，由货主与代理仓直接办；代理仓不形成入库作业、仓租与退货处理发生项。

### 收费发生项

- 本上下文只登收费发生项，不带金额；对货主收多少由 `parcel-pricing` 按 `SELL` 价卡评价，`settlement-accounting` 采用为客户运营应收（ADR-0368 决定七）。计价为它立评价对象另立 ADR，在那之前小包计价的评价对象不含它。
- 各种类在作业事实发生时形成：入库作业在收货确认时按每次收货形成；出库作业在出库确认时按每个包裹（自提按每次提货）形成，代理仓出库以代理仓报来的交接结果为来源事实；退货处理在退货入库与回库处置时形成；增值服务在服务完成时形成；加工在加工或拆解入账时形成；销毁在销毁入账时形成。
- 仓租按（货主，仓，计费日）每日形成一份，带日终在库的计量：按入库批次给出数量、仓测体积、库存状态、库存形态、库区用途与库龄天数，按库位给出占用的库位、库位类型与连续占用天数。库龄段、免租期、淡旺季与单价都在价卡里，不在这里。库龄口径没选时不形成仓租发生项，答未配置。
- 体积与重量类计量取仓测尺寸重量；未测的如实答未测量，另附货主声明的那份并标明来源。
- 同一作业事实至多形成一份发生项，重放答已有的那一份。发生项形成之后不改写；来源事实被更正时追加更正版本，指名被更正的那一份。

### 作业端

- 收货（含按箱收货）、上架、移库、补货、加工、商品换标、开箱、盘点、拣货、出库复核、打包、出库确认与自提交付进入一线作业客户端；离线与弱网容忍照 [ADR-0021](../../adr/0021-frontline-operations-client-is-part-of-the-product.md)，作业事实的身份与发生时间由设备签发（[ADR-0023](../../adr/0023-work-fact-identity-and-time-are-minted-by-the-device.md)），见 ADR-0368 决定六。

## Lifecycles

### 入库预报

- 货主经客户渠道提交 → 已预报：固定仓、到仓方式、入库方式、预计到仓时间与明细，同一事务取得单据号。
- 已预报 → 收货中：第一次收货确认；一份预报可以分几次收货。
- 收货中 → 已完结：仓确认这份预报收货结束，没到的数量记为少收。
- 已预报 → 已取消：货主在第一次收货确认之前撤回；收货开始之后不能撤回，只能按收货差异了结。

### 收货与上架

- 到货清点 → 收货确认：按商品、计量单位与库存状态（整箱入库的按箱）入账到收货暂存库区，形成入库批次，与预报比出收货差异。
- 收货暂存 → 已上架：移到存储、拣选或次品库位；可以分几次上架，没上架的部分留在收货暂存，可见但不可分配。
- 待认领到货 → 已认领：认给一个货主之后按收货或退货入库入账；认不出的留在待认领，怎么处置归租户规则。

### 加工

- 加工指令 → 待加工：固定组合商品、组成版本与数量（拆解时固定成品与数量）。
- 待加工 → 已加工：投入与产出在同一笔流水里入账，产出形成新的入库批次；组件不够时停在待加工。
- 待加工 → 已作废：不入账。

### 出库请求

- 货主经客户渠道提交，或运营按货主授权录入 → 已受理：固定仓、发运方式、要出的货、收件人与地址、本单申报值，以及按发运方式要带的服务产品、面单或提货凭证，同一事务取得单据号；按组件出的组合商品在这时展开。
- 已受理 → 已预占、部分预占、待预占（未配置）或已拒绝：按可用量与缺货处置原子判定。部分预占的请求在可用量变化时再判；待预占（未配置）的不再判，直到租户选定缺货处置。
- 已受理、待预占（未配置）或部分预占 → 已拆单：拆成几份新的出库请求，原请求终结；拆出的新请求各取新的单据号。
- 已预占 → 已分配：波次释放时分配并生成拣货任务；预取面单的这时提交委托。
- 已分配 → 已拣货：拣货任务全部完成。实拣不足的部分撤销分配、保留预占，等下一次波次释放再分配，差额形成库存差异。
- 已拣货 → 已打包：出库复核通过、逐包裹打包；本产品网络的每个包裹提交一份委托（预取面单的改为补正声明测量）。
- 自提不需打包的：已拣货、出库复核通过 → 交付提货方即已发出。
- 已打包 → 已发出：全部包裹出库确认，或其余包裹已经出库截单回库。
- 委托未接受的包裹全部拆包回库，经运营决定不再重提 → 已关闭：预占释放。
- 出库截单成立 → 已取消（整份截回）或部分取消；已出库确认的包裹不受影响。
- 指名代理仓的：已受理 → 已转代理仓 → 代理仓已受理（代理仓答缺货或拒绝即已拒绝）→ 代理仓报来装箱结果（本产品网络的这时代货主提交委托）→ 代理仓报来交接结果即已发出。
- 已拒绝、已拆单、已取消、已关闭与已发出都是终态；本文说的请求终结，就是进入其中之一。

### 装箱记录

- 打包 → 已打包：记包裹序号、商品（或箱号）与数量、包材与称得的重量尺寸。
- 本产品网络：已打包 → 委托已提交（预取面单的委托在打包之前已提交，这时补正声明测量，更正被采用之后才能出库确认）→ 委托已接受 → 已出库确认，库存按分配消耗；委托未接受（被拒绝或撤回）→ 已拆包回库，或换新的包裹序号重新打包，原装箱记录照留；包裹被有效取消 → 已拆包回库，这一件按出库截单成立办。
- 自备面单：已打包 → 已贴面单（包裹数与面单数对上）或待货主补正（对不上，或承运方拒收）→ 交给面单所指的承运方即已出库确认，记外部单号；待货主补正的，货主补交面单后回到已打包，或经出库截单拆包回库。
- 自提：已打包（或按请求备好的货）→ 核对提货凭证、交付提货方即已出库确认。
- 出库截单 → 委托撤回或取消成立后（不经小包托运的直接）拆包回库。

### 盘点

- 创建 → 待盘点：固定所涉库位与商品，这时不锁定。
- 待盘点 → 盘点中：所涉库位上没有未完成的拣货任务、加作业锁定也不违反占用规则时开始，加作业锁定。
- 盘点中 → 已盘点：录入清点结果，算出盘点差异，解除作业锁定。
- 已盘点 → 差异已批准（盘盈、盘亏流水入账）或差异已驳回（不改账）。
- 盘点中 → 已作废：解除作业锁定，不形成差异。

### 库存差异

- 形成 → 待处理：记来源（盘点、拣货、上架或出库复核）、所在的格与差额。
- 待处理 → 已批准：以盘盈、盘亏或调整流水入账；待处理 → 已驳回：不改账。

### 退货入库

- 到仓 → 已登记：按退货预报或装箱记录认货主，认不出的转待认领到货。
- 已登记 → 已清点：清点与质检结果以退货入库流水进入退货暂存库区，形成入库批次。
- 已清点 → 已处置：逐件回库处置，全部处置完即结束。

### 冻结

- 运营决定 → 已冻结：固定格、数量与原因；违反占用规则时不成立。
- 已冻结 → 已解冻：解冻决定作出，数量回到可用量。

### 代理仓库存声明

- 收到 → 有效：带来源、声明时点与有效期。
- 有效 → 已过期：过了有效期，答「未知」。
- 有效或已过期 → 已被取代：同一来源对同一格报来更新的声明。

## Boundaries and ownership

- `warehouse-fulfillment` 拥有货主商品身份、商品别名、组合商品与组成、包装层级、仓测尺寸重量与货主声明的商品申报资料，包材，仓、库区与库位，库存账与库存流水（含整箱库存与贴标别名），占用与分配，入库预报、收货与收货差异、待认领到货、上架、库内移动、形态转换、加工、商品换标与开箱，出库请求、发运方式、拆单、波次、预取面单、拣货任务、出库复核、打包与装箱记录、出库确认与出库截单，盘点、库存差异与库存调整，退货预报、退货入库与回库处置，代理仓库存声明与代理仓出库，以及仓储作业收费发生项。
- `party-commercial` 拥有货主客户账户、合同与服务产品；本上下文引用它们，不另立货主档案。
- `parcel-shipment` 拥有委托、包裹身份、面单交易与客户承诺；本上下文为发运方式是本产品网络的出库请求以货主名义提交委托、保存答复，不取得委托或包裹的所有权。委托提交之后，包裹的撤回、取消与处置按小包托运的规则办。自备面单与自提的出库请求不经小包托运。
- `node-operations` 拥有节点收寄、作业位置、节点控制与集运单元；同址时出库确认与节点收寄各记各的，本上下文不读也不写节点作业的事实。
- `transport-fulfillment` 拥有揽收、运输交接、交付与退运旅程；退件交付到仓是它的交付，到仓之后的退货入库归本上下文。
- `customs-compliance` 拥有正式申报资料、归类与合规判断；本上下文只把货主声明的申报资料（整箱出时是箱单）原样带进委托。出库确认不是关务受门禁的「出库」动作；保税仓不进产品（ADR-0370 决定七）。
- `parcel-pricing` 评价仓储作业收费发生项，`settlement-accounting` 形成费用与客户运营应收；本上下文不带金额，也不据它们改写发生项。评价时能不能用货主声明的尺寸重量，由计价定。
- `visibility-exception` 只投影事实所有者已接受的事实。本上下文把发运方式为本产品网络、已指名小包托运包裹的出库确认交给它（类型词 `warehouse-outbound-confirmed`），标准里程碑映射由租户登记；出库请求的受理、预占、拣货、出库复核与打包这些仓内中间事实，以及不经本产品网络发出的货，都不进客户全程追踪，货主经本上下文的客户渠道查出库请求（ADR-0370 决定六）。
- 代理仓由合作方经营；本上下文只保全它报来的事实，不替它铸作业事实，也不记它的库存账。平台仓的入库计划与平台标签归货主与平台，本上下文不对接平台。
- 跨上下文的提供与消费关系以 [CONTEXT-MAP「关系约束」](../CONTEXT-MAP.md#关系约束)为准。
