以下是候选聚合边界，不等于表设计；聚合应围绕业务不变量和事务一致性决定。

候选聚合标识与状态关键命令 / 不变量

库存余额 / 库存流水货主、仓、库位、SKU、批次、质量等维度；粒度待验证入账、预占、释放、扣减、调整；并发下不得重复占用同一可用量
物流单元物理实例、状态、封签、成员版本装入、移出、封闭、解封；有效直接父级唯一、禁止循环，锁定或约束方案待设计

06 / 核心场景与异常

按业务事实而非页面步骤建模。选中场景展开。

场景 A：国内至海外的小包换单

客户委托与预报 → 国内观察、匹配与收货 → 测量、分拣 → 可选装袋与部分交出 → 头程与适用清关 → 海外袋级或逐件接收 → 旧码匹配 → 面单就绪、打印与贴标确认 → 尾程实际交出及对方回执。

异常：无预报隔离认领；袋到件未核不视为逐件接收；面单未就绪等待；购单和打印超时分别保留未知。

场景 B：商品库存到一件代发

ASN / 无预报接收 → 核验货主、SKU、数量与质量 → 指定库存权威上架记账 → 订单请求预占 → 波次或单单拣货 → 复核包装 → 实际出库扣减 → 交接与费用依据。

异常：短收、过期、破损、并发抢占、取消释放、部分拣出均需具体处理及账本追溯。代理仓库存有来源和过期时间。

场景 C：部分交接、截单与费用

计划 100、观察 98，其中 1 暂扣、97 符合条件交出；对方仅汇总声明 96。保留 97 逐件交出事实及 96 汇总声明，差异 1 未定位；2 件未观察不等于丢失。按合同决定候选费用，不构造逐件接收。

已发起截单、外部拦截和退款各自独立；部分成功、超时未知和资金冲正均保留原证据。

场景 D：无预报退件及客户处置

到仓观察 → 身份候选与授权认领 → 待指令 → 检查及客户授权 → 重派、退回或其他合法处置 → 费用依据与反馈。若拆包并恢复商品库存，商品库存权威核验后再记账。

07 / 一致性与事件设计

本地一致性

围绕聚合内不变量进行原子校验。预占、库存变化和对应流水必须采用经过验证的事务与并发策略；幂等键作用域和保存期依据业务重试窗口确定。

跨系统协作

可采用事务性 Outbox 或等价可靠发布，消费侧去重、处理乱序与对账；外部副作用依合作方幂等或查询能力处理，不承诺端到端恰好一次。

事件证据

保留事件 ID、对象和版本、租户、来源、发生与接收时间、粒度、关联和因果 ID。纠错追加引用原记录，不删除已发生事实。

异常与补偿

UNKNOWN、PARTIAL 和 DISPUTED 一等建模。补偿是新增业务动作；无法撤回的实物交接、打印、清关或扣费需经责任方处理。

11 / 商品库存与仓配：战术设计

候选聚合与身份

商品目录、库存账户、库存预占、入库单、作业任务、出库请求分别为候选聚合。库存账户粒度至少评估租户、货主、仓、库位、SKU、质量、批次、序列号与有效期。最终边界以不变量和既有 Parcel 模型确定。

库存守恒

在同一计量粒度下，期末实物在库 = 期初 + 已确认入库 + 调入 + 已批准盘盈 − 已确认出库 − 调出 − 已批准盘亏。状态转换和预占只改变分类或可用量，不得凭空改变实物总量。

可用量与预占

若预占、冻结和锁定分类互不重叠，可用 = 已确认在库 − 预占 − 冻结 − 锁定；否则须建立明确的交集处理，禁止重复扣减。同一可用量并发预占必须原子检查并防止超卖。

箱库存与商品库存

开箱转换前明确箱中 SKU 数量、货权、质量、计量单位与可验证明细；转换采用原子或受控中间状态，一次只能由唯一库存权威执行，转换前后按 SKU 及单位守恒。

命令 → 成功事实前置条件与事务边界拒绝 / 异常
确认收货 → 收货事实站点、货主、数量、单位及质量可核验；观察不自动入库存无预报、错货、短收记录差异并等待认领或复核
确认上架 → 库存入账指定库存权威，在同一事务内登记有效数量与流水库位禁用、货权冲突、重复命令拒绝或返回原结果
申请预占 → 预占成功库存权威按可用量和规则原子判定，记录订单及版本不足可拒绝或按明确策略部分分配，不得静默超卖
取消 → 预占释放只释放尚未消耗且属于该订单的有效预占已拣货或已交接启动回库 / 截单，不直接回滚现实
出库复核 → 库存扣减基于已确认出库的 SKU、货权、数量和预占，同事务写流水缺货、错拣、损坏进入差异；补偿与审批有审计

维度候选状态 / 命令核心约束
站点到仓OBSERVED → RECEIPT_PENDING → ACCEPTED / REJECTED观察与接收独立；仅扫描袋码不证明内部逐件接收。
认领关联UNMATCHED / AMBIGUOUS → MATCHED → CLAIM_REVOKED授权与证据必需；撤销是新事实，已执行操作需要影响分析。
箱袋OPEN → SEALED → REOPENED；可再次封签形成新版本同一实物同一时刻至多一个直接父级；禁止循环；并发装载必须原子控制。
交出进度PLANNED → PARTIAL_DISPATCHED → DISPATCHED按已交出批次记录，可在其他件未交出时收到部分回执。
接收对账ACK_PENDING / PARTIAL_ACK / DISPUTED / CONFIRMED与交出进度并存；汇总回执只能确认汇总数量，不产生单件事实。
购单与打印申请 REQUESTED / READY / FAILED / UNKNOWN；打印单次独立接口超时和打印回执缺失为 UNKNOWN；贴标需独立复核；重打不再次购单。
边界示例：计划 100、仓库观察 98、1 暂扣、97 实交，对方汇总声明 96；未交 3 与差异 1 同时存在，不指定丢失件。

13 / 跨域流程、费用与逆向

事件链：国内至海外

ArrivalObserved → ReceiptAccepted → MeasurementRecorded → MembershipRecorded / UnitSealed → DispatchRecorded → 承运方声明 → 海外 ArrivalObserved → LabelReady → PrintAttempt / AppliedConfirmed → 尾程交出。

每条事件保留原始来源、发生与接收时间、主体、租户、关联 ID、对象版本、粒度；命名均为候选。

分阶段费用

仓库输出计费证据，计费域按合同、币种、规则生效时间和费用粒度产生候选；审批、账单、冻结、扣款和退款分别记录。重复事件不得重复收费，已出账调整或冲正不得改写原单。

截单与部分成功

REQUESTED → ASSESSING → EXECUTING → SUCCEEDED / FAILED / UNKNOWN；仓内、承运商和资金动作分别记录。外部超时须查询 / 对账，不能将请求成功解释为物理拦截完成。

退件与库存

到仓观察 → 原单匹配或待认领 → 客户指令 → 授权质检和处置 → 重派、退回或其他 → 费用依据。拆包并入 SKU 库存前由库存权威确认货主、数量与质量。

事件顺序可能迟到或重复：保留原始回执、时间、版本和来源；跨域使用可靠发布、幂等消费和对账，外部动作不承诺端到端恰好一次。
