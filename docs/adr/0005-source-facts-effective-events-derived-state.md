# ADR-0005: 由来源事实形成有效事件并派生状态

Status: Accepted
Date: 2026-07-29

## Context

扫描、人工操作、渠道回传、轨迹和关务响应等来源可能重复、迟到、冲突、无法关联或不满足业务有效性。如果来源输入直接修改包裹或旅程状态，系统会把未经判断的数据当作履约事实，并难以解释和纠正状态变化。

## Decision

系统区分来源事实、有效事件和派生状态。来源事实保留来源及原始业务语义；只有经过适用业务校验并被接受后，才能形成有效事件；业务状态依据当前有效事件和领域规则派生，不作为可以任意独立修改的事实。

更正或有效性变化必须保留与原来源事实和原判断的关系。本决策不指定事件存储、消息传递、状态投影或其他实现技术。

## Consequences

- 每个状态可以追溯到被接受的业务事实，来源噪声不会直接改变业务结果。
- 迟到事实、更正和有效性变化可以触发重新派生，但历史来源和判断依据仍然保留。
- 系统必须建立来源关联、业务校验、重复识别和事件有效性判断能力。
- 状态不再是任意维护的主事实，查询和操作需要同时理解事件与当前派生结果。

## Alternatives considered

- **来源系统直接写入当前状态**：集成简单，但来源质量和语义差异会直接污染核心业务状态。
- **最后一次更新覆盖之前状态**：容易实现，却无法正确处理迟到、冲突和更正。
- **只保存最终状态**：存储最少，但无法审计状态为何形成，也不能可靠重新判断。
