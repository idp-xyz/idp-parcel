# ADR-0006: 场站节点管理小包网络作业而非完整 WMS

Status: Accepted
Date: 2026-07-29

## Context

国际小包运营需要在收货、称重、量方、集包、拆包、分拣、暂存和交接过程中持续掌握包裹及装载单元，但这些操作容易被扩展为以库存为中心的完整仓储管理。系统需要明确专业场站作业与 WMS 的职责边界。

## Decision

国际小包场站节点拥有包裹和装载单元在网络节点内的接收、处理、分拣、集拆、暂存与交接作业，以及与这些作业直接相关的位置和控制关系。

场站节点不建设或拥有以库存为中心的完整收、存、拣、补、盘业务，也不以 WMS 库存模型替代包裹网络流转模型。真实业务同时需要完整仓储管理时，应通过明确边界协作或另行作出领域扩展决策。

## Consequences

- 系统能够专业管理国际小包节点操作，同时保持对包裹网络流转的聚焦。
- 包裹的当前节点、作业区域、暂存位置和控制方不等同于可用库存或仓储账面数量。
- 涉及完整仓储职责的客户场景需要与外部能力协作，不能通过不断增加场站字段隐式吸收。
- 场站与仓储边界需要在集成、权限和异常处理时持续保持清晰。

## Alternatives considered

- **在国际小包系统内建设完整 WMS**：可以覆盖更广场景，但会引入库存、库位、补货和拣选等不同核心模型并显著扩大范围。
- **完全依赖外部系统处理场站作业**：边界最窄，但无法支撑物流企业对分拣、集拆和交接过程的核心运营控制。
- **直接复用 WMS 库存模型表达包裹流转**：表面复用较多，却会混淆暂时控制、网络位置与仓储库存语义。
