# ADR-0001: 国际小包采用自治产品与领域边界

Status: Accepted
Date: 2026-07-29

## Context

自营国际小包网络覆盖客户委托、包裹处理、网络运营、关务、渠道履约和多方结算，其责任主体、业务粒度和生命周期不同于货主运输管理。系统需要在作为既有货主 TMS 的能力扩展、建立统一运输大模型和形成自治产品之间作出选择。

## Decision

国际小包网络运营建设为独立产品和独立项目，并拥有自治的领域模型、领域语言、业务边界和演进路线。既有货主 TMS 的聚合、状态和流程不得作为国际小包核心模型的默认约束；跨产品协作必须通过明确边界表达。

## Consequences

- 国际小包可以围绕包裹、网络节点、渠道和关务建立符合自身责任的模型，而不向货主模型持续增加条件分支。
- 两个产品可以独立确定范围和演进节奏，但跨产品场景需要显式定义语义转换和协作关系。
- 在语义尚未证明稳定一致时允许适度重复，不能为了表面复用提前建立统一大模型。
- 独立产品带来额外的产品治理、文档维护和集成成本。

## Alternatives considered

- **作为货主 TMS 的国际小包能力包**：会把网络经营者责任引入以货主采购和监督为中心的模型。
- **建立覆盖货主和国际小包的统一运输大模型**：短期减少重复，但会混合不同业务粒度、责任和生命周期。
- **独立界面但共享货主领域模型**：只能隔离产品外观，不能消除核心语义冲突。
