# ADR-0300：已按节点登关务区域的租户，不在册对象起讫有一端未登区域时，跨区那一道答「未配置」并指名那个节点；一条区域都没登的租户不变

Status: Accepted（2026-10-25，Claude Code 会话代 CC owner 决：用户 2026-10-20 原话「要我裁定的部分，你作为业务和系统专家，请你自决吧」；票 demo-chain-gaps/147，裁定见代决复核报告 `.scratch/owner-review-20261020/report.md` 的 R12。部分停用 [ADR-0206](./0206-customs-action-admission-judgement-folds-three-sources-and-judges-cross-zone-by-node-customs-zones.md) 决定二一句，回答其越权风险点 12 与 [ADR-0213](./0213-a-transport-handover-declares-its-releasing-receiving-and-onward-nodes.md) 越权风险点 7 声明了去向的那一半，见「对已接受记录的作用」。越权风险点见文末，待 CC owner 复核，TF owner 会签。）<!-- 索引注记 -->｜**判法**：跨区判不出（起讫有一端在动作时点未登区域）时，租户在动作时点至少有一个节点的区域在生效区间内、对象不在任何案件与单元里，跨关务区域移动答`未配置`，依据「节点区域未登记」指名未登的节点（两端都没登就两个都指名）；对象带跨区的门照旧答未配置；其余情形这一道不列——一条区域都没登的租户、在册而不带跨区门的对象、在案未成单元的对象。**登没登过**按动作时点读本上下文的区域册，只在跨区待定时问，问不动答读不动、指名区域那一口；产品不带任何租户名单或默认。**记录**：判断标识照旧由答复与依据派生，这一位不进标识、不迁移。**消费侧**：运输履约照 ADR-0205 决定二把未配置译成未决、依据原文不回设备，段里不在案的对象因此每件都在列，收窄归票 171。**不变**：去向没声明的交出没有节点可指名，跨区那一道照旧不列（ADR-0213 决定四）
Date: 2026-10-25

## Context

- ADR-0206 决定二：起讫有一端在动作时点未登记区域时跨区判不出，此时只看对象带不带跨区的门——带着就答`未配置`并指名未登记的节点，不带「这一道不列」。决定四：对象不在任何案件与单元里时，跨关务区域移动答`未决`，其余受门禁动作答`不受门禁`。
- 两条合在一起，就是 ADR-0206 越权风险点 12「登了区域反而更严」：不在册的对象没有单元可读，读不出它带跨区的门，于是起讫有一端未登区域时这一道不列，整次答复不受门禁；同一次出发两端都登了区域、跨区成立时答未决。做跨境业务的租户漏登一个节点，没立案的跨境包裹从那里出发都读成不受门禁，没有任何信号。ADR-0213 越权风险点 7 是同一类风险在交出上的样子。
- 决定二这样写，是为了不逼没有跨境业务的租户为了不被挡而逐节点登区域（Alternatives「节点未登记时一律答未配置」被否决）。那一条理由只对一条区域都没登的租户成立：一个租户已经为某个节点登了区域，就说明跨关务区域的移动在它那里是真问题。
- 用户 2026-10-20 授权代决；代决复核报告 R12 裁「是」：对已登记过至少一个节点关务区域的租户，不在册对象起讫有一端未登区域时，跨区那一道改答「未配置」并指名未登的节点；纯境内租户不受影响。
- 落点：判断方法在 CC 领域 `crossZoneMatters`（`domain/action_admission.go`）；它的输入是编排读回的区域读数与对象范围；区域册的读口是 `ports.NodeCustomsZoneView`。运输履约的出发、交出与交付读数怎样译关务的`未配置`由 ADR-0205 决定二定好（落`未决`），回给设备的逐对象那一格只列没得出放行的对象（ADR-0237）。

## Decision

**一、跨区判不出时，已按节点登区域的租户的不在册对象答未配置。** 起讫有一端在动作时点未登记区域时，跨关务区域移动这一道这样判：

- 对象带着跨区的门（ADR-0206 决定二原文那一支：某个当前申报单元登了跨区那一道的门禁目录且这一道不是「不受门禁」，或有动作时点有效的限制约束跨区移动）：答`未配置`，指名未登记的节点。不变。
- 对象不在任何案件与单元里，且租户在动作时点至少有一个节点的关务区域在生效区间内：答`未配置`，依据种类「节点区域未登记」（`NODE_ZONE_NOT_REGISTERED`），来源指名未登记的节点，两端都没登就两个都指名。新增。
- 其余情形这一道不列：一条区域都没登的租户；对象在册而单元不带跨区的门；对象在案而未成单元（它的每一道都已答`未决`，不会被放过）。

整次答复按 ADR-0206 决定五的压制次序取最重：新增那一支下整次答复是`未配置`，装载出发或出库那一道照旧答`不受门禁`。

**二、「租户登没登过区域」按动作时点读本上下文的节点关务区域册。**

- 判据：动作时点至少有一个节点的区域版本在生效区间内，半开区间与按节点读区域同一句。区域版本只在换版时落终点，所以这等于「起点不晚于动作时点的登记至少有一行」。
- 按动作时点读，不按此刻：离线补登的动作照它那一刻的登记册判，与区域读数、限制、放行同一时点（ADR-0206 决定一）。
- 只在跨区待定时问。判得出跨区时这一位进不了答复，问了只多一次读、多一处读不动。
- 问不动与读区域不动同一格：`读不动`，指名区域那一口（`NODE_ZONE_VIEW_UNAVAILABLE`），不形成判断。不拿「没登」顶替——那会把跨境租户读成纯境内租户，正是本记录要堵的那一格。
- 不写死：哪个租户算「登过」完全由它自己的登记决定，产品不带任何租户名单、默认或开关。区域取值仍是租户取值（`PAR-CUS-08`）。

**三、判断记录与标识不改形。** 判断标识仍由请求、区域读数、逐动作答复与同格依据派生（ADR-0206 决定六）。「租户登没登过」这一位不进标识、不另成一列：它只在改变答复时才算数，而答复一变标识本就换；没改变答复的那几次（对象在册）重放照答`已有判断`。判断册那一行的依据里记着未登的节点。不迁移。

**四、消费侧不改，现有译法覆盖这一格。**

- 运输履约把关务的`未配置`落`未决`（ADR-0205 决定二），依据种类仍是「节点区域未登记」、来源指名那个节点，随事实落册；回给设备的只有对象与它的格，依据原文不回（ADR-0205 决定一），不新增暴露。
- 出发读数：段的起讫有一端是未登区域的节点、段里对象都不在案时，每件都没得出放行，于是每件都回给执行方——ADR-0237 只收窄得出放行的那几件。这是如实的读数，执行方确实要拿下那几件。问询方可以是任一场外设备、问询不留痕，那一格归 ADR-0237 越权风险点 2 与票 [demo-chain-gaps/171](../../.scratch/demo-chain-gaps/issues/171-gate-previews-are-scoped-to-the-asking-devices-work-and-leave-a-trace.md)，本记录不收。
- 交出读数（ADR-0213 决定四）：声明了去向、去向未登区域时同一判法。没声明去向的交出没有起讫、没有节点可指名，跨区那一道照旧不列，读数照旧写明去向未声明。

三类：决定一、二的判法是产品策略——替所有租户定的判断方法；读区域册、依据的存取是机制；哪个节点在哪个区域、登不登是租户取值（`PAR-CUS-08`），本记录不带默认。

## 候选与反方

- **甲 · 维持 ADR-0206 决定二，不列。** 否决：跨境租户漏登一个节点，没立案的包裹从那里出发读成不受门禁，没有任何信号；登了区域反而更严（ADR-0206 越权风险点 12）。
- **乙 · 节点未登记时一律答未配置，不分租户。** ADR-0206 已否决：逼纯境内租户逐节点登区域，等于产品替租户拟默认。本记录不翻案，只给已经登过区域的租户换判法。
- **丙 · 已登区域的租户，节点未登就一律答未配置，不分对象在不在册。** 否决，越出 R12：对象在册、单元把跨区那一道登成不受门禁时，跨不跨区这一道都答不受门禁，答未配置只多挡一车。单元没登跨区目录的那一格另记越权风险点 2。
- **丁 · 不在册对象跨区待定时答未决，与判得出时同格。** 否决：续办不同。未决等的是立案，这一格要的是有人去登区域——恢复动作不同就分格（ADR-0029）；未决的依据也不指名节点，配置员找不到要登的是哪一个。
- **戊 · 「登过」按此刻读，或按「任一时刻登过」读。** 否决：同一请求的答复会随之后补登的区域漂，离线补登的动作就不是按它那一刻判了。
- **己 · 把「租户登过区域」这一位另存进判断记录并进标识。** 否决：要迁移判断册、改标识派生，存量请求重放会全部换标识；这一位只在改变答复时才算数，而答复变了标识本就会换。代价记为越权风险点 5。
- **庚 · 在案而未成单元的对象也走这一支。** 不扩：那类对象每一道已答未决，不会被放过；单元成形后，单元登了跨区的门就按 ADR-0206 决定二答未配置。代价记为越权风险点 3。
- **辛 · 去向没声明的交出也答未配置或未决。** 不取：没有节点可指名，读数已写明去向未声明，不是静默（ADR-0213 决定四）；要不要把漏报去向当作未决，是交接登记一侧的判法，不在 R12。记为越权风险点 4。

## 对已接受记录的作用

- **部分停用 ADR-0206 决定二一句**：「不带：这一道不列。」——改为：不带时，对象不在任何案件与单元里、且租户在动作时点已有节点登了关务区域，这一道答`未配置`并指名未登记的节点；其余情形这一道不列。**适用场景**：只限跨区判不出时的不在册对象，且租户在动作时点已有节点登了区域。「带着……这一道答`未配置`，并指名未登记的节点。」「这样，没有跨境业务的租户不必为了不被挡而去登区域。」与决定二其余各句不变，决定四、五、六不变。
- ADR-0206 决定四「这包括……以及跨区判不出、跨区那一道按决定二不列的出发——后者整次答复也是不受门禁」不停用：这一道不列时仍是如此，只是不在册对象不列的情形只剩租户一条区域都没登这一种。
- **回答 ADR-0206 越权风险点 12**：取了它写的「另一种判据」（对象不在册且跨区待定时答未配置），加一个租户条件——只对已按节点登区域的租户；纯境内租户不受影响，因而不撞决定二否决的「节点未登记时一律答未配置」。五格与决定四不变，与风险点 12 末句写的改法一致。
- **回答 ADR-0213 越权风险点 7 的一半**：交出声明了去向而去向未登区域时，按决定一作答；去向没声明的那一半照旧，ADR-0213 决定四不变，见越权风险点 4。无条款停用。
- ADR-0205 决定一、二与 ADR-0237 不改，本记录落在它们现有的译法与判法上。ADR-0237 越权风险点 2 写的「票 147 落地之后，起讫有一端是未登区域的节点时同样每件都在列」就是决定四第二条那一格。

## 越权风险点

1. **登了一个节点就要登全**（CC owner、租户）。租户一旦为任一节点登了区域，方向性动作涉及的每个节点都要登，否则不在册的包裹在那一处答未配置，运输履约读成未决，段里不在案的每件都要拿下或转人工。这是 R12 要的结果；代价是上线后新增节点忘登时，读数从「静默放过」变成「每件未决」。只为个别节点登区域试用的租户同样落进这一格。首发判据照旧把节点区域列为上线前确认项（`PAR-CUS-08`，ADR-0206 越权风险点 11）。
2. **在册对象的单元没登跨区目录，仍然放过**（CC owner）。ADR-0206 决定二把「单元没登跨区目录」读作这个范围本没有跨区的门；两端都登了区域、跨区成立时，同一单元那一道答未配置（门禁目录未登记）。所以对已登区域的租户，「在册、单元没登跨区目录、起讫有一端未登区域」仍是登了反而更严的一格。R12 只裁了不在册那一支，本记录不收。owner 若要收：已登区域的租户，跨区待定时单元没登跨区目录也答未配置；五格不变。
3. **在案未成单元的对象不指名节点**（CC owner）。它每一道都答未决（单元未形成），不会被放过，但依据里不出现未登的节点；要等单元成形、单元登了跨区的门才看得到是哪个节点没登。
4. **去向没声明的交出不列跨区**（TF、CC owner）。ADR-0213 越权风险点 7 的另一半照旧：没有去向就没有起讫、没有节点可指名，读数写明去向未声明。漏报去向的跨境交出不会因本记录被拿下。
5. **「登过」这一位不进判断记录**（CC owner）。判断册上看不出一次「不列」是因为租户没登过区域，还是因为对象在册不带跨区的门；要答「当时凭什么不列」，得按动作时点回读区域册。区域册不覆盖、不追改历史区间（ADR-0206 决定三），回读得到；但之后新登的、起点早于那次动作的版本会让回读与当时不同。
6. **每件未决的暴露**（TF owner）。见决定四第二条：问询方能拿到段里每件的标识与「未决」。与 ADR-0237 越权风险点 2 是同一格，收窄归票 171。
