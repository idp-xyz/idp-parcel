# ADR-0008: 试点证据采用自建 MinIO S3 对象存储

Status: Accepted
Date: 2026-07-31

## Context

首发试点需要保存客户合同依据、脱敏映射、外部回执、历史回放数据、验收执行记录和 `Go/No-Go` 决定。这些资料包含客户、伙伴、账号授权和监管信息，不能放入项目文档、源代码仓库、个人文件或邮件中。

当前公司没有可复用的企业级对象存储平台。试点需要一个独立的证据存储边界，具体实施由基础设施责任方负责。

## Decision

为 `idp-parcel` 建设公司自建的 MinIO S3 兼容对象存储，使用逻辑命名空间 `idp-parcel/pilot` 保存试点证据和脱敏映射。物理部署和责任方必须在 `PAR-GOV-11` 中登记后才算就绪。

MinIO 只拥有证据对象的存储和访问边界，不拥有客户、参与方、线路、节点、包裹或其他业务领域对象；项目文档只保存稳定脱敏标识、证据索引、对象版本和受控访问责任，不保存真实映射、账号凭据或受限资料副本。

MinIO 的部署拓扑、运行安全、备份、容量和运维流程不在本 ADR 细化；正式证据启用前由基础设施责任方完成相应实施和核验。平台就绪前，临时存储不能作为正式生产证据的权威源。

## Consequences

- 公司保持证据存储和访问边界的自主控制，不依赖外部文档平台的租户或发布周期。
- 自建 MinIO 的实施和运维责任由基础设施团队承担，具体运行要求在其实施文档中管理。
- 证据索引可以稳定引用对象版本，映射更正和证据替换不会覆盖历史版本。
- MinIO 不得被扩展为 `idp-parcel` 业务数据库或跨上下文业务数据共享通道。

## Alternatives considered

- **托管 S3 对象存储**：运维负担较低，但当前没有可复用平台；本期选择自建以保持部署和访问边界自主可控。
- **企业文档管理平台**：适合人工协作，但本期需要对象版本、稳定索引、审计和留存能力的明确控制，仍需额外验证。
- **项目仓库、个人网盘或临时本地目录**：建设最快，但无法满足受控访问、历史版本、审计和生产证据隔离要求。
