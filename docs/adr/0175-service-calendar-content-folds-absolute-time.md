# ADR-0175：服务日历的截单、处理时长与衔接缓冲按绝对时刻折进时间投影

Status: Accepted（2026-09-30。本项是机制。接受依据是 ADR-0146 决定一、决定七。）
Date: 2026-09-30

## Context

CONTEXT 要求每个节点有业务时区，截单按当地语义，跨节点按绝对时刻比较，计划窗口带节点处理时间与衔接缓冲。目录里日历行此前只有身份和有效区间，没有这三格的形状。ADR-0148 把时间投影划进目录折叠，没有写下这三格怎么存。

## Decision

**一、三格都是分钟，都可空。** 截单是节点本地当日的分钟（0–1439）。处理时长是节点日历上的分钟数。衔接缓冲是连接日历上的分钟数。空是没登记这一格。登记了 0 才是零分钟。不写默认时长，不种租户行。时区仍用节点、连接、线路上已有的业务时区，日历不另存一份。

**二、离开时刻。** 到达的本地时刻早于截单，从到达时刻起加处理时长。不早于截单，则从下一个本地日历日的零点起加处理时长。结果换成绝对时刻。连接登记了缓冲，就加在离开之后、下一节点到达之前。没登记连接日历就不加缓冲，这不是登记了 0。

**三、节点没有可用日历。** 整行缺席，或没有处理时长，这个候选不得到时间投影，路径按不可执行，并点名那个节点。不补一份默认日历。

**四、段链与策略。** 线路的连接序列是候选段链。目录没有责任方列，段的责任引用先指连接版本，不编造法人。策略引用是判断时点适用于该服务目的的那一版路由策略。成本不在这里折。

## 候选与反方

- **没日历就当全天营业。** 那是默认日历。否决。
- **缓冲没登记就当 0。** 0 是租户可以登记的取值。否决。

## Consequences

- 迁移是 `network_routing/0015_service_calendar_content.sql`。
- 初始路由与复核的证据视图从目录折出除成本外的事实。成本缺席时不能形成计划。

## 越权风险点

1. 段的责任引用暂时指连接版本。归 network-routing 的 owner 复核。
2. 错过截单后从下一个本地零点起算，不是从次日截单起算。归 network-routing 的 owner 复核。
