# UC-CC-013 判断动作准入

状态：开发基线已形成；判断方法、节点关务区域登记册与判断记录已交付（[ADR-0206](../../adr/0206-customs-action-admission-judgement-folds-three-sources-and-judges-cross-zone-by-node-customs-zones.md)），真实节点区域取值待提供（`PAR-CUS-08`），生产消费方接线随运输履约出发登记一票

## 目标与边界

本用例从动作执行方在一次方向性动作时（出发还有动作之前的出发前门禁问询，[ADR-0219](../../adr/0219-a-device-previews-the-departure-gate-before-departing-and-reads-what-the-departure-will-record.md)）请求「这个对象此刻能不能做这一步」开始，到 `customs-compliance` 形成并记下一份动作准入判断，或者答未受理、读不动为止。

本用例包含：

- 按动作意图与节点关务区域定适用的受门禁动作；
- 按本上下文自己的申报单元与案件册解析对象的申报范围与程序；
- 逐动作把内部合规限制、放行门禁核对与外部放行结果三源折成封闭答复；
- 按内容派生判断标识记下判断，重放回到同一份；
- 维护节点关务区域登记册。

折法、适用动作与跨区判据的权威在 [CC CONTEXT「动作准入判断」](../../domain/customs-compliance/CONTEXT.md#动作准入判断) 与 ADR-0206，本用例只引用、不复述。

本用例不执行：

- 形成、解除或覆盖内部合规限制（[UC-CC-011](./UC-CC-011-MANAGE-INTERNAL-COMPLIANCE-RESTRICTIONS.md)）；
- 登记放行门禁核对，或发 `customs-compliance.gate-verification.recorded`（[UC-CC-009](./UC-CC-009-RECONCILE-TAX-PAYMENT-RECOVERY-AND-RELEASE-GATE.md)）；
- 接收或解释外部放行结果（[UC-CC-006](./UC-CC-006-RECEIVE-AND-RECONCILE-EXTERNAL-RESULTS.md)）；
- 阻止或撤销已经发生的物理动作——是否照记、怎样标记违规，归动作执行方（ADR-0205，票 demo-chain-gaps/32 起草）；
- 入队任何信封。

|---|---|---|---|
| 对象 | 动作执行方 | 正式包裹引用 | 袋、集运单元由执行方展开成员后逐件问；本上下文不展开 |
| 动作意图 | 动作执行方 | 出发（起点、终点）、交出（所在节点，可带去向）、交付（所在节点） | 不带适用动作；节点按 NR 节点代码 |
| 动作时点 | 动作执行方 | 动作发生或拟发生的业务时刻 | 不以请求到达时刻代替；限制、放行、区域都按它读 |

| 三源 | 限制册、门禁目录与付款核对、放行事实 | 各自既有语义 | 只读；同层冲突的放行不算 |

## 结果语义契约

| 结果 | 业务含义 | 必须返回或可查询的依据 | 禁止行为 |
|---|---|---|---|
| 判断已形成 | 首次在当时三源上形成判断并记下 | 判断标识、逐动作答复与依据、区域读数、跨区判断、判断时刻 | 不得入队；不得写门禁核对册 |
| 已有判断 | 同一请求在同样三源上重放 | 首次记下的那一份（标识与判断时刻不变） | 不得另记一份或改写首次判断时刻 |
| 未受理 | 请求缺坐标 | 无 | 不得折成任何答复格 |
| 读不动 | 某一来源或判断册依赖故障 | 指名哪一口 | 不得用半份三源作答，不得折成未决 |

答复五格的含义与压制次序见 `CC-ADMISSION`。

## 应用流程

1. 受理门：租户、对象、动作意图、动作时点齐全，否则未受理。
2. 按动作时点读意图里起讫节点的区域，定适用动作与跨区判断；跨区待定时同读跨区那一道的门禁，供折叠判「对象带不带跨区的门」。
3. 按对象解析当前申报单元与在案未成单元的程序。
4. 按对象自身与各当前单元读限制；按单元、程序、动作读门禁（与放行门禁核对同一读法）；按单元读放行事实。
5. 领域折叠，形成逐动作答复与整次答复。
6. 按内容派生判断标识并记下；撞上已有记录即答已有判断。

任何一步读不动即停在读不动，不进入下一步。

## 一致性、幂等与并发

- 判断标识由请求、区域读数与逐动作答复和同格依据派生，判断时刻不进标识；动作时点按判断册保存的精度（微秒）入标识。同一请求并发或重放都落到同一行，主键挡住第二份。
- 答复、同格依据或区域读数一变，判断标识随之变，另记一行；旧判断不改。进不了答复的来源变化不换标识（例如限制正挡着时到了一份部分放行），重放答已有判断。
- 判断在自己的事务里记下，不与执行方的写事务合并：执行方在开写事务之前问，执行方那笔回滚时，留下的是一次如实发生过的询问。在执行方事务里问即拒。读不动时判断那一笔回滚，答复照样指名哪一口。

## 验收示例

| 编号 | Given / When | Then |
|---|---|---|
| `AT-CC-411` | 演示租户节点区域已登（上海、深圳在 CN，新加坡在 SG）；SHA→SZX 出发 | 只适用装载出发；跨区判断为同区 |
| `AT-CC-412` | 同上；SZX→SIN 出发 | 适用装载出发与跨关务区域移动；跨区判断为跨区 |
| `AT-CC-413` | 对象不在任何案件与单元里；SHA→SZX 出发 | 装载出发答不受门禁，依据「对象不在关务册内」 |
| `AT-CC-414` | 同上；SZX→SIN 出发 | 跨关务区域移动答未决（范围未解析），整次答复未决 |
| `AT-CC-415` | 对象在出口单元内，跨区门禁满足，动作时点前有一份全部放行 | 跨关务区域移动答放行，依据指回那份放行 |
| `AT-CC-416` | 同上但没有放行 | 答阻断（未取得放行）；门禁满足不答放行 |
| `AT-CC-417` | 同上只有部分放行，另有一份同层冲突的全部放行 | 答未决（只有部分放行）；同层冲突那份不算 |
| `AT-CC-418` | 门禁满足、已全部放行，包裹上有一条动作时点有效、约束跨区移动的限制 | 答阻断，依据指名限制；外部放行不解内部限制 |
| `AT-CC-419` | 限制在动作时点之后才解除 | 仍答阻断；按动作时点判 |
| `AT-CC-420` | 对象在单元内，单元的门禁目录未登记 | 答未配置（门禁目录未登记） |
| `AT-CC-421` | 终点节点未登记区域，对象的单元登了跨区门禁且不是不受门禁 | 跨关务区域移动答未配置，指名未登记的节点 |
| `AT-CC-422` | 终点节点未登记区域，对象不带任何跨区的门 | 跨关务区域移动不列；对象不在册时整次答复为不受门禁（与 `AT-CC-414` 的不对称见 ADR-0206「越权风险点」） |
| `AT-CC-423` | 同一请求在同样三源上重放；或执行方读回微秒精度的动作时点再问 | 答已有判断，标识与判断时刻不变；判断册仍一行；Outbox 无新行 |
| `AT-CC-424` | 门禁目录（含交回折不出结论的认定）、限制册、放行读口或判断册任一读不动，含读口在事务里报 SQL 错误 | 答读不动并指名哪一口；不形成判断；判断册写口拒收这次写入本身（词表外、缺事务）是编程错误，不答读不动 |
| `AT-CC-425` | 同一节点同一起点重登不同区域 | 答内容冲突，不覆盖；换区域走登记更晚起点的新版本 |

## 生产参数与待决风险

- 节点区域取值：`PAR-CUS-08`，演示以 `SYN-ZONE-CN` / `SYN-ZONE-SG` 合成（证据 `S`）。
- 逐件建案等 psb/18：此前演示包裹不在册，演示动线上不出现放行。
- 待决风险以 ADR-0206「越权风险点」为准，此处不复述。
