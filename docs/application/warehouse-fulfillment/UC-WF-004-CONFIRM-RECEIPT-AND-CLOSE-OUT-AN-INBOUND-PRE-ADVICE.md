# UC-WF-004 确认收货并了结入库预报

状态：用例已写成，待实现（PN-09，首发之外的可选能力）；各仓的收货暂存库位、谁有权完结与代录、各项授予待租户提供

## 目标与边界

本用例从仓内作业对一份入库预报确认收货开始，到实收入账、与预报比出的收货差异交到货主手里并得到结论、仓把这份预报完结为止。收货怎样入账、哪些货不入账、收货差异怎样成份与作结论、完结之后怎样，以[仓配履约 CONTEXT](../../domain/warehouse-fulfillment/CONTEXT.md)「入库与加工」与「入库预报」「收货与上架」「收货差异」各条生命周期为准，本用例只组织输入、结果、流程与验收。

本用例解决「到的货实际收了多少、入了谁的账、与预报差在哪」一个问题。收货确认即入账；上架是之后的库内移动，不在本用例。

本用例包含：

- 收货确认：商品入库按商品、计量单位与库存状态收，整箱入库按箱收；一份预报可以分几次收。
- 每次收货与预报比出收货差异：多收、错货、破损。
- 仓以运营决定完结预报，没到的数量记为少收。
- 货主对每一份收货差异作结论：确认或异议；运营可以按货主授权代录，货主本人之后作出的结论取代代录的那一个。
- 收货事实到达时预报已不能收货的，转成待认领到货。
- 货主与运营查阅累计实收与收货差异。

本用例不执行：

- 入库预报的受理与撤回（[UC-WF-003](./UC-WF-003-ACCEPT-INBOUND-PRE-ADVICE.md)）。
- 上架与其他库内移动、待检转良品或次品的状态转换（[UC-WF-007](./UC-WF-007-PUT-AWAY-MOVE-REPLENISH-AND-CONVERT-STOCK.md)）。
- 更正已入账的收货：已入账的流水不改不删，收错了走库存差异与库存调整（[UC-WF-011](./UC-WF-011-RESOLVE-STOCK-DISCREPANCIES-AND-APPROVE-STOCK-ADJUSTMENTS.md)）。
- 开箱时实点与箱单的差额：它同属收货差异，由开箱（[UC-WF-008](./UC-WF-008-PROCESS-AND-RELABEL-GOODS-ON-INSTRUCTION-AND-UNBOX-CARTONS.md)）形成，结论照本用例作。
- 形成入库作业收费发生项：归收费发生项的用例，本用例只留下收货确认这一作业事实。
- 没有预报、认不出预报的到货的登记与认领（[UC-WF-005](./UC-WF-005-REGISTER-CLAIM-AND-DISPOSE-OF-UNCLAIMED-ARRIVALS.md)）。

## 启动条件

- 部署已打开仓配开关（`ADR-OPT` 决定四）。关着时本用例各口不提供业务答复。
- 收货：操作者持这个仓的作业范围授予，设备已登记在用（参数登记册 `PAR-INT-08`、`PAR-INT-10`）。完结与代录：操作者持「入库预报完结」「收货差异结论代录」中相应的运营决定授予（`PAR-INT-08`）。货主作结论：客户端持「收货差异确认」授予（`PAR-INT-13`）。未配置、未授予各答其格。
- 三个面的写都判准入范围（`PAR-INT-11`）；对照没登的租户照各族的规则答不在准入范围。
- 收货暂存库位由租户登记（[UC-WF-001](./UC-WF-001-REGISTER-WAREHOUSES-ZONES-LOCATIONS-AND-PACKAGING-MATERIALS.md)）。代码与迁移不带默认库位；这个仓没登记收货暂存库位时没有可选的库位，收货无处可落。
- 一个仓都没登记的租户：收货事实答查无所指的仓，完结与差异结论答未配置，读口答空（`WF-RULE`，`ADR-OPT` 决定五）。
- 演示租户 `SYN-TENANT-01` 的仓、库位、商品、设备与授予在演示种子里配，证据记 `S`。

## 结果语义契约

| 结果 | 业务含义 | 必须保存 | 禁止推导 |
|---|---|---|---|
| 收货已确认 | 这条事实落册：成立的行以收货流水进入指名的收货暂存库位并形成入库批次，不成立的行如实标出；预报进入或留在收货中 | 事实身份、设备与操作者、发生时间与序号、接收时间、指名的预报与引用的待认领到货、逐行的内容与结果、流水与入库批次的引用、这一次形成的收货差异 | 上架已完成；库存可分配；差异已被货主确认 |
| 已转待认领到货 | 事实到达时预报已取消或已完结：原事实保全为一件待认领到货，不入账 | 原事实的全部内容、到货标识，原预报与货主作线索 | 预报被重新打开；这批货已归某个货主 |
| 已有结果 | 同一事实身份、内容相同的重复到达；已完结的预报再被完结；与现行结论相同的重交（货主本人取代代录结论的那一次除外） | 回显在册结果 | 第二次入账、第二份差异 |
| 内容冲突 | 同一事实身份已在册，这一次的内容与在册的不同 | 无；在册的事实不变 | 覆盖在册的事实；第二次入账 |
| 收货内容不合 | 整条事实不成立，一行都不入账 | 无；逐行指出 | 丢掉坏行、入账其余 |
| 查无所指的仓 | 收货事实指名的仓在本租户没登记；本租户一个仓都没登记时同此 | 无 | 代建仓 |
| 查无此预报 | 指名的预报在本租户查不到 | 无 | 代建预报 |
| 未配置 | 完结或差异结论到达时本租户一个仓都没登记 | 无 | 代建仓 |
| 已完结 | 这份预报收货结束，之后不再收货；有预报了没到的数量，就形成一份记少收的收货差异 | 完结的操作者、时刻与说明；形成的收货差异 | 没到的货被取消；另起了新的预报 |
| 预报状态不符 | 完结时预报不在收货中 | 无；回显当前状态 | 代为撤回 |
| 结论已记录 | 一份收货差异的结论落册，成为现行的结论：差异还没有结论时货主本人或代录的结论，或货主本人取代代录的那一个 | 结论、说明、途径、时刻、来源请求键，代录的操作者与依据引用；被取代的代录结论照留 | 库存账被调整；仓认可了异议 |
| 已有结论 | 与现行结论不同的结论到达，而它取代不了现行的：现行的是货主本人的，或到达的是代录的 | 无；回显现行的结论 | 覆盖 |
| 来源冲突 | 货主口已随一个结论落册的来源请求键，又来指名另一份差异 | 无 | 覆盖在册的结论 |
| 查无此差异 | 指名的差异在这个货主名下查不到；代录指名的差异在本租户查不到 | 无 | 泄露别的货主或别的租户的差异 |

「收货已确认」里每一行有自己的结果：已入账；未入账、认不出的货，记错货；未入账、对不上预报所列未收之箱的箱，记错货；未入账、箱号与在库的重复而没带仓另编的箱号，不形成差异。最后一种，那一箱留在这条事实的逐行结果里，货主在逐次收货的读口看得到它与原因；预报受理之后箱号不改，补正在系统外商定，落到系统里是仓带上另编的箱号再收这一箱：它没入账，仍是预报所列未收之箱。「收货内容不合」是整条事实的结果：行的形态与预报的入库方式不符，预报不在这个仓，认得出的商品的计量单位、批号效期或贴标别名不成立，库位不在收货暂存库区，数量不为正，或引用的待认领到货对不上：它不在已认领，认给的不是这份预报，或这份预报已不能收货（[UC-WF-005](./UC-WF-005-REGISTER-CLAIM-AND-DISPOSE-OF-UNCLAIMED-ARRIVALS.md)）。

信封一层的「发行方未配置」「令牌无效」「未授予」「设备未登记或已停用」「不在准入范围」与坏载荷，作业事实登记面照 ADR-0149 决定二、四，运营决定面照 ADR-0151 决定一、三，客户面照 ADR-0139 决定四作答，不读册、不写册。查阅不判准入范围。货主口指名别的货主的差异，与查无此差异同答。

业务拒绝、未决与技术失败分开：收货内容不合、内容冲突、预报状态不符、已有结论与来源冲突都是已形成的答案；已转待认领到货不是拒绝，是把已经发生的到货照实留下；未配置是租户取值没到，不是拒绝；待货主确认是未决，不改账也不挡后续作业；册读写不动不形成答案，设备与提交方原样重交。

## 应用流程

| 步骤 | 责任方 | 应用动作 | 结果与下一步 |
|---|---|---|---|
| 1 | 仓内作业人员 | 在一线作业端对一份预报清点到货，逐行记下实收，确认收货；设备签发事实身份、发生时间与序号 | 作业事实登记面认证设备与操作者，核作业范围与准入范围 |
| 2 | `warehouse-fulfillment` | 同一事实身份已在册：按这个口的规范化形状比内容 | 内容相同答已有结果，不再入账；内容不同答内容冲突，在册的不变 |
| 3 | `warehouse-fulfillment` | 核指名的仓在本租户已登记；找指名的预报，看它此刻的状态 | 仓没登记答查无所指的仓；预报查不到答查无此预报；已取消或已完结的，把原事实保全为待认领到货，答已转待认领到货（这条事实本来就引用着一件待认领到货的不另建，答收货内容不合） |
| 4 | `warehouse-fulfillment` | 核整条事实：仓、入库方式、库位，认得出的商品的计量单位、批号效期与贴标别名，引用的待认领到货 | 不成立答收货内容不合，整条不落 |
| 5 | `warehouse-fulfillment` | 在同一笔事务里逐行入账：成立的行以收货流水进入收货暂存库位，形成入库批次；认不出的货与对不上预报的箱不入账 | 预报进入或留在收货中 |
| 6 | `warehouse-fulfillment` | 同一笔里与预报比出这一次的多收、错货与破损，成一份收货差异 | 答收货已确认，带逐行结果、形成的差异与这次收到而还没有仓测的（商品，包装层级）与箱 |

## 一致性、幂等与并发

- 收货确认按设备签发的事实身份认重放（ADR-0023），内容按这个口的规范化形状比（ADR-0149 决定四）：同一身份、内容相同的重复到达答已有结果，不追加第二次入账；同一身份、内容不同的答内容冲突，在册的那一条不变。收货内容不合、查无所指的仓与查无此预报的不落册，不占事实身份；已转待认领到货的落了册，重复到达照同一条规则答。
- 一条收货事实的各行在同一笔事务里入账，入库批次与这一次的收货差异同笔形成；任一成立的行落不下，整条不落。
- 同一份预报上的收货、撤回与完结串行判，谁先谁后按到达本上下文的先后（`WF-RULE`），不按设备的发生时间：撤回或完结的答复在迟到的收货事实到达之前已经交出，不能事后改口。迟到的那条事实照实保全为待认领到货。
- 多收按到达先后累计：哪一次收货让某商品的累计实收超过预报，超出的部分记在那一次的差异里。
- 完结的重放身份取被指名的预报：一份预报只完结一次，已完结的再被完结答已有结果。
- 一份收货差异至多一个现行的结论（`WF-RULE`）。差异还没有结论时，货主本人或代录的结论都成立。现行的是代录的结论时，货主本人经客户渠道作出的结论取代它，不论与它相同还是不同，被取代的照留。现行的是货主本人的结论时不再改。除了这一次取代，与现行结论相同的重交答已有结果，不同的答已有结论并回显现行的那一个，不论哪个接入请求；代录不取代任何已有的结论。货主口的来源请求键随成立的结论落册；已落册的键又来指名另一份差异的，答来源冲突。
- 货主本人的结论与代录的结论同时到达，在同一份差异上串行判：代录的先到，货主本人的随后取代它；货主本人的先到，代录的照已有结果或已有结论答。
- 库位在收货事实发生之后被停用，那条事实照记（`WF-RULE`）。识别码与贴标别名按事实发生那一刻的指向与有效区间解析；计量单位是不是已声明的包装层级、跟不跟踪批号与效期，按入账那一刻的当前修订判，修订与收货谁先落照 [UC-WF-002](./UC-WF-002-MAINTAIN-OWNER-GOODS-AND-RECORD-WAREHOUSE-MEASUREMENTS.md) 的先后规则。离线记下的收货因此可能在到达时整条答收货内容不合，比如商品在它发生之后改成了跟踪批号；它不占事实身份，补齐之后可以重交。

## 权限、隔离与审计

- 收货要这个仓的作业范围授予与已登记在用的设备；完结与代录各要自己那一种运营决定的授予；谁持有是租户取值。
- 货主只能对自己客户账户的收货差异作结论，只能读自己的累计实收与差异。
- 代录的每一笔记下录入的操作者与依据引用，不另问 `party-commercial` 的授权裁定（`BD-WF-004`）；依据引用不以明文进日志或指标。
- 货主的读口对每个结论带出途径，代录的另带依据引用，不带录入的操作者；被取代的代录结论照留，货主读得到。
- 认不出的货留下扫到的码或描述与数量，不记到任何别的货主名下：别名不跨货主解析。
- 审计至少关联收货事实、设备与操作者、预报、逐行结果、流水与入库批次、收货差异与它的结论、完结的操作者与时刻。

## 首发试点叠加条件

- 仓配不在首发范围（[ADR-0368](../../adr/0368-commodity-inventory-and-warehouse-fulfillment-join-the-product-as-a-new-context-and-node-operations-stays-non-wms.md) 决定八）；本用例属 PN-09，不进首发试点的任何准入。
- 三个面的写照各族判准入范围。某个租户怎样经 PN-08 的阶段准入启用仓配，`ADR-OPT` 越权风险点 7 留着没定；仓配的写落在治理登记册的哪个对象范围随它一起没有定，本用例不替它定。
- 真实的库位、设备与授予没有时，可以实现收货入账、差异、完结与结论的机制，以及显式的未登记答法与受控 `S`；演示租户的取值只在演示种子里。
