# UC-WF-019 形成仓储作业收费发生项

状态：用例已写成，待实现（PN-09，首发之外的可选能力）；库龄口径、仓的重量体积单位、仓的业务时区与增值服务项目待租户提供

## 目标与边界

本用例从一条作业事实入账，或一个计费日结束开始，到形成仓储作业收费发生项或追加更正版本、并交出信封为止。种类、计量、明细行、业务时间与更正链，以[仓配履约 CONTEXT](../../domain/warehouse-fulfillment/CONTEXT.md)「收费发生项」与 ADR-0377 为准，本用例只组织输入、结果、流程与验收。

本用例解决「这次作业发生了多少，交给计价与结算去要价」一个问题。发生项不带金额。库龄段、免租期、淡旺季与单价不出现在本用例里。

本用例包含：

- 七种作业种类在对应的作业事实上形成。
- 仓租按（货主，仓，计费日）每日一份。
- 更正版本：重述与作废。版本链线性。
- 同一事务交出「仓储作业收费发生项已形成」信封，只带（租户，发生项，版本）。
- 按（发生项，版本）的只读口。

本用例不执行：

- 计价与结算。结算账户没登记由结算答未配置，不挡本用例形成发生项（`WF-RULE`）。
- 代理仓的入库作业、仓租与退货处理。

## 启动条件

- 部署已打开仓配开关。关着时不形成发生项，读口不提供业务答复。
- 仓的业务时区、库龄口径、重量与体积的单位没登记时，要带它们的发生项不形成，答未配置（`WF-RULE`）。
- 一个仓都没登记时不形成，答未配置。

## 输入语义契约

下表是业务语义。计量与属性取自来源作业事实，本用例不另写一套单位换算。

| 输入组 | 权威来源 | 最低业务语义 | 使用约束 |
|---|---|---|---|
| 作业事实入账 | 各作业用例 | 哪一笔事实、发生时刻、货主、仓 | 同一事实至多一份发生项 |
| 计费日结束 | 仓的业务时区 | 货主、仓、计费日 | 同一（货主，仓，计费日）至多一份仓租 |
| 来源事实更正 | 更正那笔事实的用例 | 被更正的事实 | 追加版本，不改写已形成的那一版 |
| 不关联库存的服务 | 货主口或代录 | 项目名、仓、数量 | 项目没登记不形成 |

## 结果语义契约

| 结果 | 业务含义 | 必须留下 | 明确不是 |
|---|---|---|---|
| 已形成 | 一份发生项与信封 | 作业种类、业务时间、该种类词表里的计量、属性、明细行 | 没有金额，也不带收货差异结论 |
| 已重述 | 更正版本，带更正后的全部内容 | 指名被更正的那一版 | 不改旧版 |
| 已作废 | 来源事实判不成立 | 不带计量 | 作废之后还可以再重述 |
| 已有结果 | 同一事实或同一计费日重放 | 回已有的那一份 | 不形成第二份 |
| 未配置 | 口径、单位或时区没登记 | 不形成 | 不补形成登记之前的日子 |
| 未测量 | 重量或体积没测，或仓测单位与登记单位不同 | 标明来源；单位不同的另标明原值与原单位 | 不折算 |

读口按（发生项，版本）答。结算读货主客户账户、仓、作业种类、业务时间与更正关系。计价读计量、作业属性与明细行。发生项不带收货差异结论。

## 应用流程

1. 作业事实入账：按 `WF-RULE` 定种类与业务时间。入库作业的到仓方式取预报上的那一个。建账导入不形成入库作业。
2. 计量、属性与明细行只取 `WF-RULE` 词表里该种类的那一列。属性每份都带，没有的带「无」。同一层面一个计量单位至多一个计量。
3. 仓租由产品内置的日结在计费日结束后形成，取结束那一刻仍在库的。没有手工填写口。晚跑的补跑已结束且当时配置已齐的日子。登记之前的日子不补。
4. 来源事实被更正：追加重述或作废。出库确认被判不成立的，那份出库作业作废。一版至多被更正一次。作废之后可以再重述。
5. 同一事务交信封，只带（租户，发生项，版本）。

## 一致性、幂等与并发

- 同一作业事实重放答已有结果。同一（货主，仓，计费日）重放答已有的仓租。
- 版本链线性。两份更正同时指向同一版，先落的成立，后到的答内容冲突。
- 发生项形成之后不改写（`WF-RULE`）。

## 权限、隔离与审计

- 形成由作业事实触发，不另开一个「手工填写金额」的口。
- 不关联库存的服务：货主提交或代录，完成是运营决定。项目没登记不形成。
- 读口只答本租户。货主看得到自己的发生项，看不见价。

## 首发试点叠加条件

演示租户的库龄口径、重量体积单位、业务时区与增值服务项目在演示种子里配，证据记 `S`。没配时相应发生项答未配置。

## 验收示例

| 编号 | 场景 | 期望 |
|---|---|---|
| `AT-WF-245` | 一次收货确认入账 | 形成一份入库作业发生项。到仓方式取预报上的那一个。业务时间取收货事实发生的时刻。信封只带租户、发生项与版本。不带金额 |
| `AT-WF-246` | 同一笔收货重放；建账导入入账 | 收货重放答已有结果，不形成第二份。建账导入不形成入库作业发生项 |
| `AT-WF-247` | 一个包裹出库确认；自提一次；代理仓交接结果 | 各形成一份出库作业发生项。代理仓的来源事实是交接结果 |
| `AT-WF-248` | 退货入库入账；回库处置执行 | 各形成一份退货处理发生项 |
| `AT-WF-249` | 加工入账；销毁入账 | 各形成一份对应种类的发生项。销毁的来源是 UC-WF-011 那笔入账 |
| `AT-WF-250` | 计费日结束，库龄口径与单位已登记；同一日再跑一次；时区没登记 | 由产品内置日结形成一份仓租，没有手工口。业务时间是该计费日在仓的业务时区里的起始时刻。再跑答已有结果。时区没登记答未配置，不形成 |
| `AT-WF-251` | 库龄口径登记之前的那些日子；登记之后日结晚了两天才跑 | 登记之前的日子不补。晚跑补的是当时配置已齐、已经结束的计费日 |
| `AT-WF-252` | 仓测单位与登记单位不同；此前未测量，后来补测；已有仓测再测一版 | 单位不同的该计量答未测量，并标明原值与原单位，不折算。补测对带着未测量的发生项追加重述。再测一版不更正此前的发生项 |
| `AT-WF-253` | 库位没有库位类型；入库批次上有冻结的数量 | 库位类型带「无」。有无冻结取「有」。在库数量不因冻结减少 |
| `AT-WF-254` | 库存调整更正一笔收货的数量；收货确认被判不成立；出库确认被判不成立 | 对那笔入库作业发生项追加重述。收货或出库确认判不成立的，追加作废，不带计量。回补用的调增不形成入库作业。作废之后可以再重述。调整不以所引收货差异的结论为成立依据 |
| `AT-WF-255` | 商品换标三种；开箱入账但租户没登记「开箱」；登记了「拍照」，货主提交、运营记服务完成 | 换标按所做的那一种形成增值服务，没登记的那种不形成。开箱不形成。拍照在服务完成时形成，不改库存账 |
| `AT-WF-256` | 一个仓都没登记；部署没打开仓配开关 | 都不形成。开关关着时读口不提供业务答复，其他上下文的答复与信封不变（`ADR-OPT` 决定一、四） |
| `AT-WF-257` | 一次收货确认：预报到仓方式是散货，实收有商品也有整箱，重量体积单位已登记 | 形成入库作业。发生项带票、件、箱与到仓方式，不设托与柜型。收货行带件或箱、千克、立方米、库存状态、库存形态、库区用途。千克与立方米不在发生项本身上再带 |
| `AT-WF-258` | 拣货、出库复核与打包入账；随后一个包裹出库确认。另一份在打包前截单并回库，租户登记了「移库」、没登记「拣货」 | 拣货、复核与打包不形成。出库确认形成一份出库作业，带发运方式、服务产品、包材、库存形态。截单不形成出库作业。回库形成增值服务，项目名是「移库」 |
| `AT-WF-259` | 退货入库后从退货暂存良品上架，租户登记了「移库」；另一件处置为销毁并经 UC-WF-011 入账 | 退货入库形成一份退货处理。上架再形成一份退货处理，回库去向是良品上架，不另形成「移库」。销毁只形成销毁 |

## 待确认业务决策

本用例没有新的待确认决策。库龄口径、重量体积单位、业务时区与增值服务项目是租户取值。没登记时该形成的不形成，答未配置，也不补形成登记之前的日子。
