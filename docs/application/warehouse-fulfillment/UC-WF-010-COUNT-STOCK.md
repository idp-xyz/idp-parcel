# UC-WF-010 盘点

状态：用例已写成，待实现（PN-09，首发之外的可选能力）；谁有权发起盘点、各项授予待租户提供

## 目标与边界

本用例从运营创建一份盘点开始，到盘点完成、清点结果与账的差额各成一份库存差异，或盘点被作废为止。盘点何时能开始、作业锁定占什么、清点结果以哪一份为准、差额怎样比，以[仓配履约 CONTEXT](../../domain/warehouse-fulfillment/CONTEXT.md)「盘点、差异与调整」「占用、预占与分配」与「盘点」生命周期为准，本用例只组织输入、结果、流程与验收。

本用例解决「账上说这些库位有这些货，实物是不是这样」一个问题。盘点只比出差额，不改账；差额批不批归 [UC-WF-011](./UC-WF-011-RESOLVE-STOCK-DISCREPANCIES-AND-APPROVE-STOCK-ADJUSTMENTS.md)。

本用例包含：

- 运营创建盘点：仓与所涉库位，可以另限定货主与商品。
- 运营开始盘点：在库存账内原子判定，对所涉库位上范围内的库存加作业锁定。
- 仓内作业按库位录入清点结果。
- 运营完成盘点：逐格比出差额，各成一份库存差异，解除作业锁定。
- 运营作废盘点。
- 运营查阅盘点。

本用例不执行：

- 库存差异的批准与驳回（UC-WF-011）。
- 整箱库存的盘点（`BD-WF-028`）；不加作业锁定的动态盘点（`BD-WF-029`）。
- 待出库库区的盘点：那里的货随拣货与出库确认进出，归出库的用例。
- 把认不出的货入账：清点时看到认不出货主或商品的货只记观察，要入账走待认领到货（[UC-WF-005](./UC-WF-005-REGISTER-CLAIM-AND-DISPOSE-OF-UNCLAIMED-ARRIVALS.md)）或库存调整。
- 向货主公开盘点（`BD-WF-031`）。

## 启动条件

- 部署已打开仓配开关（`ADR-OPT` 决定四）。关着时本用例各口不提供业务答复。
- 盘点的创建、开始、完成与作废：操作者持「盘点」这一种运营决定的授予；查阅要「主数据与运营查阅读」授予（参数登记册 `PAR-INT-08`）。清点结果：操作者持这个仓的作业范围授予，设备已登记在用（`PAR-INT-08`、`PAR-INT-10`）。未配置、未授予各答其格。
- 两个面的写都判准入范围（`PAR-INT-11`）；对照没登的租户照各族的规则答不在准入范围。
- 盘点只对自营仓的库存账；停用的仓与停用的库位照常可以盘（`WF-RULE`）。
- 一个仓都没登记的租户：创建与清点结果答查无所指的仓，开始、完成与作废答未配置，读口答空（`WF-RULE`，`ADR-OPT` 决定五）。
- 演示租户 `SYN-TENANT-01` 的仓、库位、在库库存、设备与授予在演示种子里配，证据记 `S`。

## 结果语义契约

| 结果 | 业务含义 | 必须保存 | 禁止推导 |
|---|---|---|---|
| 盘点已创建 | 一份盘点落册，进入待盘点，所涉库位与范围就此固定 | 盘点标识、仓、所涉库位、范围、说明、决定标识、操作者、时刻 | 库存已被锁定；可用量已变 |
| 盘点内容不合 | 所涉库位或范围不成立 | 无；逐项指出 | 丢掉不成立的库位、受理其余 |
| 盘点已开始 | 进入盘点中：所涉库位上范围内的库存加了作业锁定 | 开始的操作者与时刻、加了作业锁定的各格与数量 | 库存账变了；冻结着的数量也被作业锁定占了 |
| 盘点不能开始 | 所涉库位上还有未完成的拣货任务；加作业锁定会违反占用规则；或所涉的库存已在另一份盘点中的盘点里（`WF-RULE`） | 无；指出哪一种与哪个库位 | 让一部分库位先开始；挤占已成立的预占 |
| 清点结果已登记 | 一个库位的清点结果落册；这个库位现行的一份按发生次序取最后一份 | 事实身份、设备与操作者、发生时间与序号、接收时间、库位、各行与观察 | 差异已形成；库存账已变；后到的一份就是现行的一份 |
| 已盘点 | 盘点完成：各格实点与账的差额各成一份库存差异，作业锁定解除 | 完成的操作者与时刻、各库位所用的那一份清点结果、形成的库存差异 | 账已改；差异已批准 |
| 清点未齐 | 完成时还有所涉库位没有清点结果 | 无；列出还缺的库位 | 没清点的库位按零或按账算 |
| 盘点已作废 | 不形成差异，解除已加的作业锁定；已登记的清点结果照留 | 作废的操作者、时刻与原因 | 清点结果被删了 |
| 盘点状态不符 | 开始时盘点已盘点或已作废；完成时不在盘点中；作废时已盘点；清点结果到达时盘点不在盘点中 | 无；回显当前状态 | 重新打开盘点；补收清点结果 |
| 作业内容不合 | 整条清点结果不成立 | 无；逐行指出 | 丢掉坏行、登记其余 |
| 已有结果 | 同一决定标识或同一事实身份、内容相同的重投；盘点中的再被开始；已盘点的再被完成；已作废的再被作废 | 回显在册结果 | 第二份盘点、第二次加锁、第二批差异 |
| 来源冲突 | 同一决定标识、内容不同 | 无 | 覆盖在册的盘点 |
| 内容冲突 | 同一事实身份已在册，这一次的内容与在册的不同 | 无；在册的清点结果不变 | 覆盖在册的清点结果 |
| 查无此盘点 | 指名的盘点在本租户查不到 | 无 | 泄露别的租户的盘点 |
| 查无所指的仓 | 创建或清点结果指名的仓在本租户没登记；本租户一个仓都没登记时同此 | 无 | 代建仓 |
| 仓不受理 | 创建指名的仓是代理仓 | 无 | 改盘别的仓 |
| 未配置 | 开始、完成或作废到达时本租户一个仓都没登记 | 无 | 代建仓 |

「作业内容不合」是整条清点结果的结果：仓不是盘点的仓，库位不在这份盘点所涉的库位里，行里的商品没登记或不在盘点的范围里，计量单位、批号效期或贴标别名不成立，库存状态与库位所在的库区不相容，同一格列了两行，数量为负。

信封一层的「发行方未配置」「令牌无效」「未授予」「设备未登记或已停用」「不在准入范围」与坏载荷，运营决定面照 ADR-0151 决定一、三，作业事实登记面照 ADR-0149 决定二、四作答，不读册、不写册。查阅不判准入范围。

业务拒绝、未决与技术失败分开：盘点内容不合、盘点不能开始、清点未齐、盘点状态不符、作业内容不合、内容冲突与来源冲突都是已形成的答案；盘点不能开始与清点未齐之后盘点留在原状态，情形消失后可以再来；未配置是租户取值没到，不是拒绝；册读写不动不形成答案，设备与提交方原样重交。

## 一致性、幂等与并发

- 创建按调用方给的决定标识认重放：同一标识、内容相同答已有结果，内容不同答来源冲突。开始、完成与作废的重放身份取被指名的盘点：一份盘点只开始一次、只完成一次、只作废一次，盘点中的再被开始、已盘点的再被完成、已作废的再被作废都答已有结果。
- 开始在库存账内原子判定（`WF-RULE`），与预占、冻结、别的盘点的开始和所涉库位上的入账串行：争同一批库存的两份盘点只开始一份，另一份答盘点不能开始。整份开始或整份不开始，不让一部分库位先开始。
- 作业锁定与冻结、预占互不重叠（`WF-RULE`）：它只占所涉库位上范围内没被冻结的库存，不挤占已成立的预占。盘点中这些库存不被库内的入账取走，各用例各有答法（[UC-WF-007](./UC-WF-007-PUT-AWAY-MOVE-REPLENISH-AND-CONVERT-STOCK.md)、[UC-WF-008](./UC-WF-008-PROCESS-AND-RELABEL-GOODS-ON-INSTRUCTION-AND-UNBOX-CARTONS.md)、UC-WF-011）。
- 清点结果按设备签发的事实身份认重放（ADR-0023），内容按这个口的规范化形状比（ADR-0149 决定四）。同一库位可以有几份清点结果，现行的是发生次序最后的那一份，此前各份照留。作业内容不合、盘点状态不符、查无此盘点与查无所指的仓的不落册，不占事实身份。
- 清点结果到达时盘点须在盘点中，按到达本上下文的先后判，不按设备的发生时间：盘点开始之前记下的清点，完成或作废之后才到的清点，都答盘点状态不符。
- 完成、差异的形成与作业锁定的解除在同一笔事务里。实点取各库位现行的那一份清点结果，账取完成那一刻那一格各入库批次之和（`WF-RULE`）。
- 盘点中移入所涉库位的作业事实照记（UC-WF-007），清点之后才入账的货因此会让差额失真。本用例不自动剔除：各份差异的读口带出那一格自盘点开始以来的入账流水，交批准的人判断（`BD-WF-030`）。
- 完成之后清点结果不再收，差异形成后不改写；要重盘，另建一份盘点。

## 权限、隔离与审计

- 盘点的四种决定同属一种运营决定「盘点」，清点结果要这个仓的作业范围授予与已登记在用的设备；谁持有是租户取值。
- 盘点只在操作者面、按租户隔离；一份盘点可以涉及几个货主的货，各格的差异各记在自己货主的账上。货主经库存的读口（[UC-WF-009](./UC-WF-009-FREEZE-AND-UNFREEZE-STOCK-AND-READ-STOCK-HOLDS-AND-MOVEMENTS.md)）看到作业锁定占着多少。
- 清点的操作者随清点结果记下：批准盘点差异时，照批准职责规则比的就是他（UC-WF-011）。
- 审计至少关联盘点、仓、所涉库位与范围、开始、完成与作废各笔的操作者与时刻、各份清点结果与它们的设备和操作者、形成的库存差异。

## 首发试点叠加条件

- 仓配不在首发范围（[ADR-0368](../../adr/0368-commodity-inventory-and-warehouse-fulfillment-join-the-product-as-a-new-context-and-node-operations-stays-non-wms.md) 决定八）；本用例属 PN-09，不进首发试点的任何准入。
- 两个面的写照各族判准入范围。某个租户怎样经 PN-08 的阶段准入启用仓配，`ADR-OPT` 越权风险点 7 留着没定；仓配的写落在治理登记册的哪个对象范围随它一起没有定，本用例不替它定。
- 真实的库位、设备与授予没有时，可以实现开始时的原子判定、清点结果的保全与完成时比出差额的机制，以及显式的未登记答法与受控 `S`；演示租户的取值只在演示种子里。

待定格按三类归：

- 机制：盘点的生命周期、开始时的原子判定与作业锁定、清点结果的保全与现行的那一份、完成时逐格比出差额、作废。现在做完。
- 产品策略：静盘；只盘商品库存；差额逐格比、不比入库批次；所涉库位都有清点结果才能完成；待出库库区不在盘点范围；`BD-WF-028` 至 `BD-WF-031` 的当前建议。随产品内置。
- 租户取值：谁持有「盘点」授予与仓的作业范围授予。留空；没有授予照各族的答法。
