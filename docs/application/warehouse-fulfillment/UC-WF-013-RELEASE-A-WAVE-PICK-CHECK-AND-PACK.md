# UC-WF-013 波次分配、拣货、复核与打包

状态：用例已写成，待实现（PN-09，首发之外的可选能力）；分配策略是否采用、预取面单所需的三格授予与各项作业授予待租户提供

## 目标与边界

本用例从一份已预占的出库请求被放进波次开始，到拣货移入待出库库区、出库复核通过并打包、写下装箱记录为止。分配不超过预占、拣货怎样入账、已拣出的预占还算不算占用、复核不符与破损怎么办、出库前的贴标走不走指令，以[仓配履约 CONTEXT](../../domain/warehouse-fulfillment/CONTEXT.md)「出库请求与发出」「占用、预占与分配」与「出库请求」「装箱记录」生命周期为准，本用例只组织输入、结果、流程与验收。

本用例解决「占住的货怎样拣出来、核对、装成包裹」一个问题。委托的提交与出库确认不在本用例。

本用例包含：

- 波次释放时分配，生成拣货任务。是否预取面单由这一次作业选择。
- 拣货：按分配移入待出库库区。实拣不足形成库存差异。
- 出库复核。不符不打包。破损的转为次品并离开待出库库区。
- 带贴标别名条件、从未经贴标库存取出的，在复核之前贴上。
- 打包：称重量方，记装箱记录。

本用例不执行：

- 受理与预占（[UC-WF-012](./UC-WF-012-ACCEPT-AND-RESERVE-AN-OUTBOUND-REQUEST.md)）。
- 以货主名义提交、补充、撤回委托（[UC-WF-014](./UC-WF-014-ACT-FOR-THE-OWNER-ON-A-WAREHOUSE-OUTBOUND-SHIPMENT.md)）。预取面单时，本用例只决定这一波要不要预取；提交那一笔归 UC-WF-014。
- 出库确认与截单。
- 待出库库区之外的上架、移库与商品换标指令（[UC-WF-007](./UC-WF-007-PUT-AWAY-MOVE-REPLENISH-AND-CONVERT-STOCK.md)、[UC-WF-008](./UC-WF-008-PROCESS-AND-RELABEL-GOODS-ON-INSTRUCTION-AND-UNBOX-CARTONS.md)）。

## 启动条件

- 部署已打开仓配开关。关着时各口不提供业务答复。
- 分配策略没采用答未配置，不分配（`WF-RULE`）。
- 预取只在三格都已登记时可选：仓配代办与资料修订的代办授予、接单规则包允许该阶段修订声明测量、包裹取消的授权规则已登记。任一格未配置即不预取（`WF-RULE`）。
- 一个仓都没登记的租户，放波次与拣货答未配置（`ADR-OPT` 决定五）。
- 未完成的拣货任务，指还没记完成、也没因出库截单撤销的那一份。盘点能不能开始照这一句（UC-WF-010）。

| 结果 | 业务含义 | 必须留下 | 明确不是 |
|---|---|---|---|
| 已分配 | 预占落到库位与入库批次，生成拣货任务 | 分配合计不超过预占 | 货还没离开原库位 |
| 已拣货 | 各拣货任务完成，货在待出库库区 | 库内移动流水；已拣出的预占不再计入占用之和 | 预占要到出库确认才消耗 |

## 应用流程

1. 放波次。策略没采用则答未配置。分配不超过所属预占，顺序照租户采用的策略（`WF-RULE`）。
2. 拣货事实到达。取得走的按分配入账，移入待出库库区。不足的部分撤销分配、保留预占，差额成库存差异，批准在 UC-WF-011，以调减或调增在差异所在的格入账，不从源头补入账。
3. 同一源头数量上若已有待处理的补入账，本用例仍照记拣货差额。两份里先批准的那一份入账，后一份不成立（`WF-RULE`）。分配已经随补入账改到新格的，未完成的拣货在新格拣。
4. 出库复核。不符不打包。破损的按 `WF-RULE` 转次品。该贴的标没贴完，不出复核。
5. 打包写下装箱记录。本产品网络的包裹由此交给 UC-WF-014 提交；这一波选了预取的，在放波次时就已经交给它按一个包裹提交。

## 一致性、幂等与并发

- 拣货、复核与打包按设备签发的事实身份认重放。相同答已有结果，不同答内容冲突。
- 放波次按调用方给的波次标识认。
- 分配与预占在库存账内串行判。拣货消耗的是自己那份分配，不挤占别的占用（`WF-RULE`）。

## 权限、隔离与审计

- 作业事实只接受持有该仓作业范围的设备。
- 放波次是运营决定，要有相应授予。没有答未授予。
- 货主在流水读口看得到拣货与贴标的移数，看不见波次本身。

演示租户的分配策略、包材与授予在演示种子里配，证据记 `S`。策略没采用时放波次答未配置。

## 待确认业务决策

本用例没有新的待确认决策。分配策略采用哪一份、预取所需的三格、波次按什么归组，是租户或当次作业的取值。没采用、没登记时答未配置，不预取。
