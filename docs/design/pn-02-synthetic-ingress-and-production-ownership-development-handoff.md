# IDP Parcel PN02-S02 合成来源保全与生产归属开发交接

状态：合成验证交接；不代表真实接入、客户、线路或生产权威已经确认

## 目的

当前没有真实客户、合同、账号、线路、请求或交易数据。本切片用隔离的 SYN-ING-* 夹具验证小包请求从接入到“是否允许进入本产品”的最小业务链路：

1. 先保全不可覆盖的原始来源和请求身份。
2. 对完整拟受理范围形成版本化生产归属判断。
3. 验证“只有本产品取得当前唯一生产权威时，未来才允许建立 parcel-shipment 最小委托”的建单门禁。
4. 其他权威或归属未决时，只保留中立关联和可续办处理，不创建客户接受/拒绝决定。

本切片不重新定义生产归属规则；长期规则以 PN02-W02、UC-PS-001 和领域上下文地图为准。

## 为什么单独建立合成切片

PN02-W02 要求真实入口、范围、权威交接和治理证据；这些事实目前不存在。直接用“示例客户”跑通会把样例误写成生产参数，或者把技术回执误当成业务归属。合成切片因此只提供开发可重复的输入和结果契约，明确结果层级为隔离 S，不改变参数登记册和正式验收矩阵。

当前开发闸门仍以 PN02-W02 为准：只允许维护建单前强类型作用域、来源保全输入、重复/冲突分类、最小候选和命名场景；不得创建生产归属端口、ShipmentRequest/“已提交”聚合、接受判断任务、领域事件、Repository、事务或 Outbox。本切片中的“允许建单”只表示未来门禁语义，不表示当前可以落地这些对象。

## 术语与结果边界

**来源记录**：接入边界收到的原始内容或不可变引用、来源身份、来源请求标识、`occurredAt`、`receivedAt` 和关联信息。两类时间是信封元数据，不进入规范化业务内容摘要；来源记录不是委托。

**来源请求身份**：由 `TenantID`、`CustomerAccountID`、`Source` 和 `SourceRequestKey` 组成的完整复合键。它只用于来源重放与冲突分类，不是调用者授权身份，也不是委托或包裹业务身份；查询不得省略其中任一段后跨作用域回退。

**授权作用域结果**：由共享身份认证/授权技术能力已经判断并传入的、带版本或引用的可见范围结果。`parcel-shipment` 只消费该结果并执行本上下文的对象范围校验，不拥有企业身份主数据、凭据验证或通用授权策略。

**统一不可见语义**：对象不存在、对象属于其他租户/客户或调用者没有查询授权时，对外返回同一 `NOT_FOUND_OR_NOT_VISIBLE` 类别；不得暴露对象存在、原始内容、范围、客户名称、来源、冲突状态或其他租户信息。

**完整拟受理范围**：本次请求声明的客户账户、责任法人、服务产品/合同、线路或服务范围、时间窗口、容量边界以及全部包裹成员。归属判断必须覆盖完整范围，不得按成员随机拆分。

**生产归属判断**：治理规则对“当前谁是该范围唯一生产写入方”的结果。它不是客户接受、拒绝、承诺、收寄或运输事实。

**安全交接**：目标权威确认承接同一完整范围，并能查询交接结果、避免重复解释请求身份；单纯转发或技术成功不构成交接。

### 生产归属的两个维度

生产归属判断同时保存两个维度：

- **权威身份**：本产品当前唯一权威、其他当前唯一权威或生产归属未决。
- **准入门禁**：当前没有生效暂停（`OPEN`），或因版本化硬风险规则处于暂停（`PAUSED`）。`OPEN` 只表示没有主动暂停，不等于最终允许建单；最终“未来可放行”还要同时满足本产品是当前唯一权威、范围与当前修订仍匹配且判断仍在有效区间内。

“暂停是生产归属结果”表示治理记录必须包含这两个维度，不表示暂停是第四种权威身份。暂停可以阻断本产品的新准入，但不改变已经形成的权威身份、在途责任或历史归属。

### 三类归属判定语义

| 结果 | 后续动作 | 禁止行为 |
|---|---|---|
| 本产品当前唯一权威（合成） | 在门禁为 `OPEN` 且范围/修订/有效期仍匹配时记录未来建单可放行；当前只返回合成判定及依据 | 当前不得创建委托/任务，也不得宣称已接受、已拒绝、已承诺、已收寄或已分配容量 |
| 其他当前唯一权威（合成） | 保留中立来源/归属关联，验证安全交接和查询语义 | 不得在本产品建立委托，不得同时投递多个生产系统 |
| 生产归属未决（合成） | 保留范围、缺口、尝试和续办入口 | 不得默认归入本产品、伪装成客户拒绝或以技术成功代替决定 |

以下处理结果与三类归属分开：

- 输入未受理：无法建立最小请求身份或完整范围；只形成接入处理记录，不创建占位委托。
- 准入暂停：治理规则暂时阻断新准入；不是客户拒绝，也不改变已经纳入的在途对象或此前权威身份。
- 接入冲突：同一请求身份携带不同内容摘要、范围或基础版本；原来源和原结果不得覆盖。`occurredAt` 和 `receivedAt` 是独立信封元数据，变化本身不形成冲突；`requestEffectiveAt` 如属于声明内容，必须把值及缺失/显式存在状态纳入规范化 `PayloadDigest` 后再判断，不能用任一信封时间默认补齐。

### S02-W06 来源与客户隔离契约

合成夹具至少包含两个租户、每租户两个客户账户，以及同一客户账户下的两个不同来源。每条来源记录的索引键必须完整包含 `TenantID + CustomerAccountID + Source + SourceRequestKey`：

- 相同外部键跨租户、跨客户或跨来源均为不同来源身份，不能复用另一条来源、重放结果、归属结果或门禁结果。
- 只有完整来源身份和摘要同时相同，且调用者的授权作用域覆盖该租户和客户账户时，才能返回原结果关联；同客户不同来源也不得通过“查任一来源”回退到另一条结果。
- 未授权查询与真实不存在查询必须返回完全相同的 `NOT_FOUND_OR_NOT_VISIBLE` 结果，不带对象引用、内容摘要、范围、客户名称、来源、冲突/归属状态或结果数量。
- 授权查询只能看到其授权租户/客户范围内的对象；批次内部可以归组不同客户，但客户回执、结果数量和查询不得暴露其他客户是否存在或处理结果。
- 合成日志和证据索引只允许保留作用域引用、对象引用、结果类别、版本、判断时间和证据索引；不得记录原始请求键、客户原文、地址、货物、申报内容、凭据或其他租户标识。

每次执行须登记夹具版本、范围版本、归属规则版本、判断 asOf、有效区间、当前修订、来源摘要、目标权威确认（如有）、处理结果和隔离证据索引。合成通过只记为 S。

## 业务流程契约

| 步骤 | 责任方 | 必须形成 | 失败/未决语义 |
|---|---|---|---|
| 1. 接收 | 接入适配器 | 来源记录、请求身份、原始内容/不可变引用、来源和系统时间 | 无法保全时不得继续形成业务决定；保留技术处理失败和重试关联 |
| 2. 归一化 | 接入适配器/接入编排 | 最小客户范围、完整拟受理范围、成员摘要和请求内容摘要 | 缺少最小身份为输入未受理，不创建占位委托 |
| 3. 去重/冲突 | 接入编排 | 同键重放或冲突判断及依据 | 同内容查询原结果；不同内容形成接入冲突 |
| 4. 归属判断 | 试点准入控制 | 三类归属之一，或受控暂停/未决结果 | 规则失效、权威不唯一、交接失败均不得默认选择 |
| 5. 安全交接 | 试点准入控制与目标权威 | 完整范围、目标确认、查询关联和生效边界 | 目标未确认或不可查询保持未决；不双写 |
| 6. 验证建单门禁 | 接入编排 | 只有“本产品当前唯一权威（合成）”且门禁为 `OPEN`、范围/修订/有效期仍匹配时返回未来可放行语义；其他结果全部阻断并保留具体原因 | 当前开发闸门禁止实际形成委托、提交版本、声明包裹、接受判断任务或事件 |

来源保全与未来建立已提交委托是两个业务边界。前者成功不能推导后者；合成门禁可放行也不能证明“已提交”已经发生，更不能推导接受、拒绝、收寄、路由、关务或计费结果。

## 并发、重试和恢复

- 同一请求身份、相同规范化内容摘要和相同业务范围的重试必须返回原处理关联；即使 `occurredAt`/`receivedAt` 不同也仍是重放，只追加本次观察；查询不到原关联时先进入未决，不创建第二份业务对象。
- 同一请求身份携带不同内容摘要、范围或基础版本时，形成冲突记录；纠错必须产生新来源版本或新请求身份，原事实不可覆盖。`occurredAt` 和 `receivedAt` 变化不改变内容摘要；`requestEffectiveAt` 若属于客户声明内容，必须由接入适配器把值及缺失/显式存在状态纳入规范化摘要，领域层不对信封时间字段单独比较。
- 归属判断与未来建立已提交之间若规则、范围、暂停状态或权威修订失效，必须重新判断；无法重判则保持未决。
- 目标权威返回超时、重复、部分范围确认或冲突时，不能把技术回执当作完整交接；只保留尝试和待续办关系。
- 暂停只阻断新准入；恢复必须有原因解除、一致性核对、在途盘点、有权决定和新的归属修订，不能因健康检查恢复或证据齐备而自动放量。恢复准备度只允许提交显式恢复决定，不把旧暂停原地改成 `OPEN`。
- 发布版本回退不改变业务权威。运营回退或对象级接管必须先暂停新准入、停止原范围新写入，再固定对象/能力/事实类型、生效边界、新权威、在途和未完成责任盘点；准备度通过也不等于权威已经转移，仍须形成新的有效归属决定。不双写、不盲目重提外部指令、不改写交接前历史。

### 当前 Go 纯领域交付

`internal/parcelshipment/domain/production_ownership.go` 只提供合成验证所需的不可变值对象和纯函数：

- `AdmissionScope`：完整拟受理范围的不可变引用与独立摘要，不复用 `PayloadDigest`。
- `ProductionOwnershipDecision`：保存权威身份、`OPEN/PAUSED` 控制、规则版本、`asOf`、判断时间、有效区间和当前修订；`OTHER`、`UNRESOLVED`、`PAUSED` 的条件证据由构造器校验。
- `EvaluateFutureSubmissionGate`：返回带原始决策和结构化阻断原因的 `ALLOWED/BLOCKED` 结果。只有 `IDP_PARCEL + OPEN` 且范围、修订和有效期匹配时才可放行。
- `SafeHandoffAssessment`：纯函数消费离线交接观察；完整范围确认且结果可查询时才返回 `CONFIRMED`，范围不一致、部分确认、超时、查询不可用或失败均返回带结构化原因和续办引用的 `UNRESOLVED`。
- `production_governance_contract_test.go`：只在测试侧表达恢复和接管准备度，证明证据齐备不等于状态已改变；不向生产包增加治理聚合、暂停开关、接管服务或迁移代码。
- `source_isolation_contract_test.go`：只在测试侧表达完整来源复合键、授权作用域、统一不可见查询结果和最小审计投影；不提供生产查询端口、IAM、共享结果表或日志平台。
- `SYN-ING-10` 通过输入边界成立：归属决定和未来建单门禁不接收装袋、换袋、外部标识或实际改路作为修改输入；这些事实无需也不得新增“归属更新”接口。只有新的版本化治理决定可以形成新归属修订。

该交付不创建生产归属端口、`ShipmentRequest`、接受判断任务、领域事件、Repository、事务或 Outbox；所有测试仍是隔离 `S`。

| S02-AT-05 | 交接不完整或失败 | 保持未决，可查询和续办，不写客户拒绝 |
| S02-AT-06 | 最小身份缺失 | 形成输入未受理，不创建占位委托/任务 |
| S02-AT-07 | 暂停与恢复 | 权威身份保持不变，暂停阻断新准入；无显式恢复证据仍阻断，在途不受影响 |
| S02-AT-08 | 回退与接管 | 原权威停止新写入，范围和责任交接可审计，无双写 |
| S02-AT-09 | 归属后物理/外部变化 | 合成归属判定成立后，装袋、换袋、换号、改路不改变权威身份 |
| S02-AT-10 | 来源与客户隔离 | 相同外部键跨租户/客户/来源不能复用结果；未授权与不存在返回统一不可见语义；授权查询只返回自身范围；日志和证据仅含最小审计字段 |

## 开发禁止项

- 不把生产归属、客户接受、客户拒绝、技术回执或消息发送成功压成一个布尔值。
- 当前无论合成结果为何，都不创建 parcel-shipment 委托、接受判断任务、“已提交”事件、Repository、事务或 Outbox；只有真实 W02 证据和后续端口评审通过后才能解除。
- 不用成员抽样或随机拆分来规避完整范围的归属判断。
- 不将接入适配器、旧系统、渠道账号或转发成功自动视为当前生产权威。
- 不以客户级默认系统、容量默认值或当前可用性补齐缺失的归属规则。
- 不为了合成验证向真实客户、履约、关务、支付或财务端点发送请求。
- 不把来源请求身份当作查询授权，不实现通用身份认证、授权引擎、跨客户查询层或共享业务结果表。

## 证据和准入结论

本切片完成只能说明建单前来源/归属业务契约具备可重复的合成证据，不能解除 PN02-W02 对生产归属端口和“已提交”实现的阻断。真实 PAR-INT-01、PAR-GOV-03..07、客户/合同/线路范围和生产接入证据仍待提供；生产结论保持 No-Go / 待参数化。合成场景不能更新参数登记册、验收矩阵状态或 PN-08 阶段决定。
