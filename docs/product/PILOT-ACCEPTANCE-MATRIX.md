# 首发试点验收场景矩阵

状态：矩阵结构与稳定场景已确认，试点实例参数和执行证据待填

本文档把[首发试点范围](./PILOT-SCOPE.md)中的范围原则和[核心端到端领域场景](../domain/SCENARIOS.md)转化为可执行的验收清单。它只规定如何证明首发试点满足已确认规则，不重新定义产品或领域规则；发生冲突时，以产品基线、试点范围、领域上下文和 ADR 为准。

## 证据与判定规则

### 证据层级

| 代码 | 证据层级 | 使用规则 |
|---|---|---|
| `P` | 真实生产 | 来自真实客户、合同、线路和生产配置，或来自明确纳入限量生产范围的真实委托、真实账期及真实外部协作。正常主链路不得用模拟结果替代。 |
| `R` | 历史数据回放 | 使用来源可追溯的脱敏历史事实校准基线、重放规则和派生结果，不产生新的外部业务指令或真实金额。 |
| `S` | 受控模拟 | 使用与生产账本和外部生产渠道隔离的合成数据、正式测试环境或受控测试账户。不得形成真实申报、履约、通知、费用或资金事实。 |
| `N/A` | 本期不适用 | 仅适用于已经明确排除或经证据证明不适用于锚点线路的场景，必须记录依据和决定方，不能用空白代替。 |

表中“`P`；未自然发生时 `R/S`”表示真实发生时必须采用生产证据，但不得为了验收主动制造高风险或不可逆结果；未自然发生时按记录的依据选择历史回放或受控模拟，并把未验证的外部行为列为剩余风险。

计划证据中的 `+` 表示多个证据层级都必须覆盖，`/` 表示按已批准的场景条件选择其中一种；分号后的文字表示条件分支。每条实际执行记录仍只标记一个主要证据层级，并通过同一场景 ID 关联其他执行记录组成完整证据包。

### 验收门槛

| 门槛 | 含义 |
|---|---|
| 阻断 | 未通过时不得正式验收。硬风险、客户隔离、权威事实、审计完整性、硬合规或授权问题，以及无法解释或破坏账实平衡的差异始终属于阻断项。 |
| 条件阻断 | 能力或场景纳入生产范围时按阻断项处理；未纳入时必须完成规定的 `R`、`S` 或 `N/A` 证据及剩余风险记录。 |

非关键偏差只有在明确影响范围、临时控制、责任方、计划关闭时间、剩余风险和试点业务责任角色的风险接受决定后才能保留。风险接受不能改变上面的阻断规则。

### 责任与执行记录

- “证据责任”表示提供和核实证据的业务职能，不预设岗位名称、人事职级或必须多人联签。
- 每个阶段升级、范围扩大和正式验收仍由责任法人指定的试点业务责任角色作出 `Go/No-Go` 决定。
- 每次执行记录必须包含矩阵版本、场景 ID、对象与能力范围、稳定脱敏标识、受控映射或证据索引版本、证据层级、数据来源和时间范围、是否真实验证外部参与方行为、执行人与复核方、结果、偏差、剩余风险及证据位置；共享记录不得用真实客户、线路或伙伴名称替代脱敏标识。
- 正式验收的证据位置必须指向 `PAR-GOV-11` 登记的自建 MinIO S3、`idp-parcel/pilot` 逻辑命名空间及稳定对象版本；项目仓库、个人持有文件、邮件或临时链接不能成为权威证据源。
- 场景状态只能使用：`待参数化`、`待执行`、`执行中`、`通过`、`未通过`、`风险接受` 或 `本期不适用`。证据未齐全时不得标记为通过。

## 完成条件

正式验收前必须同时满足：

1. 所有阻断场景已经使用规定层级的证据通过，且不存在尚未解除的硬风险。
2. 所有条件阻断场景已经通过适用证据，或以 `N/A` 明确记录本期不适用依据；不得保持未分类。
3. 正常端到端主链路和一个真实账期已通过真实生产验证，模拟结果不能替代。
4. 未自然发生的高风险分支已经使用允许的 `R` 或 `S` 验证，未验证的外部行为已经列入剩余风险与后续监控。
5. 全部在途委托已完成逐项盘点，正式验收决定不会改变其生命周期、生产归属或后续处理责任。
6. 试点业务责任角色已基于明确证据版本、偏差和剩余风险形成最终 `Go/No-Go` 决定。
