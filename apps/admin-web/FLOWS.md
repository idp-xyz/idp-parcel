# 法人资料版本交互回归

## 范围与基线

资料版本从整份资料拼接的时间线改为版本选择与单版详情。对象页与工作台共用同一业务组件，不改身份修订、登记表单、写权限、按时点查询或后端契约。

2026-10-30：独立浏览器访问本机开发服务停在操作者登录页。认证后的真实整页流程尚未验证，不注入凭据或绕过认证。合成数据组件测试与真实业务流程分开记录。

## 必须验证

- 默认选择后端按当前时点解析的有效版本；最新登记不等于当前生效。状态读取失败时保留历史查看，不猜测当前版本。
- 版本选择显示生效时间、登记时间、状态和简短变化摘要。切换不强制滚动，快速切换不显示另一版本的比较内容。
- 变更明细默认隐藏未变化字段；可更换比较基准，也可查看完整资料。首次登记单独说明，不伪造历史基准。
- 联系人没有稳定标识。只对可靠匹配项做字段比较；有歧义时按新增与移除展示并提示，不按下标配对。
- 两个时间都有标签，依据单独展示，长地址、账号、依据可换行。
- 键盘可选择版本、切换详情标签、操作基准和复选框；焦点可见，标签面板关联正确。
- 主体切换、登记后刷新、错误重试不得沿用旧主体答案；区分空历史、接入未配置、登录/授予拒绝与读取错误。
- 窄容器使用原生版本选择，375px不产生整页横向溢出；工作台窄栏同样适用。
- 降低动态效果偏好下无多余动画，不依靠颜色单独表示变化类型。
