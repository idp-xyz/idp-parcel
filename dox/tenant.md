# 租户上线

产品把判断方法、内置策略和连接器做完，把每个租户自己的取值留空。留空的格如实答`未配置`，不带生产默认。一个租户上线要做三件事：提供取值、登进产品、走完阶段评审。

## 租户要提供什么

逐项清单是[参数登记册](../docs/product/PILOT-PARAMETER-REGISTER.md)，一租户建一份实例。每项要有证据引用、证据责任、适用范围、版本或有效时间；口头说明和行业估算不算。「当前登记」只用六种状态：`待提供` `待核验` `待决策` `已确认` `本期不适用` `已失效`。没启用的分支要登权威不适用依据，不能拿未配置代替。

| 一类取值 | 例子 | 没提供时产品怎么答 |
|---|---|---|
| 范围与责任（`PAR-COM-01..03`、`PAR-GOV-*`） | 真实锚点货主客户、客户合同责任法人、成熟主力线路；回放与影子范围、限量生产准入与生产权威规则、暂停与恢复授权、接管条件、证据存储 | 没有权威区间就没有生产权威；暂停按范围版本的覆盖关系读，读不出就保守拦 |
| 商业与价格（`PAR-COM-*`、`PAR-SET-02/03/11/12`） | 服务产品及版本、客户合同版本与有效期、接单规则包与决定授权、接受前财务控制策略、发布审批职责规则、SELL 与 BUY 价卡、计价参考序列、单据编号时区与规则 | 商业解析与批准答`未配置`；缺序列取值时评价挂起，不沿用旧值、不当零 |
| 网络与路由（`PAR-NET-*`） | 节点与服务区域、揽收、干线、尾程履约方，班次与容量，收寄模式，初始路由与复核策略，送站预报有效时窗 | 路由未形成并指名缺哪一格；排序、冻结、自动改路形态没声明即`未配置`，不代租户选 |
| 关务（`PAR-CUS-*`） | 出口与进口监管程序、服务方和渠道，关务参与方与责任角色，自动提交政策与监管凭证来源，案件关闭义务，节点关务区域 | 门禁答`未配置`；建案要求没登记是未决，不是「不要求」 |
| 接入与集成（`PAR-INT-*`） | 客户生产委托接入渠道、面单渠道和账号、外部履约与轨迹数据源、供应商账单接入、财务系统交换边界、操作者账户与授予、集成客户端、作业设备、推送源、客户 webhook 订阅 | 没启用接入渠道的口答渠道未配置；没登记的外部交换不放行 |
| 结算与资金（`PAR-SET-*`、`PAR-COM-08..10`） | 结算账户范围、客户结算模式与币种、计费与付款条件、供应商账期、换算依据、分摊与毛利口径、对账与争议规则 | 评价请求停下并报停因；结算币金额保持待判断 |
| 追踪与披露（`PAR-VIS-*`） | 标准里程碑映射、ETA 口径和质量阈值、异常类型清单、分诊与自动建案阈值、通知模板与披露范围、索赔与追偿条件、普通客户追踪公开与授权规则 | 目录没登记就不派生对客视图，不自动建案，不自动通知 |
| 非功能（`PAR-NFR-*`） | 基线数据观察期、日均与峰值业务量、包裹与集运规模、扫描与查询放大倍数、增长余量、关键流程非功能目标 | 产品不带容量假设；没有真实基线不得进入渠道或国家专属生产启用 |

**真实名称、账号、凭据和映射不进仓库。** 仓库与共享文档只登脱敏标识（如 `CUST-PILOT-01`、`LANE-PILOT-01`）和证据索引。脱敏标识与真实实例的映射、合同、个人信息、密钥本体放在租户登记的 S3 兼容对象存储的 `idp-parcel/pilot` 命名空间里；登记册只记平台、对象标识、版本和访问责任。

## 每一项登在哪个口

受控登记命令都在 `cmd/` 下：运营方操作员在数据库网络内手跑，不监听端口，内容全部来自输入文件，进程不内置任何生产默认，未知字段一律拒绝。

| 命令 | 登什么 |
|---|---|
| `parcel-commercial` | 商业权威依据的发布批；参与方、服务产品、责任法人资料、消费方解析键、版本收尾、审批职责规则 |
| `parcel-access-register` | 操作者与授予、集成客户端、作业设备、准入范围对照、推送源与签名密钥、首方客户端 |
| `parcel-network-register` | 版本化网络目录：服务区域、日历、线路、路由策略；可采用随产品发布的参考配置 |
| `parcel-node-operations-register` | 送站预报有效时窗及其收口 |
| `parcel-transport-register` | 周期安排、具体班次、容量池 |
| `parcel-customs-register` | 关务案件配置：就绪判断、提交授权、解释规则、关闭义务、门禁前置条件、建案要求规则、口岸与申报路径目录、监管凭证、税费付款协作与核对 |
| `parcel-ve-register` | 追踪与异常目录：里程碑映射、分诊规则、通知策略、索赔资格与授权、披露策略、异常披露规则、信号规则；索赔材料收讫 |
| `parcel-pricing-register` | 价卡与计价参考序列的登记快照；序列版本复核 |
| `parcel-pricing-feed` | 来源连接器绑定；按绑定抓一次序列取值 |
| `parcel-pricing-template` | 不登记；写出价卡导入的空白模板 |
| `parcel-settlement-register` | 外部资金事实采用与更正、结算账户、资金映射与核销、分摊分法、财务连接器、计费时点采用、费用项目映射 |
| `parcel-collection-register` | 代收指令、分户账、代收事实、差异事项、协议抵扣、回汇批次、分户账记账 |
| `parcel-document-numbering-register` | 单据编号时区、租户的单据编号规则 |
| `parcel-governance-register` | 权威区间、暂停、恢复、阶段评审（候选版本组与 `Go/No-Go`）、接管 |
| `parcel-frontline-import` | 过渡期把现场按汇总模板记下的收寄与集运作业事实批量灌入既有命令 |

`parcel-frontline-import` 是过渡口：拆除期限写成源码常量 `2026-12-31T23:59:59+08:00`，晚于它即拒绝启动、退出非零，没有环境变量或参数可绕过，延长只能改源码发版。

不少登记另有在线口，路径列在 [contexts/](./contexts/) 下各上下文文件的「入口」一节。单据编号加扰密钥不走登记口，由部署的实例配置注入。演示租户 `SYN-TENANT-01` 由 `scripts/demo-seeds` 经同一批命令灌入，全是 `SYN-` 合成值。

## 怎样算可以上生产

证据层级四种，每条执行记录只标一种：

| 代码 | 证据层级 | 是什么 |
|---|---|---|
| `P` | 真实生产 | 真实客户、合同、线路和生产配置，或限量生产范围内的真实委托、真实账期与真实外部协作 |
| `R` | 历史数据回放 | 来源可追溯的脱敏历史事实，不产生新的外部业务指令或真实金额 |
| `S` | 受控模拟 | 与生产账本和外部生产渠道隔离的合成数据、测试账户或只读输入镜像 |
| `N/A` | 本期不适用 | 已明确排除或有证据证明不适用，须记依据和决定方，不能用空白代替 |

1. **`S` 不升级。** 合成结果不能记成 `R` 或 `P`，重放结果完全一致也不行。演示租户跑通只证明机制。影子运行是执行阶段，不是第五种证据层级；影子通过不构成 `P`。
2. **进生产只有一条路。** 某个租户实例进入生产，只来自登记册证据加 PN-08 阶段评审的 `Go`。任何局部切片不得自行批准生产范围。
3. **先固定候选版本组。** 同一版本的代码、规则、参数、契约、矩阵和证据打成一组，评审对着这一组做。
4. **阶段依次走**：历史回放 → 影子运行 → 限量生产 → 正式验收。每一步要一次 `Go`。
   - 历史回放：不发生产外部指令，不形成真实金额；证据 `R`，必要的隔离执行用 `S`。
   - 影子运行：只比对，不成为生产权威，不发关务、履约、消息或财务副作用。
   - 限量生产：对精确范围建立唯一权威区间，新委托才纳入；主链自然发生的用 `P`。进入前阶段治理参数须已生效，客户、线路、伙伴、合同、容量、授权和集成参数就绪，影子与恢复、接管演练通过。
   - 正式验收：是评审里程碑，不是可长期驻留的运行状态。要真实主链和真实账期的 `P`、全部阻断场景通过、全部在途盘点完成。
5. **谁决定。** `Go/No-Go` 由该租户责任法人指定的试点业务责任角色作出，开发方作不了。日期到达、指标达标或系统建议都不自动转换阶段。
6. **`No-Go` 不改变现状。** 它只表示评审目标未获准，不自动改变当前执行阶段、生产权威或在途责任。发现硬风险另形成暂停决定；暂停只阻止新准入，恢复要显式决定。原权威无法继续时另形成对象级接管决定。
7. **变了就重评。** 范围扩大、规则或发布版本变更、伙伴变更、关键参数变更，都生成新的候选版本组，对受影响场景重新评估。

场景与通过标准看[验收场景矩阵](../docs/product/PILOT-ACCEPTANCE-MATRIX.md)。候选版本组、阶段决定、权威区间、暂停恢复与接管怎么记录，看 [contexts/pilot-governance.md](./contexts/pilot-governance.md)。
