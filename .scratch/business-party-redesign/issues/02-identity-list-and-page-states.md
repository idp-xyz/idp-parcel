# 02 单位名录：整页列表态与各页面态

Category: enhancement
Status: in-progress——2026-11-11 起
父票：[spec](../spec.md)
Blocked by: 无——可直接开始

## 要做的

照[静态参考](../static-reference.html)的「单位名录」整页（没有选中行时）。版式与用词以它为准，这里只列它表达不了的。

- **本页自己的布局，不改 `WorkbenchPageTemplate`。** 模板里现成的件（状态槽、翻页条的纯逻辑、列定义）照用；别的页不受影响。
- **行为一样不少。** 检索、状态、排序照旧下推到读口，游标翻页，换条件回第一页；视图状态照旧住在地址上；`/` 聚焦检索、`Esc`、`↑/↓` 照旧。静态页没画表头排序：生效日期、登记日期两列照旧可排，默认登记时间新到旧。
- **页头一行**：页名、一句说明（放不下截断）、刷新、「建立合作关系」、「新增往来单位」、更多。三个视图共用这一个页头，动作不随视图换。
- **视图签**：单位名录、合作关系、我方关联，数取各册答复的总数，答案没到不摆数。待办两项在同一行右端：待确认的合作关系段数、尚未生效的单位家数，为零不出现，点了带着对应筛选跳过去。两册读得全时从手上的答复数；读不全时各发一次带状态条件的读、取它的总数（状态是这两册读口的筛选维，总数精确）。
- **工具条一行**：检索、状态下拉、类型芯片；视口不够宽时芯片收成下拉。芯片上的数随检索词与状态走、不随类型自己走；摆哪几枚看整册（整册里一家都没有的类型不摆），条件下数到零的压淡留在原位。本票里数的来源不变（整册读得全时由页面数），读不全的降级照票 01。
- **表格**：单位（图标块按类型取图标与底色、名称、编码与注册地）、类型、合作关系（段数；有待确认的另起一行标出）、状态、生效日期、登记日期。列定宽，余量落在行尾；窄了先收登记日期。「合作关系」一列按页面已有的那份关系索引算，口径与类型列一致：只数它担任角色的在用关系，我方公司两边都数。
- **表底翻页条**：共几家、上一页、第几页共几页、下一页。
- **页面态**（静态页「演示状态」逐个可看）：
  - 首次加载：骨架照表的列排，页签不摆数，工具条可用。
  - 读取失败、未配置、需要登录、没有授予：状态件与用词照现有的 `catalogueViewState`，只换表格区；说明块落在上三分之一。读取失败留着工具条。
  - 空册：标题与说明用现行原话；有登记权限时块里另给一枚普通样式的「新增往来单位」，主按钮仍只有页头那一枚。
  - 筛空：「当前筛选条件下没有匹配的单位」加「清除筛选」。
  - 只读：写入口整组不摆（判据照 `useMayWriteRegistry`），指向入口的文案照 `entryHint`。
- **字号只写角色名**，不写像素；粗体只给页名。

## 完成判据

- 三道门退 0；新增的纯逻辑（芯片计数随条件走、摆哪几枚、翻页条文案）钉 node:test。
- 浏览器（演示租户，1280、1440、1734 三个宽度）：
  - 页头、视图签、工具条各只占一行，不折不裁；三个视图之间切换，表格顶端不跳。
  - 页面区顶端到第一行不超过 190 像素；900 高的视口至少看得到 11 行。
  - 无横向溢出；1560 以下类型芯片收成下拉。
  - 类型芯片逐枚点一遍，行数与芯片上的数一致；叠上状态与检索词后仍一致。
  - 待办两项点了各自落到带筛选的视图。
- 页面态逐个核：首次加载、读取失败、空册、筛空、只读。读取失败与未配置在演示环境不好造的，用探针或停掉 API 造，造不出的如实记。
- 深色与浅色主题各看一遍：没有写死的色值。
- 只读核对，零写请求。
