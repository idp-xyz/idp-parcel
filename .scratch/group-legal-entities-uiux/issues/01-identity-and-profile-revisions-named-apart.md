# 01 — 身份修订与资料修订分开命名

**Parent:** [spec](../spec.md)

**What to build:** 一个责任法人身上有两条修订轴：

- **身份登记修订**：出现在列表行、详情栏头部的徽章、事实条「当前修订」、对象页的 meta，以及「修订历史」签里。
- **法人资料修订**：出现在法人资料签的「生效修订」和「资料修订历史」里。

现在两条都只写 `rN`。在演示租户里，同一屏上同时出现「r1」和「生效修订 r2」，读的人分不清哪个算当前。

本票要求两条轴在呈现上永远带名：身份那条写「身份 rN」，资料那条写「资料 rN」。详情栏里展示身份修订历史的签改名为「身份修订」，与法人资料签里的「资料修订历史」对上。对象页的签名由共用模板的固定词表钉住（`workspace-tabs.ts`，票 admin-web-ux-alignment/04），调用方改不了，所以那一签仍叫「时间线」，签里的计数句和条目标题带「身份」二字。

两条历史的排序方向不改。身份按升序排是有意的，理由见 spec「不立票及理由」；两边的计数句里已经写明了方向。

修订历史区和业务参与方页是共用的。业务参与方只有一条轴，那一页不加前缀：前缀由法人页的适配方传进来，不改共用判读的默认值。

**Blocked by:** None — can start immediately

**Category:** enhancement

**Status:** in-progress

- [ ] 详情栏里展示身份修订历史的签名为「身份修订」；对象页「时间线」签里的计数句与条目标题带「身份」二字
