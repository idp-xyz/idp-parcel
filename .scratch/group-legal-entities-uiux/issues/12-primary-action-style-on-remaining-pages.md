# 12 — 其余页面主动作改用主色

**Parent:** [spec](../spec.md)

**What to build:** 05 在集团与法人页落地了主动作样式，但其余页面的主动作还是灰底的次要样式，包括页头主动作和表单提交按钮。本票把它们改用同一个样式，让全站的视觉层级一致。

逐页判定哪个按钮是主动作：一个视图里最多只有一个主动作，其余仍用次要样式。

**Blocked by:** 05 — 主动作用主色（本页）

**Category:** enhancement

**Status:** in-progress

- [ ] 每个页面视图里，最多一个按钮用主动作样式，而且就是这个视图的主动作
- [ ] 两套主题各截图抽验，在完成记录里说明
- [ ] 三道门退 0

## Comments

**来自票 05 评审（2026-10-16）：** 确认对话框的确认按钮也在本票范围内，它是一个视图里的主动作。上游 `ConfirmDialog` 的 `tone` 映射到 `confirmVariant`，`neutral`、`info`、`warning` 走 default 变体，同样只有强调色字、没有底、没有聚焦环。比如 集团与法人 登记视图的「离开」（票 04 加的）。可以经 `renderFooter` 换自己的按钮，也可以等上游补 primary 变体，见票 05 完成记录里的上游建议。
