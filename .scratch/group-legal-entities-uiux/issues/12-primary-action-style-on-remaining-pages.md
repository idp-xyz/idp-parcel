# 12 — 其余页面主动作改用主色

**Parent:** [spec](../spec.md)

**What to build:** 05 在集团与法人页落地了主动作样式，但其余页面的主动作还是灰底的次要样式，包括页头主动作和表单提交按钮。本票把它们改用同一个样式，让全站的视觉层级一致。

逐页判定哪个按钮是主动作：一个视图里最多只有一个主动作，其余仍用次要样式。

**Blocked by:** 05 — 主动作用主色（本页）

**Category:** enhancement

**Status:** resolved

- [x] 每个页面视图里，最多一个按钮用主动作样式，而且就是这个视图的主动作
- [x] 两套主题各截图抽验，在完成记录里说明
- [x] 三道门退 0

## Comments

**来自票 05 评审（2026-10-16）：** 确认对话框的确认按钮也在本票范围内，它是一个视图里的主动作。上游 `ConfirmDialog` 的 `tone` 映射到 `confirmVariant`，`neutral`、`info`、`warning` 走 default 变体，同样只有强调色字、没有底、没有聚焦环。比如 集团与法人 登记视图的「离开」（票 04 加的）。可以经 `renderFooter` 换自己的按钮，也可以等上游补 primary 变体，见票 05 完成记录里的上游建议。

## 完成记录（2026-10-16，作者会话，前端切片直接在 main 上做）

- **落点：** 代码与票面认领同在 `73ac144a`。
- **改了什么：**
  - 各视图的主动作叠上 `primaryActionClass`：参与方关系登记、身份停用、业务参与方登记、发布流程的下一步、计价试算、价卡「存为草稿」、序列「登记」、序列「提交复核」、有效时间判断的提交，以及模板预览页演示的主动作。
  - 新增 `components/primary-action.ts` 的 `dangerActionClass`（red-700 实底配白字，6.47:1，node:test 守着），以及共用页脚 `components/confirm-dialog-footer.tsx`。全应用七处 `ConfirmDialog` 都经 `renderFooter` 换上：确认键按 `confirmVariant` 取主动作或危险动作实底，取消键用 breadcrumb 色；键序、提交中禁用、`aria-busy` 与转圈照上游默认页脚。
- **判定：** 一个视图最多一个主动作。
  - 「先预览后落册」两步（价卡导入、序列登记）里，落册那一步是主动作，预览照旧次要。
  - 表格行内动作照旧次要（结算「人工分配」、价卡草稿逐行动作），它们不是视图级主动作。
  - 经 `headerActions` 传入的动作也照旧次要：渠道选择「查看」是查找；最近对象「清空历史」是危险的次要动作；有效时间判断「发起判断」只是展开表单，表单里的提交才是这一视图的主动作。
- **判据：**
  - ✅ 每个视图最多一个主动作样式：逐个调用点判过，判定见上。
  - ✅ 两套主题抽验：真浏览器（Playwright Chromium，1440×900）实测计算样式。

    - 取消包裹「逐件请求取消」（danger 语气）：确认键 `rgb(185, 28, 28)` 配白字，取消键 `rgb(51, 65, 85)`。
