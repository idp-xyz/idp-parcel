# 10 — 1024 宽下不折坏

**Parent:** [spec](../spec.md)

**What to build:** 在 `858280a2` 上，用 1024×800 打开详情栏，实测有四处折坏：

- 事实条里的时间被拆成「08:00:0 / 0 UTC+8」；
- 列表里的状态徽章折成「已生 / 效」两行；
- 「注册号」引用签的标签变成竖排；
- 命令头的 KPI 只剩前两个，后面的悄悄消失了，没有任何提示。

本票让窄宽下的布局保持完整：
- 事实条改成两列；
- 时间、徽章和引用签标签都不在词中间断行；
- KPI 放不下时换行或可以横向滚动，不能悄悄丢掉。

**Blocked by:** 06 — 详情栏头部瘦身（事实条与头部的内容在那里定）；08 — 本页可访问性（字号提升会改变窄宽下的排布）

**Category:** bug

**Status:** resolved

- [x] 在 1024 和 1280 宽下，列表和详情栏都没有上面列的断行，全部 KPI 可见或可以滚到
- [x] 1440 宽下的布局不回退
- [x] 用真浏览器截图验证，在完成记录里说明；三道门退 0

## 完成记录（2026-10-16，作者会话，前端切片直接在 main 上做）

- **落点：** 代码与票面认领同在 `d62b553f`。
- **改了什么：**
  - **工作台命令头**改为可换行。指标组在 2xl 以下独占第二行（`order-last basis-full`），组内按需换行。此前的问题：它在同一行里用 `overflow-x-auto` 横向裁切；票 08 把标签提到 12px 之后，1280 和 1440 下第四格「在用中已生效」也被裁掉了；md 以下整组藏起。
  - **详情栏事实条**在四列与两列之间二选一：`minmax` 的下限用 `clamp(25% − 间距, (32rem − 100%)×999, 50% − 间距)`。先试过两种都不行：按最小格宽自动分列，会在 1280 排出三格加一格；固定四列，在窄栏里把「08:00:00」拆成两半。
  - **不在词中断行：** 引用签的标签加 `shrink-0 whitespace-nowrap`，副题里的参与方身份和列表状态格加 `whitespace-nowrap`。列表标识截断时补了 `title`，悬停能看全称。
- **判据：** 用真浏览器（Playwright Chromium，宽 1024 / 1280 / 1440，高 800）量化核对，探针在浏览器里拦掉了全部非 GET 请求：

  | 宽度 | 事实条 | 时刻 / 徽章 / 引用签标签断行 | KPI | 横向滚动 |
  |---|---|---|---|---|
  | 1024 | 两行（2×2） | 无 | 四格都在视区内 | 无 |
  | 1280 | 两行（2×2） | 无 | 四格都在视区内 | 无 |
  | 1440 | 一行四格 | 无 | 四格都在视区内 | 无 |

  - ✅ 1024 与 1280 下列表和详情栏都没有票面列出的那几种断行，全部 KPI 可见。
  - ✅ 1440 下布局不回退：事实条仍是一排四格。命令头比改前多一行，因为指标组移到了第二行；改前 1440 下第四格本来就被裁着，换来的是全部可见。
  - ✅ 三道门：`tsc -b --noEmit` 退 0，`run-tests` 533/533，`vite build` 退 0。构建产物里有那串 `grid-template-columns:repeat(auto-fit,minmax(clamp(…)…))`。
- **评审：** 动了工作台模板（共享面，只有本页在用），**作者自审，不算非作者评审**（本仓不用子代理，本机也没有空闲通道）。自审 0 阻断：命令头在 2xl 及以上恢复同排，与改前一致；在 2xl 以下只是多一行，不裁切任何格子。
