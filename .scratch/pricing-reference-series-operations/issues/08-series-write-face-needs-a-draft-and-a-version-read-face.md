## 为什么立

票 [04](./04-review-endpoint-and-admin-structured-form.md) 切片 04b 要五件，交了两件，
**其余三件不是没做，是做不了**——它们各自缺一件后端，而那两件后端本册今天都没有。写在
一张票里是因为它俩合起来才凑成「运营配置员的写面主路径」，分开做会得到半条路。

三件与它们缺的东西：

| 04b 未交件 | 缺什么 | 缺在哪一层 |
|---|---|---|
| 目录页「复核状态」列 | `ReferenceSeriesCatalogueRow` 没有复核事实 | 逐版本读面 |
| 行动作「更正此版本」预填全部期次 | 同一个行类型没有期次，也没有任何详情读口 | 逐版本读面 |
| 逐字段登记表单的**提交前预览** | 证据等级、内容摘要、与上一版逐期差异，三样前端都算不了 | 草稿／预览步骤 |

**第三件尤其不能靠前端凑。** 票 04 的红线原句是「前端不算摘要、不裁证据等级，只呈现后端
答复」；而摘要只有领域构造函数算得出，证据等级同理（全期有可复核凭证才是`可复核`），
逐期差异要上一版的期次。**没有预览的逐字段表单等于把一份可能被拒的载荷盲提上去**，比
今天的 JSON 口好不了多少——那正是 04b 只交两件而没有硬做表单的原因。

## 先答再开工：本册按 ADR-0101 决定八选哪一形

[ADR-0101](../../../docs/adr/0101-operator-facing-registration-payload-shape-is-product-defined.md)
决定一把运营操作者面的载荷形状划归产品定义，决定八要求**每册在自己的实施票里写明选了
哪一形与理由**：结构简单、低频的册可以直接逐字段表单；矩阵型、高频、需双人治理的册走
「模板导入 → 草稿 → 批准 → 发布」。

参考序列**两头都不像**，所以这一裁是真的要裁而不是照抄价卡：

- **不像价卡**：一版序列是几期到几十期，不是上千格的矩阵；没有模板导入的必要。
- **不像复核**：复核是两格、无版本链、无摘要；序列登记有期次表、有证据等级、有内容摘要、
  有更正版本链，**而且它的三态预览恰恰要求一个持久化或至少可复现的中间态**。

倾向（不是裁决）：**逐字段表单 + 一个无持久化的「校验预览」端点**——收同一份登记快照，
过领域构造门，交回证据等级、内容摘要与逐期差异，**不写库**。它比价卡那套草稿册轻，因为
序列没有「录入者今天上传、批准者明天批准」的需求（复核是独立动作、已有自己的口）。
**但 ADR-0101 决定四那条硬句照样适用**：预览页显示的摘要与登记册记下的摘要必须逐字节
相等，否则会长出「预览通过、登记却答内容冲突」这一格，而它与真实的内容冲突不可分辨。

## 要建什么（裁完形之后）

1. **逐版本读面加两组字段**（`ports.ReferenceSeriesCatalogueRow` + postgres 转写 + http 行体）：
   - **复核事实**：本版复核条数、其中通过条数、最近一次复核的时刻与结论。
     **不含「在用」**——owner 2026-09-03 已裁，理由见票 04 那条 Comment 第四节：
     `SelectInForceSeriesVersion` 要一个时刻而目录页没有。**在用归 05a 的覆盖读口**。
   - **期次**：起 / 止 / 值 / 凭证引用，供「更正此版本」预填。
2. **校验预览端点**（形态待上面那一裁）：过领域构造门，交回证据等级、内容摘要、逐期差异；
   不写库、不进版本清单。装配行进 `cmd/parcel-api/endpoints.go`（共享接线文件，先占号）。
3. **管理台三件**：复核状态列、逐字段登记表单（含预览）、「更正此版本」预填 +
   强制更正依据 + 自动带 `PriorVersion`；**页面上不出现「编辑」**。

## 红线

- **在用判定只在 `domain.SelectInForceSeriesVersion` 一处。** 读口只取事实，不在 SQL 里
  另写一套排序裁决——`ports/reference_series_review.go` 的注释原话是「SQL 若也排一遍就是
  两处口径」。接 05a 的人同守这一条。
- 前端不算摘要、不裁证据等级，只呈现后端答复（票 04 原红线）。
- 预览与登记共用一份摘要，逐字节相等（ADR-0101 决定四）。
- 操作者身份不自报：登记责任方与复核责任方都从 ADR-0100 的 `OperatorEnvelope` 来，
  表单不收也不送。

## 验证

读面：真库用例证两组字段照实转写（无复核的版本两个计数为零而不是缺字段；无期次不可能，
期次至少一条是领域硬句）。预览端点：http 单测证只收 POST、未配置 403、以及**同一份快照
过预览与过登记得到逐字节相同的摘要**——那是决定四那条硬句唯一守得住的地方。前端：
`tsc --noEmit` 与 `node scripts/run-tests.mjs` 绿。
