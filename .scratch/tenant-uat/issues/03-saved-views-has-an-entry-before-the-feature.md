# 「保存的视图」还没开放，导航和工作台已经有入口

Category: enhancement
Status: resolved

出自第 1 站 1.16。验收卡见 [stations/01-entry.md](../stations/01-entry.md)。

## 看到的

左侧导航、工作台一块、命令面板都有「保存的视图」。点进去页面写着「列表页的『保存视图』还没开放；开放后，筛好的条件可以存下来」。空态本身说得明白。

## 定了什么

用户 2026-11-27：功能完整实现并开放，不藏入口。

## 落了什么

列表页和工作台模板在地址上存当前筛选：去掉 `view` 之后的查询串，存进这台电脑的「保存的视图」。打开时用 `replaceState` 把地址换回去，并派一次 `hashchange`，让本来就听地址的列表自己重读。空态改成「在列表页点『保存当前视图』。存下的是那张列表地址上的筛选」。2026-11-27 在「客户与合同」读到「保存当前视图」。

只活在页面内存里、不进地址的筛选，存不下来。`saved-views`、`recent-objects`、`workbench` 自己不提供保存。
