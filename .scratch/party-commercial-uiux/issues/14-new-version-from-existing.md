# 14 — 基于此版本发新版本

**Parent:** [spec](../spec.md)

**What to build:** 版本一经发布不可覆盖，改动靠发新版本——这是本区的主要任务。今天每次都要在发布表单里从空白整张重填，哪怕只改一个字段；差一个字就成了另一份内容。目录里的行没有任何入口通向「以这一版为底稿发新版本」。

改法：

- 合同、协议、产品三张目录表与七本有自己发布表单的政策册，每行加一颗「发新版本」按钮。点了把这一版的记录还原成发布表单的草稿，切到发布签（政策页同时选中那一册），表单按它预填。随所属版本发布的两本册（接受前财务控制、接受判断时点策略）没有自己的表单，行上没有按钮。
- 预填**只抄读面上确有的**：对象标识照抄（同一对象的新版本），内容格照抄；读面没有的格（信用政策、结算政策、接单规则包没有版本的适用范围，合同没有货主客户账户）留空。**版本号与所有生效区间一律留空**——版本号要人起，新旧两版区间重叠解析时答「适用冲突」，把上一版的区间抄过来就是替人造这个冲突。
- 发布流程顶上提示「已按「…」预填。版本号和生效区间要自己填；读面上看不到的格也是空的。发布前请逐格核对」。
- 再次点同一版、或换一版点，表单整个重建，不留上一次的预览与草稿；按钮的提示说明会替换该表单里已填的草稿。
- 还原是纯函数（各册 `*-form.ts` 的 `*DraftFromRecord`），带 node:test 用例：抄对了什么、留空了什么、读面可缺键缺席时不崩、状态类的 0 / 空数组不折成缺席。

不做的：「标识旁列出在册版本、提示区间重叠」（另票）；自动起一个版本号建议（版本号是租户自己的命名，不替人起）；还原批准依据、引用的批准信息（读面没有，草稿里本来也没有这类格）。

**Blocked by:** None — can start immediately

**Category:** enhancement

**Status:** resolved

## 完成记录（2026-10-26，tops-54，前端切片，worktree `idp-parcel-pcux4`）

- **落点：** 本笔提交。公共件、信用政策样板与四个页面由会话做；其余九张表单的还原函数与表单属性分给三个子代理各做三张（文件互不重叠），会话逐张看过回报与不含中文的改动行后收。
- **改了什么：**
  - 公共件：`new-version.ts`（`NewVersionStart`：还原好的草稿 + 「基于哪一版」+ 可选警示；`NewVersionRequest` 与 `nextRequest`，页面拿发起序号作表单 key）、`NewVersionAction.tsx`（目录行上的「发新版本」按钮列，不吞行点击，读屏名「基于 … 发新版本」）、`PublicationDraftFlow` 的 `prefilledFrom` / `prefilledCaution`（流程顶上「已按「…」预填。版本号和生效区间要自己填；读面上看不到的格也是空的。…」）。
  - 十张表单各一个纯函数 `*DraftFromRecord`（`credit-policy-form.ts` 为样板）与可选属性 `start`；交付条件一节共用 `deliveryConditionDraftFromRecord`。各册抄什么、留什么都写在函数头注里；共同点：对象标识照抄，**版本号与全部生效区间留空**，读面没有的格留空。
  - 页面：政策页行模型带 `source`（七本有表单的册），点按钮 → 记下这一版、切到发布签、选中那一册、那一册的表单按序号重建；合同、协议、产品三页的页签改受控以便代码切签。
  - 接单规则包预填带警示：读口不带时点策略、接受内容、面单有效期、资料修订四节声明，预填后是空的而「留空即未声明」，上一版声明过的新版本不补就丢了——读面补不回来（要后端目录行带出），只能提醒，提示条里用红字单列。
- **会话裁的几处（子代理提出的）：**
  - 结算政策的合同两格**不拆**限定版本标签：子代理做过「恰好一个 `/` 才拆」的版本，但领域那边明确不要前端再多一处知道分隔符，且合同格已是对象加版本一起选，留空只是再选一次。
  - 授权规则请求方下拉：预填的请求方不在词表里时，受控选单原先找不到对应项、显示「未选」而草稿里仍带着值，显示与要送的内容分叉；子代理给草稿持有的值加了一项原样示出（词表可读时「某码（不在可选项里）」，读不到时原值）。保留。
  - 合同的版本适用范围读面上有，两种情形都抄；合同级「要不要接受前财务控制」声明读面不在合同记录里（在另一本册），留空——但这一项在载荷里必送，留空服务端会点名，不会悄悄丢，所以不加警示。
  - 合同「登记了正文但零约定」照空草稿预开一行空约定，不还原成零行；人不要就删，不删预览会点名。
