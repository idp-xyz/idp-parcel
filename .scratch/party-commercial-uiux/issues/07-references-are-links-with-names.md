# 07 — 引用可点、显示名称

**Parent:** [spec](../spec.md)

**What to build:** 参与方与商业区的表格里，引用别的对象时只有一串不能点的标识：供应商协议的「供应商」「责任法人」是 `SYN-PARTY-CARRIER-LM-01`、`SYN-LE-01`；接单规则包的服务产品、客户合同、责任法人，结算与信用政策的责任法人与相对方，合同上的接单规则包与接受前财务控制策略，渠道映射的服务产品，都一样。评估里「客户 X 有哪些合同、走哪个产品」在界面上答不出来，断在这里。

要做的：

- 引用一律画成链接。参与方与责任法人带名称（名称在上、标识小字在下）；合同、产品、规则包、策略今天没有名称，只显标识。
- 点了去那个对象所在的页，并带上检索词 `?q=<标识>` 定位到那一条：参与方 → 业务参与方页；责任法人 → 集团与法人页；客户合同 → 客户与合同页；服务产品 → 服务产品与渠道页；接单规则包、接受前财务控制策略 → 商业规则与策略页对应的册。
- 名称从业务参与方册与责任法人册取（页面各读一次，不逐行请求）；读不到或不在册时只显标识，不猜、不报错。
- 目标页都要能从地址读检索词（今天只有业务参与方页与客户账户签能）：集团与法人、客户合同签、服务产品、商业规则与策略。商业规则与策略换册时清掉检索词，免得新册被旧词筛空。
- 参与方全景里「去「客户与合同」」「去「集团与法人」」等跳转也带上检索词。

不做的：合同列表加「客户」一列（读口不带，归 spec 后续第三段）；参与方关系抽屉（ps-external-mark-relations/17 刚改过，整体改版另票）。
