# 05 — 商业规则与策略页布局

**Parent:** [spec](../spec.md)

**What to build:** 商业规则与策略页在 1440 与 1920 宽下都折坏了：

- 顶部 10 个页签（1 个「政策册」、8 个「发布 X 版本」、1 个「受控发布（JSON 镜像）」）挤成两行，「政策册」折成「政策 / 册」。
- 政策册签里 9 个册按钮逐字竖排（「接 / 单 / 规 / 则 / 包」），册说明夹在按钮与工具位之间，右端计数「接单规则包 1 条」压在「保存视图」上，过滤条出现横向滚动。
- 页面说明约 200 字，被截成「商业规则…」。
- 读签与写签名称对不上：「商业价格政策」对「发布价格政策版本」，「接单规则包」对「发布规则包版本」。
- 选中的册不进地址，刷新回到第一本。
- JSON 镜像签自己写着「不是运营配置员的主路径」，却与主路径并列。

改法：

- 页签收成三个：「政策册」「发布新版本」「JSON 发布（高级）」。「发布新版本」签里先选册（与政策册签同一组册名），再出那张表单；选中的册与政策册签共用一个地址参数。
- 册选择改成能换行的按钮组，带 `aria-pressed`；册说明放到按钮组下方一行；计数回到模板的右端计数位，不与工具位重叠。
- 页面说明一句话；册与对象的关系放进各册说明（01 改过的文字）。
- 读写两侧用同一组册名。

另：参与方身份表把能用的排序下拉放在主筛选位，模板的「排序」位仍是禁用、悬停说「本页尚未提供排序」。把这个下拉接进模板的 `sort` 位，同页不再自相矛盾。

**Blocked by:** 01（册说明文字）

**Category:** enhancement

**Status:** resolved

- [x] 1440、1280 宽下页签一行放得下，册按钮不逐字竖排，计数不压工具位，过滤条不横滚。截图为证。
- [x] 选中的册在地址里，刷新后保持；政策册签与发布签选的是同一本。
- [x] 读写两侧册名一致。
- [x] 价格政策表单以 main 现状为准（code/25 已去掉体积系数一格），不加回。
- [x] 参与方身份表的排序走模板 `sort` 位，同页不再有禁用的「排序」位。
- [x] 三道门退 0。

## 完成记录（2026-10-26，tops-54，前端切片，worktree `idp-parcel-pcux`）

- **落点：** 本笔提交。
- **改了什么：**
  - 页签收成三个：「政策册」「发布新版本」「JSON 发布（高级）」。原来七个「发布 X 版本」签各占一签。
  - 选册那一排（`RegisterChooser`）挪到列表模板之外、能换行、带 `aria-pressed`；政策册签与发布签共用这一排与同一个选中的册。列表标题就是选中的册名、说明就是册说明，右端计数改「共 N 条」，回到模板的计数位，不再与工具位抢地方；页面层那句长说明随之撤掉，不再被截断。
  - 发布签：选中的册有自己的表单就摆那张；没有自己版本的两本给去向——接受判断时点策略「随接单规则包一起发布」并带一键切到规则包，接受前财务控制「随客户合同一起发布」并带去客户与合同页的按钮。
  - 签与册写进地址（新纯函数 `commercial-policies-address.ts`：`?tab=publish|json`、`?register=<册>`，取缺省值的那一项不写），读写同 `useAddressKeyword` 的做法（`replaceState`，不压后退记录），地址被前进后退改了也跟着读。
  - 发布落定后那一册重读；仍停在发布签让人看完答复（原来也不自动切签）。
  - 参与方身份表、参与方关系表：排序下拉从主筛选位挪进模板的 `sort` 位，同一行不再并排一个能用的排序和一个禁用的「排序」。
- **判据：**
  - ✅ 1440 与 1280 宽：三个页签一行；九本册的按钮一行排开（更窄时换行），不逐字竖排；计数「共 N 条」在右端、不压工具位；主区 `scrollWidth == clientWidth`，过滤条不横滚。截图在会话临时目录。
  - ✅ 地址：点「授权规则」后地址为 `#/commercial-policies?register=AUTHORIZATION_RULE`，切到发布签为 `…&tab=publish`，表单是「发布授权规则版本」；直接打开 `?tab=publish&register=AS_OF_POLICY` 落在发布签、选中接受判断时点策略、显示去向说明。
  - ✅ 读写两侧册名一致：两签用同一个 `RegisterChooser`、同一份 `policyKindLabels`。
  - ✅ 价格政策表单未改（以 main 为准，体积系数一格不在）。
  - ✅ 参与方页两张表的排序位是可用的下拉，模板的禁用「排序」位不再出现。
  - ✅ 纯函数用例 `commercial-policies-address.test.ts` 5 条。三道门：`tsc -b --noEmit` 退 0，`run-tests` 631/631，`vite build` 退 0。
- **未改：** 切换发布签里的册会卸下当前表单、草稿随之丢掉（切页签本来就丢，spec 后续「切页签不丢草稿」一条一并处理）。
- **评审：** 改动全在 `pages/**`（没碰 `templates/`），自查判据。
