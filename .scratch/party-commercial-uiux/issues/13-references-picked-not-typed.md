# 13 — 引用他物的格从册里选，不手敲标识

**Parent:** [spec](../spec.md)

**What to build:** 发布与登记表单里，有一批「引用另一个对象」的格是纯文本框，要人手敲标识：信用政策的责任法人、客户合同的货主客户账户、合同层交付条件「所收紧的服务产品」的对象与版本、接单规则包正文的服务产品 / 客户合同 / 责任法人、客户服务规则的适用对象、参与方关系登记里授权交付范围的客户账户。同一个概念在别的表单里已经是选择器（供应商协议、结算政策的责任法人与相对方用 `ReferencePicker`，结算政策的合同用对象加版本一起选的 `ContractPicker`）。打错只会在预览（英文报错，03 之后是中文）或发布时才暴露；配置员还得切出去查标识（09 之前一切签草稿就丢）。

改法：

- 引用一个对象的格一律用 `ReferencePicker`，候选从对应的册读；引用的是对象本身的（规则包正文、客户服务规则适用对象），候选一对象一项、写出它有哪几版与在用的那版。
- 要连版本一起选的格（所收紧的服务产品版本）对象与版本一起选、两格同时落，不让人手拼版本号。
- 读口分页的册（货主客户账户）不做成选单——选单只列得出第一页，第一页之外的人选不到；做成能直接输入的格，带第一页候选作输入提示。
- 选项文字全区一种写法：名称 · 标识 · 中文状态（供应商协议、结算政策原来直出英文状态码）。
- 读不到读口时照旧退回手填并说明原因；选出来的只是引用，在不在册、能不能引仍由服务端判。

不做的：服务产品引用表的「被引对象类别」——那格的注释写着当时的裁定（没有词表读口之前不内置这份候选），本票不推翻；候选多时的可搜索选单（今天的册都很小，等册变大再换）；客户服务规则的「责任方」（读口没有说清它是参与方还是法人，不猜）。

**Blocked by:** None — can start immediately

**Category:** enhancement

**Status:** resolved
