# 08 — 版本按对象排在一起、可只看在用的

**Parent:** [spec](../spec.md)

**What to build:** 客户合同、供应商协议、服务产品与带版本状态的政策册，同一个对象的各个版本平铺在表里，顺序跟着读口走。演示数据里供应商协议 `SYN-SUPPLIER-TRUNK-CN-SG-01` 的 v1、v2（已退役）与 v3（已生效）夹着别的协议出现；04 之后状态已是徽章，但要看「这个对象此刻用的是哪一版」，仍要自己在表里找齐它的各版。

要做的：

- 列表按对象排在一起：同一对象的各版连续出现，组内新版本在上；组与组之间按对象标识排。
- 加一个状态筛选：「全部 / 在用 / 其余」，「在用」只留状态为已生效的版本，其余留已发布未生效、已退役、已到期、已替代。默认「全部」，不替用户藏行。带计数，计数只在拿到业务答案后显示（README「列表页上列通则」）。
- 筛选与检索叠加；筛空时给「这组条件下没有」那一行，不显示成册为空。

不做的：行点开详情与版本历史（另票）；「在用」只看服务端答的状态，不在前端按时刻另算。

**Blocked by:** None — can start immediately
