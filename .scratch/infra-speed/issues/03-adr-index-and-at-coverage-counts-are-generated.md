## 要什么

- **`docs/adr/README.md` 的两个列表（已接受 / 已被取代）由 `tools/adr-index` 从各 ADR 文件生成**：行文 `- [ADR-NNNN：<标题>](./<文件>)`，标题取 H1；部分停用与取代的注记取自该 ADR 的 `Status` 行。README 顶部的说明段仍手写，列表落在一对标记之间，工具只重写标记内。`-check` 模式：生成结果与文件不同即非零退出。
- **一次性迁移注记**：README 里现有每一条「｜**部分停用**……」与「→ 由 … 取代：……」注记，凡对应 ADR 的 `Status` 行尚未承载的，搬进那一行（`Status` 行在本仓被取代时本就会改写，见 README 顶部那段；正文一字不动）。搬完后第一次生成的列表与搬之前的 README 逐条对照：每个 ADR 一行、注记文字不丢不改，差异只许是格式归一；对照结果写进完成记录。
- **README 顶部「部分停用」规则改写**：被停条款与适用场景写在被停用 ADR 的 `Status` 行（README 由它生成），不再要求手改 README 行。别处凡写「在 docs/adr/README.md 该行写被停条款」的现行指引（`AGENTS.md`、`docs/agents/*.md`、各 workflow 提示不算）一并改指向；只追溯的旧票面不改。
- **AT 盘点的「总览」两张计数表由工具从同文件各分节的行数重算**（同一个工具加子命令，或 `tools/` 下另一个小工具，作者定）；票只移行，不碰计数。
- 进 main 步骤里在「重生成机制清点」旁加上这两步（生成 ADR 索引、重算 AT 计数），单独成笔，与机制清点同口径（「生成物不占号」）。

### 做了什么

### 代决与越权风险点

代决（用户原话「你作为业务和系统专家自决……解决所有的问题」）：

1. **注记在 Status 行里用显式标记划出**，不按「部分停用」之类的字样去认。原因是 `Status` 行里两个方向都写：本记录停用了谁（去向），本记录被谁停用（来向），两者都叫部分停用，措辞也各会话各写。标记是 HTML 注释，渲染时看不见。
2. **README 上的注记一条不落地全部搬**：除了票面点名的部分停用与取代，「判据」摘要、「**已接受**（……）」出处与摘要、草案、后继、「已答」都搬。「尚未承载」按逐字判断——没有一份 `Status` 行逐字含有 README 那一段，所以带注记的 146 份全搬。理由：票面要求「注记文字不丢不改，差异只许是格式归一」。只搬两类的话，约一百条判据摘要会从索引上消失。
3. **标记用两对**，每个列表一对；票面写的是「一对」。这样两个列表中间的「## 已被取代决策」标题和那句说明仍是手写，不必挪进代码里。
4. **AT 计数单列一个工具 `tools/at-coverage-counts`**，桶名取节标题、去掉全角括号里的说明，不在代码里另写一份桶名。③ 在总览里的行名因此由「实例/闸门」变为「实例半边/闸门阻断」。
5. **两个工具住主模块**。票面的 `go test ./tools/...` 与 `go run ./tools/adr-index -check` 在仓库根就能直接跑；新包按测试分片规则落进 `rest` 片。机制清点自成模块是因为它要 `x/tools`，这两个工具用不着。

越权风险点：

1. **Status 行里多了不是状态的话**：判据摘要、接受出处这些原本只在 README 的文字，现在跟在各 ADR 的状态后面。owner 若认为 Status 行只该写状态与前向指针，摘要类注记可以删，但删了也就从索引上没了。
2. **同一件事在一行里说两遍**：52 份 Status 行，标记前段与索引注记都写了停用，其中有同一次停用的两种措辞，也有去向与来向（0022 0025 0052 0053 0064 0068 0072 0075 0078 0081 0085 0086 0091 0094 0098 0100 0101 0104 0106 0139 0140 0148 0149 0150 0151 0164 0169 0175 0183 0185 0186 0187 0195 0196 0198 0199 0201 0204 0206 0207 0209 0210 0211 0212 0213 0214 0215 0217 0218 0219 0220 0221）。另有 42 份前后两段都写了接受出处（0139–0142、0179、0180、0182–0190、0195–0221）。这类重复以前就有，只是分在 README 与 ADR 两个文件里；合并要逐份判断以哪种措辞为准，归票 07。
3. **35 条标题改取 H1**，README 自拟标题里 H1 没有的字不再进索引。其中 5 条 README 是截短（0100 0112 0139 0187 0190）；6 条 README 多写了一段（0079 0082 0086 0089 0093 0098）；21 条另写了措辞（0087 0088 0096 0097 0101 0104 0115 0116 0122 0126 0127 0129 0131 0132 0133 0136 0137 0140 0141 0150 0153）；3 条只差标点（0077 0110 0138）。旧行在 `5c7c9121` 的 README 里查得到。
4. **AT 总览的数一次跳了**：① 342→417，合计 1134→1209，变化都在 NR、TF、VE 三个前缀的 ① 列。原因是手改的数落后于实际的行，不是本票改了分桶。另有一个盘点本身的缺口不归本票：UC-NO-005 等新立的部分 AT（如 `AT-NO-101` 起）只出现在文末追记的叙述里，没有表行，所以工具不数。
5. **CI 没有对应的 `-check` 门**。`.github/workflows` 不由本会话改；而且「票不重生成」与在 PR 上跑 `-check` 相抵触，门该挂在哪种触发上要先裁，归票 08。
6. **`parallel-sessions.md`「第三类：索引文件」那一句不在票面地盘清单里**，因为它随本票变成假话，所以顺手改了。
7. **票 02 新立的 ADR-0222 若照旧手加 README 行**，进 main 重生成时那一行的注记会被盖掉。要先把它搬进 ADR-0222 `Status` 行的索引注记，再重生成。
