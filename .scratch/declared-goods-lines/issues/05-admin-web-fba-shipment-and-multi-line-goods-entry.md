# 05 管理台：FBA 货件下单页，小包下单改多行货物

Category: enhancement
Status: ready-for-agent
Blocked by: 03

依据：ADR-0374 决定三（模型统一、入口按场景分）；ADR-0373 决定二、三、六。diff 只落在 `apps/admin-web/**` 时走 [workflow.md「前端切片」](../../../docs/agents/workflow.md#前端切片一人在-main-上直接做)。

## 要做的

- **小包下单页**（`SubmitShipmentRequestPage`）：货物从每个包裹一组扁平字段，改成委托级的多行货物表（品名可加第二语言、数量与单位、单价或行总价、币种、净重、编码、原产国、SKU、销售订单号）；单件委托不出现装箱分配；多件委托可选择报不报装箱分配。
- **FBA 货件下单页**（新页，同一个 `/v1/shipment-requests`）：平台、平台货件号、平台参考号、平台仓收件资料；箱子表（每箱声明测量与平台箱标号）；货物行表；装箱矩阵（行 × 箱的数量，提供「同款每箱 N 件 × M 箱」快捷填法）；提交前在页面上提示逐行数量之和对不上。服务端照样按 02 的形状规则核，页面提示只是方便录入。
- 两个页面在导航里分开入口，答复与错误展示复用现有 `ResultPanel`。

## 完成判据

- 纯逻辑（行与分配的组装、矩阵求和、快捷填法）有 `node:test` 测试。
- 三道门通过；用 `SYN-` 数据在本地对 03 的后端提交一票 FBA 货件（30 箱以上）与一票两行小包，答复正常。

## 不做的

亚马逊箱内明细模板（Excel）导入：等真实租户拿出模板再做，记入冻结清单「五」的记录。
