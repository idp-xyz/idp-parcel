# 06 没有改动就不登新版：保存钮禁用、按钮旁说一句

Category: enhancement
Status: in-progress
父票：[spec](../spec.md)
Blocked by: 04

## 出处

用户 2026-11-04：「信息没有变化，无需增加新的版本，保存按钮也无效，你觉得呢」。会话同意：与 Fiori 编辑态一致，没有脏改动时 Save 不可点。

## 要做的

1. 整张公司资料表单：有当前版时，草稿折成内容与当前版比没有任何变化（只改来源单据 / 生效时间不算）→「保存」禁用，按钮旁「资料没有改动，不用保存」。第一版（没有当前版）照旧。
2. 分区就地编辑：同一判据；来源单据自动句的「内容未变，重新登记一版」改为「尚无改动」。从「添加」打开的空行在填之前不算改动。
3. 往来单位「更正名称」：名称与当前一致 → 禁用，按钮旁「名称没有改动」。
4. 预览里「资料内容与第 N 版完全相同」那条支路随之不可达，留着不碍事。

## 完成判据

- 三道门退 0；`profileSectionBasisOf` 的测试跟着改。
- 浏览器核：三处打开即禁用并显提示，改一格即启用，改回去再禁用。
