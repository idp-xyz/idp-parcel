# 09 初始路由证据从目录折出：日历与截单成时间投影，线路成段链，策略版本成引用

Category: enhancement
Status: draft
Blocked by: 07
父票：[psb/04](../../product-strategy-boundary/issues/04-routing-product-strategy-first-cut.md)「接路由证据取数侧」那一步（初始路由一侧，成本除外）
地盘：network-routing 目录的内容列（服务日历、截单、节点处理时间与衔接缓冲的形状，新迁移号开工时预留）、postgres 取数侧。
出处：[ADR-0146](../../../docs/adr/0146-product-strategy-is-a-third-class-between-mechanism-and-tenant-values.md) 决定七；02 的 ADR；network-routing [`CONTEXT.md`](../../../docs/domain/network-routing/CONTEXT.md)「每个节点、网络连接和适用线路必须明确业务时区……跨节点时间按绝对时刻比较」「路由计划使用计划时间窗口、节点处理时间和衔接缓冲，不虚构尚未分配的精确班次时间」。

## 做什么

1. 服务日历、截单、节点处理时间与衔接缓冲的**形状**入目录，取值归租户。取数侧按各自业务时区解释、跨节点按绝对时刻比较，折出每个候选的时间投影。
2. 承诺上界按 02 定的来源（随请求或经端口）进证据。
3. 线路的连接序列折成候选段链；策略引用取判断时点适用的路由策略版本。
4. 初始路由与复核两处消费点经真取数侧拿到除成本外的全部事实族。成本缺席时按 03 的形态出局，结果如实——此时尚不能形成计划，是预期。

## 不做

- 不做成本（归 10）；不定任何租户的日历、截单或缓冲取值。

## 完成判据

- [ ] 真库用例：跨时区两节点的候选时间投影按绝对时刻正确；日历缺登的节点使候选在时间可行性上如实不可用，不补默认日历。
- [ ] 提交前重校经真取数侧成立：目录改一笔 → 视图修订变 → 重判（UC-NR-001 `AT-NR-010`）。
