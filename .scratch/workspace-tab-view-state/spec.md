# 公司主体工作区标签恢复界面状态

Category: bug
Status: resolved

## 来源与边界

用户反馈顶部工作区 Tab 切换后状态丢失。主责仍为 PN-02 / party-commercial、UC-PC-001 的管理台呈现，非关务专项，不改变领域规则与租户取值。用户明确要求只有其提出提交和 push 时才执行相关动作；本票保持本地改动。

原因：Layout 使用 `preserveInactiveTabContent={false}`，页面切走即卸载；本地 React 状态随之丢失。保留该卸载策略，工作区按标签保存已接入的临时呈现状态，回到标签时恢复；业务答案仍重新读取。页面地址与地址中的搜索词继续由 hash 负责。

## 完成判据

- 公司主体列表的生命周期筛选、注册地筛选、待处理筛选、排序与选中行在切换顶部标签后恢复。
- 恢复右侧详情当前页签、按时点查询输入、列表滚动位置与分栏比例，列继续按实际宽度适配。
- 列表与各对象标签的状态独立；关闭标签后释放其缓存，重新打开恢复默认界面状态。
- 缓存仅存当前工作区内存；不缓存业务答案、不常驻后台页面、不替代业务读口或地址权威。
- 未接入状态缓存的业务页维持既有行为。共享模板通过可选 `viewStateKey` 启用统一的分栏与滚动恢复机制，公司主体页配置稳定键。
- 浏览器标签往返、组件事件路径与前端三道门通过，完成非作者 Spec 评审。
