## 做什么

前端切片（只动 `apps/admin-web/src/**`，照 `docs/agents/workflow.md`「前端切片」）：设置区新增「单据编号」页，工作台形态。

- 列表：十一类单据，每行单据名（业务叫法）、此刻生效的格式与样例号、来源胶囊（产品默认 / 本公司规则）、重置周期、日期所用时区。
- 右栏：这一类的历次规则版本与生效时刻；类型代码、模板原文进技术详情。
- 登记：任务式表单「改用新的编号格式」——填模板与生效时刻，边填边调预览口显示样例号与「可能与已用号段重叠」的提示；按登记册配置写授予收起（ADR-0315）。模板令牌给一份中文说明（年、月、日、流水位数、加扰），不要求用户懂语法。
- 单据编号时区：页头显示租户此刻的单据编号时区，没登就醒目地写「单据编号时区未配置——开立方没有业务时区的单据（如运单、异常案件）暂不带单据号」，并给登记入口（同样按授予收起）。
- 诚实态：读口未配置 / 无权 / 读不到分开显示；没登记过的类型如实显示「产品默认」。

### 关键取舍与理由

- **格式只「读」不「判」**：页面把模板切成字面与部件只为读给人听；合不合法一律由预览口与登记口答（文法只在平台库一处，ADR-0355 决定四）。认不出的部件原样露出、不判错。预览说登不上时不放提交（那一刻提交必拒），预览答不出时照放（登记口自己判）。
- **重叠要勾选确认**：ADR-0355 越权风险点 7——需要号码连续的租户换格式前应先看重叠提示；只摆提示而不拦，一眼扫过就登了。
- **生效时刻按呈现时区填**：与管理台其他表单同一口径（`wallTimeToRfc3339` + 呈现时区），输入框旁写明「按 UTC+8 填写」；没给默认值，两个快捷钮只替人填。
- **单据编号时区不预选**：租户取值、产品不给默认（ADR-0355 决定七）；本机时区只作一键挑选。
- **时区中文名本页自己按此刻取**：网络页的 `timeZoneLabel` 按 1970 年取名，候选表里会出现偏移与名字对不上（America/Juneau 配 UTC-9 叫「北美太平洋标准时间」）；ICU 给不出中文名时交回 IANA 名，不把「GMT-11:00」当名字。网络页那份没动（不属本票）。
- **开立方叫法按类型给**：读口只答「按开立方业务时区」，不答开立方是谁；对账单写结算账户、送货预报与交接单写网点，表外的类型写「开立方」——04、05 若改声明，页面不会说错。
- **横幅放在工作台之上**：`WorkbenchPageTemplate` 没有横幅位，改模板属共享面（`templates/*`），本票不碰；横幅在页面层包一层摆。
- **号名是界面词**：「争议号」「应付单号」「案件号」「索赔号」「预报号」「交接单号」「委托号」由本票定在词典里（运单号取 ADR-0355 决定十一）；04–09 在各自页面上称呼单据号时可直接取这一册。
