# 09 渠道返回的面单载荷在领域、库与读面都没有落点

Category: enhancement
Status: resolved——裁丙并落 [ADR-0092](../../../docs/adr/0092-channel-label-payload-lands-as-a-reference-and-the-body-store-is-an-unconfigured-outbound-seam.md)：只落引用、本体存放是未配置的出向缝；三处落点齐，**本票无新迁移**（理由见文末），见「完成记录」
Blocked by: 04（已 resolved）、07（已 resolved）

## 缺口

面单交易聚合上与结果有关的字段只有 `ChannelParcelIdentifier`（包裹级标识）与
`ChannelResultReasonReference`（结果原因）；`LabelTransactionParcelResult` 只有
`parcel`/`accepted`/`identifier`/`reason` 四项，读面 `LabelTransactionParcelRow` 同形。

**全仓 `internal/` 下 `PDF`、`ZPL`（含小写）零命中**——这个数本身是论点，实测于 `957e768`。
`migrations/parcel_shipment/0010_label_transaction.sql` 的列与快照文档同样没有载荷或其引用。

也就是说：渠道把面单给回来了，本仓**没有地方放它**。

## 为什么被两票阻塞

- `04` 决定要留几份：只留渠道成品、还是成品加加工件两份。
- `07` 决定载荷的形态维度：一次结果可能有**多份图件**（UPS），粒度可能是**批**而非包裹
  （UniUni），格式可能是栅格也可能是指令流。落点形状要容下这些，而它们在 `07` 才定形。

先做本票会得到一个按单份、包裹粒度、单一格式写死的列，然后在 `07` 落地当天推翻。

## 做什么

定「渠道返回载荷」在三处的落点形状：聚合、库（`0010` 之后的迁移）、读面。**只定形状不定格式**。
一个要正面回答的问题：载荷**本体**入库，还是只入引用而本体去对象存储——这决定迁移与读面的
形状，且难逆转。

## 红线

- **具体格式取值属实例半边**（哪家给 PDF、哪家给 ZPL、DPI 多少），机制里不内置任何一个
  （[ADR-0088](../../../docs/adr/0088-label-channel-service-enters-the-first-release-service-forms.md) Decision 五）。
- 不可覆盖：同一次结果的载荷不得被后来的调用顶替，更正走版本或追加。

## 完成判据

三处落点各有形状并同笔落地；`gofmt -l` 空、`go build`/`go vet` 退 0、
`go test -count=1 ./...` 绿并注明含不含真库（**本票动迁移，真库必须实跑**）。

## 参照

[能力形状盘点](../capability-shape-inventory.md)第一段与第五段；票 `04`、`07`。

## 取证：那一问的选项空间比票面写的窄

2026-09-02 由 MCP-1 取证于 `13bc515`。**本节只记事实与由它推出的约束，不替产品拍板**——
「本体入库还是只入引用」难逆转，按 [AGENTS 改文档](../../../AGENTS.md#改文档)要走 ADR，等一次裁决。

**一、本仓今天没有任何对象存储依赖。** `go.mod` 直接依赖仍是三个（`go-chi/chi/v5`、
`jackc/pgx/v5`、`idp-bento-go`），按 `s3`／`minio`／`blob`／`bucket` 扫 `*.go` 与 `go.mod`
无一处生产命中。

**二、框架也没有文件能力。** `idp-bento-go@v0.1.0-rc.2` 的顶层包是 `api`、`application`、
`compat`、`domain`、`eventing`、`infra`、`internal`、`postgres`、`repository`、`testkit`；
按 `file`／`blob`／`storage`／`object`／`attach`／`document` 递归扫其目录名**零命中**。

**三、而产品基线把「文件」划给了技术组件，不划给本产品。** 它「独立项目边界」一节写明：公司级
身份认证、审计、消息、**文件**、配置和可观测性等能力**只能通过有版本及兼容性约束的技术组件
复用**，且技术组件不得取得本产品业务数据所有权。

三条合起来把选项挤成这样：

- **甲·本体入业务库**（`bytea` 列）。今天就能做、与结果同事务，但它让本产品**拥有了文件**——
  与上面第三条正面相抵；且面单是逐包裹或逐批产生的二进制，随业务量线性涨进业务库，备份与
  恢复成本跟着涨。
- **乙·只入引用，本体去对象存储**。合第三条，但**那个组件今天不存在**（第一、二条）。现在做
  就要新引一个直接依赖，而「直接依赖只有三个」这件事本身被[开发主线](../../../docs/product/PARCEL-NETWORK-FIRST-RELEASE-DEVELOPMENT-BASELINE.md)当作「参数显式未配置」的佐证在引用——票 `04`
  当初把清点工具做成嵌套模块，避的就是同一件事。
- **丙·引用形状现在定，存放处按未配置格留空**。聚合与库只存**引用**（定位符、完整性摘要，
  连同 `07` 已定的角色／格式／粒度声明），本体存放交一个出向端口，真组件就位前如实答未配置。
  这是本仓机制半边／实例半边的既有分法，未配置格形状 ADR-0052／0054／0055／0090 已成建制；
  代价是真组件就位前演示看不到面单本体，而那与九个端点今天一律答未配置是同一种诚实。

**不论哪一个，红线「不可覆盖」都要求落点是版本或追加形状，不是一列可改的值。**

**待裁**：甲／乙／丙取哪一个。裁完再动迁移——本票动迁移，而迁移那一组是共享接线文件里最凶的
一种（[并行会话](../../../docs/agents/parallel-sessions.md)「共享接线文件」一节：占号、四件同笔、
`add` 前逐块核），开工前要先在频道占号。

### 本票没有新迁移，这不是漏做

票面写「库（`0010` 之后的迁移）」「本票动迁移，真库必须实跑」，那是在「本体可能入库」还没被
否决时写的。裁丙之后落的是**引用**——几个字符串加一个时间，与本聚合其余追加式清单（逐包裹
结果、后续动作）同形，走既有的 `snapshot jsonb`，没有新列也没有新表。为满足票面那句话去造一张
表，是拿结构迁就一句已经失效的假设。

**真库实跑那一半照做了**，只是证的东西换了：`label_transaction_document_test.go` 三条对真
PostgreSQL 证快照往返——批粒度件覆盖两件包裹且本体未存放、重打追加之后原条仍在且顺序即追加
顺序、以及**旧快照（无载荷字段）照样读得回来**。最后那条是不加迁移换来的义务：`omitempty`
让历史行读回一笔没有载荷的交易，那正是它当时的真相。

### 摘要必备、定位符可缺，这一格是裁决的核心

摘要证明**我们确实收到过这份件**，定位符回答**它此刻在哪**。合成一格，「收到了但没处放」就
表达不出来——而在文件组件就位之前那是唯一走得到的分支。`BodyStored()` 因此派生自定位符在不在，
不另存一格（同 `Finalized()` 的理由）。

摘要必须在字节还在手上时算出，这一点写进了端口注释：漏算就永久失去了那份证据，事后补不回来。

### 粒度枚举从 `ports` 挪进 `domain`

票 `07` 当初把它放在 `ports`，因为那时它只是线上的形状。载荷进了聚合之后它成了那条记录的结构
分叉，留在 `ports` 会成两份——领域不能 import `ports`（会成环），那边只能再声明一个同名枚举，
两份迟早在某一格上分家。角色与格式没有跟着挪：它们是渠道声明的自由取值，不做封闭集合。

### 追加门与重建门刻意宽严不同

`AppendLabelDocument` 不收`失败`格——整笔未受理不会产生面单。**重建门收**：一行`失败`带着载荷
完全可能是本上下文写出来的（件在`已提交渠道`时追加，结果随后才记成失败）。重建门以结果自证
一致、不逆推形成过程，这与 `RehydrateLabelTransaction` 原有的取法同源。两侧共用同一个
`labelDocumentRecord` 做结构校验，不抄第二份。

### 读面上载荷挂交易级，不挂包裹行

一份批粒度件覆盖多件包裹，挂到包裹行就等于复制成 N 行——那正是票 `07` 的端口形状当初拒绝的
「拆成假的逐件」。读面那一行自带覆盖范围，要按包裹看就从它过滤。读面也不摊定位符：查阅回答
「有没有这份件、它是什么、本体拿不拿得到」，本体在哪是存放端口的事。

### 欠一笔：ADR 索引条目

`docs/adr/README.md` 此刻带着另一会话未提交的两处改动（ADR-0078 停用批注与 ADR-0091 索引行），
而 `git commit --only` 对某个路径取的是它工作树的全部内容——一并提交会错记归属，且那条索引行会
指向一个尚未入库的 ADR 正文。按[并行会话](../../../docs/agents/parallel-sessions.md)「索引文件
不属任何人」那一节的先例（「索引随该文件另行提交」），**ADR-0092 的索引条目本笔不带走**，待
那份改动落定后补。
