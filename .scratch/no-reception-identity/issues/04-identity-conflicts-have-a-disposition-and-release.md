## 裁定（2026-10-19，会话 idp-parcel-9b 代决；用户 2026-10-16 授权「你作为业务和系统专家你来自决」）

1. **先做人工处置，不做自动解除。** 处置是一种运营决定，走操作者渠道，按运营决定族归属（ADR-0151）；谁持有这一种授予属租户取值，仓内不写默认、如实答未配置，演示租户在种子里配。歧义信号消失后的自动解除要 PS 在委托被拒绝或撤回时另交信封，记作后续方向，本票不做。
2. **处置落成追加版。** 处置是对这件作业实物当前有效判断的又一版：指名前版（ADR-0199 的版本链），带处置依据引用与操作者；两种结果——关联到冲突候选中的一件，或确认不是其中任何一件（留作待识别、不记冲突，可再经重核）。原判断与冲突行永久保留，只追加、不覆盖。关联到某一件时，那一件若已关联到别的作业实物（ADR-0196），处置前须先处置那一件，或在同一次处置里同时指明两件各归何处——取哪种由 ADR 定。
3. **方向依据的身份一格改读每条判断链的当前有效版本，不再对全部行取或。** 处置版一落、它所在链的当前版本不记冲突，这一格就解开。第一期之前落下、没有前版的旧冲突行各自是一条链的当前版本，照旧判冲突（不回填，同 ADR-0199）。
4. **一码两物里先到那件已被 PS 采用的那次（ADR-0196 决定五）**：处置不撤回已交出的意图；处置把它关联到另一件包裹时交一封新的收寄意图，由 PS 侧按已有采用规则处理，VE 协调仍在 ADR-0196 决定五的范围里。
5. 难逆转的写进 ADR-0210；先改 NO CONTEXT「待识别实物与身份关联」里身份冲突那一格与方向依据的读法，再改 UC；处置命令口归哪份 UC（UC-NO-002 的延伸还是另立）由 ADR 定。

越权风险点：代 NO owner 定了「方向依据改读链头」——它改了 no-directional-basis/01 已落的读法，owner 复核时看有没有依赖「任一行记冲突即冲突」的读面。

## 现象（读文档与码）

身份冲突今天有三个来源：一码两物（ADR-0196）、身份核对多候选、号码另有未接受委托的声明（ADR-0195 歧义信号）。三者都在收寄册上落下记身份冲突的行；`JudgeIdentityBasis` 只要任一行记冲突就判身份冲突，方向性作业对这件实物一直停住。没有任何入口能处置或解除它：ADR-0199 决定三明写「记身份冲突的不重核……那要身份冲突的处置能力」；ADR-0196「Consequences」写「解除要等身份冲突的处置能力（未立票）」。

## 要裁的问（分诊时定，难逆转的进 NO ADR）

- 谁处置：复核页上的人工处置，还是按规则自动解除（例如歧义信号所依的那份委托被拒绝或撤回之后，重核即可解开）？两者是否都要。
- 处置落成什么：照「只追加、不覆盖」追加一版带关联（或确认独立）的判断，方向依据的身份一格怎样读「已处置的冲突行」——今天它对所有行取或，处置版要能盖过它。
- 一码两物里先到那件已被 PS 采用的那次（ADR-0196 决定五「交 VE 协调」）与处置的关系。

**ADR-0210 摘要**

- 决定一：身份冲突只经人工处置解除。「运营决定」能力面加决定种类「身份冲突处置」，谁持有授予是租户取值（`PAR-INT-08`），仓内不写默认，演示租户在种子里配；授予之外不问 PC；不做自动解除（要 PS 另交信封，记作后续方向、不立票）；重核与再次收寄都不解除。
- 决定二：对象是主实物与调用方指名的「所处置的版本」（须是链头，且各链合起来判冲突）；处置候选是各链当前有效版本上的候选与关联；两种结果——指定其中一件，或确认都不是；必带处置依据引用，操作者写作 `OPERATOR/<发行方>#<sub>`。没有冲突的实物不能单独处置。
- 决定三：主实物每条判断链的当前有效版本各追加一版处置版，指名前版；收寄事实与控制照前版、业务时间是原接收时刻、不另起控制起点；指定一件那几版照 ADR-0186 取服务结果；处置文档自带形状版本；派生来源标识 `IDENTITY-DISPOSITION/<前版>`；来源文档取链起点那一版的。
- 决定四（裁定二交给 ADR 的那一格）：**取「同一次处置同时指明」**——指定的包裹此刻关联在别的实物上时，请求须把它们列为连带实物，同一笔事务各追加「不是它」；不取「先处置那一件」，理由是中间的空窗会让贴同号的第三件唯一关联并交意图、「这件是 X」与「那件不是 X」本是一个决定、那件可能根本没有冲突而不能单独处置。连带实物的处置候选须恰好只有 X。取锁先实物后包裹。
- 决定五：方向依据身份一格只读没有后继的形成与待识别两种行，折法其余不变；ADR-0196 先到那件在第一期之后落缺少·{待识别, 身份冲突}，第一期之前的旧冲突行照旧判冲突，不回填。可先于处置落地。
- 决定六：命令口挂「运营决定」操作者 Intake；重放身份是（租户，所处置的版本）；同内容答已有结果、异内容答已处置（都回显在册的那次），被别的版本接续答版本已换代；比对格是结果、指定的包裹与连带实物集合，依据引用与操作者不比；业务拒绝三格；坏载荷 400。
- 决定七（裁定四）：指定一件且主实物此前没就它交过收寄结果时交一封意图（多链只交一封，落在接收最早那一版）；都不是与连带实物不交；已交出的不撤回。
- 决定八：`FindOtherUnitIntakes` 与 `ParcelContainmentView` 认「处置截断」——被处置版接续过的行不再算，还没处置过的照旧；这两面不读链头。
- 决定九：「都不是」那一版照常重核，但 PS 唯一命中的包裹在它排除之列时不追加。
- 决定十：处置命令口另立 UC-NO-004，不并进 UC-NO-002。
- 越权风险点含裁定末尾那一条（改读链头改了 no-directional-basis/01 的读法与 ADR-0196 决定四的折法）、「正式身份由 PS 确认」的读法、不问 PC、处置截断超出裁定字面、「处置」同字、重核例外、连带实物的限制、逐链追加写到没看过的链、意图可能落在已被 PS 为别的实物采用的包裹上。

**发现**（不改裁定；需要的都已在 ADR-0210 越权风险点点名）

- **「正式身份由 `parcel-shipment` 确认」与裁定一相抵的读法。** GLOSSARY「待识别实物」、NO CONTEXT 生命周期「`parcel-shipment` 确认正式身份 → 建立带适用时间的版本化关联」与 SCENARIOS 场景九都写 PS 确认；裁定一让节点的人在 PS 的候选里定。ADR-0210 读成「正式包裹由 PS 给出与确认，实物与包裹的关联归节点」（CONTEXT-MAP 本就写节点拥有「实物身份候选与冲突」），这几处原句没改，只在 GLOSSARY 与 CONTEXT 旁边补了处置；越权风险点 2。
- **「处置」与 NO CONTEXT「不能凭异常案件、现场备注或操作权限自行形成处置决定」同字。** 字面上像是裁定一让节点凭操作权限形成处置。CONTEXT 加了一条写明身份冲突处置不是那种改变实物去向的处置决定，名称一律写全；越权风险点 5。
- **只改身份一格读链头，处置会被别的读面推翻。** `FindOtherUnitIntakes` 与 `ParcelContainmentView` 按行读关联：处置成「不是 X」之后，贴同号的第三件仍会给它追加冲突版，在袋查询仍把它算作 X。这两面若也改读链头，又会在处置之前让第三件唯一关联到两件正在争的 X。ADR-0210 决定八取「处置截断」，超出裁定字面；越权风险点 4。
- **裁定二「可再经重核」会把处置推翻。** 「都不是」那一版是重核对象，人工重核或同号再签的关联交出的信封会让它唯一命中被排除的那件、关联回去，那件若在别的实物上还会给对方追加冲突版。ADR-0210 决定九加了例外，部分停用 ADR-0199 决定三分格；越权风险点 6。
- **裁定二的「又一版、指名前版」是单数，一件实物却可能有几条判断链**（第一期之前没有前版的冲突版各自成链；不同节点各有收寄）。只接一条链，身份一格读另一条链的链头仍判旧关联或冲突，裁定三「这一格就解开」不成立。ADR-0210 决定三取逐链追加；越权风险点 8。
- **ADR-0196 决定四对先到那件的原因集变了**（{身份冲突} → {待识别, 身份冲突}）。现有两份一码两物真库用例只断言「含身份冲突」，不受影响；票 05 逐条核。
- **adr/README 的部分停用约定要求改被停用记录的 Status 行与 Links 节各加前向指针**；本票照派活说明「旧 ADR 文末追加复核记录、决定原文不动」，没动 0196、0199 的 Status 行（两份也没有 Links 节），前向指针在复核记录与 README 行上。推送方若要补 Status 行，`git diff` 自检的口径要随之放宽。

- **产品基线 PN-03 一行只列 `UC-NO-002/003`**，本票没改基线（它高于用例），是否补 UC-NO-004 由推送方定。
