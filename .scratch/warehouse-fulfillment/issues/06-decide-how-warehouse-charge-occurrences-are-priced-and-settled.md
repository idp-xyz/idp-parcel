# 06 仓储作业费的计价与结算

Category: docs
Status: in-progress——2026-11-11 认领，分支 `cursor/wf-charge`（工作树 `idp-parcel-wf-charge`，基线 `48ca93e2d`）
Blocked by: 无

依据：ADR-0368 决定七把仓租按持有期计价留给「另立 ADR」；CONTEXT-MAP「关系约束」`warehouse-fulfillment → parcel-pricing / settlement-accounting` 一条写着「同一份 ADR 还要定结算怎样为它发起 SELL 请求、它的商业依据在哪一刻由谁固定、用什么确认依据确认。」；UC-SA-002「给开发的交接」仓储那一行的承接格写「计价评价对象与结算发起、商业依据、确认依据的 ADR 先行」。这份 ADR 还没有。

另受 [ADR-0375](../../../docs/adr/0375-warehouse-fulfillment-is-an-optional-capability-on-its-own-pn-09-slice-off-per-deployment-unless-switched-on-and-unconfigured-per-tenant-until-registered.md) 决定三、四约束：结算与计价消费仓配事实的几处只在有仓配事实时被触发；开关关着时派发不登记仓配自己各类信封的路。结算发起评价请求的触发面要落在这两条之内。

## 要做的

按 /grill-with-docs 写一份 ADR，定下面各格，并同笔改小包计价 CONTEXT、结算与经营核算 CONTEXT、CONTEXT-MAP 那一条、UC-SA-002 与 UC-PP-001「给开发的交接」。

- **计价的评价对象**：仓储作业收费发生项进小包计价 CONTEXT「评价对象」。各作业种类按哪些计量与作业属性判条件（两词见仓配履约 CONTEXT「收费发生项」）。
- **仓租**：库龄段、免租期、淡旺季、按体积或按库位计，怎样落进价卡结构；库龄口径两种怎样进评价输入；要不要换规范化版本，换的话过 ADR-0352 的部署门。
- **未测量**：仓测尺寸重量缺席时，评价能不能用货主声明的那一份（仓配履约 CONTEXT 把这一格留给计价）。
- **结算怎样发起 SELL 评价请求**：时点与触发面（发生项已形成的信封，还是别的）。
- **商业依据**：发生项不带接受时的商业解析。责任法人、结算相对方、结算账户、合同或责任依据与主要计费范围在哪一刻、由谁固定。
- **确认依据**：内置的确认依据只有包裹的`有效交付已终局`，仓储费用项目用什么确认。
- **更正**：发生项的更正版本怎样成为费用调整。
- **BUY 侧**：代理仓与外包仓向租户收的费，UC-SA-002 已记首版不做；本票只确认这一格不动。

参照出处见票 01「裁决」里收费发生项与仓租各条所引的领星 OMP 报价公开帮助文档；外部页面会变，以落进票面的要点为准。

不动 `internal/**`。

## Comments

### 2026-11-11 调研记录（未完）

取证于 main `48ca93e2d`。小包计价一侧由调研子代理通读后交回，下面是它的结论；原句与实测我没有逐条复核，写 ADR 时要重核。结算、参与方与商业一侧的调研没做成：子代理起来之后被网关以余额不足停掉，那一半待查。ADR 还没动笔。

**小包计价现状**

- 评价对象是封闭集，`EvaluationSubjectKind` 取 `ACCEPTED_PACKAGE`、`ESTIMATE`、`SHIPMENT`、`MASTER_DOCUMENT`。小包计价 CONTEXT「评价对象」写「它有且只有四种」，ADR-0171 决定四写「不给 `EvaluationSubjectKind` 加第五种。」（原指集运单元）；加仓储作业收费发生项要改写这两处。
- 选卡只按（租户、计价范围、方向、目的、计价基准时点），不认对象也不认客户；ADR-0260 的越权风险点记着同一计价范围只有一张在用 `SELL` 卡。仓储卡要另立计价范围，按货主议价就是一货主一范围。
- 价卡文法的骨架写死重量与分区：方案必带重量价表与重量策略，已完成的评价必有基础运费行、计价重量与命中费率。数量乘单价只有重量（`UnitPriceRate`），首重续重的量纲是重量，档位只有重量上下界；数值特征的量纲没有天数与件数；类别条件只有相等。唯一的非重量乘法是 `ChargeUnitPerPiece`（定额乘成员件数，只许票级、主单级的卡）。所以仓储费不是加特征词汇能表达的，要加文法、换规范化版本。
- 一份评价一个对象、一条基础运费行，费用代码评价内唯一；逐行算费再求和没有先例。ADR-0364 决定三讲的是计价重量的聚合，而且还没实现。
- 零金额：`Money` 只拒负数，档位价与定额可以为零；ADR-0348 否决过用零表达缺档（「零与「卡上没有这一档」是两个答案，后者该是待判断。」）。整份合计为零时结算记`负向结束（零额）`、不建费用行；一份评价的全部费用行要映到同一个费用项目才形成费用。
- 规范化版本：基础版 `PPC-5`，本构建认的最新版 `PPC-6`。ADR-0364、ADR-0365 已接受、没实现，占着「下一版」。只加枚举取值照现行读法不换号（ADR-0347 的先例），那样 ADR-0352 的登记门拦不到。
- 未测量：小包计价 CONTEXT 写「某一计算目的是否拒用申报，是未确认规则——保持可配置或显式未决，不预设。」ADR-0171 决定二说的是包裹的客户申报对节点实测，照搬到仓测要另说理由。输入解析器今天不读价卡。
- 单位：换算只接重量与长度（ADR-0346 决定六）；内置目录有体积与件数，没有票、箱、托、天、库位·天。
- 淡旺季：价卡换版要显式收尾（ADR-0234），漏了就是适用冲突；按序列作百分比附加只能借 `FUEL_RATE`，而 ADR-0013 说序列的数值来自承运商公布费率或财务侧牌价，租户自定的系数不是。
- 调研员实测到一处既有缺陷，待复核：类别条件的期望取值不进价卡内容摘要，两份只差 `ZONE` 期望值的方案 `ContentDigest()` 相同（探针经 `go test -overlay` 跑，没落仓库）。仓储的作业属性条件全是类别相等，这一处要先处置；修它就是加键换号。

**领星 OMP 的报价结构**（公开帮助文档，取证于 2026-11-11：[仓租费](https://help.xlwms.com/2f8e/a8f8/06d0/7479)、[操作费](https://help.xlwms.com/2f8e/a8f8/06d0/49ea)；外部页面会变，以这里摘的为准）

- 仓租：按体积或按库位。规则是库龄阶梯乘十二个自然月的单价，淡旺季靠月份单价表达。按体积另有最小计费体积与批次体积进位（按单个库存、按同一批次总体积、按同一库龄段总体积）；免租期的体积照计、金额为零。按库位的按库位类型分别配阶梯与单价，没配的库位类型不产生仓租，有货即占整库位，库位清空后库龄归零。产品库存、箱库存、退货库存各设规则。T+1 出费用；规则改了次日起生效，已生成的不重算，可以手动重新计费。
- 操作费（入库、出库）：一条规则是至多三个条件变量（区间或多选）对一个计费变量（票、箱、托、SKU 数量、重量之类），带减免量、单位数量、是否进位、单价、基础费、最低收费与最高收费。出库常按票总重收基础费、按 SKU 数量收续件费，并按物流渠道（仓库物流、平台物流、自提）区分。重量可取实重，或实重与体积重取大。
- 增值服务：固定计费变量与单价，下单时勾选即自动计费。
- 计费项绑定报价方案，报价方案生效后才收费。

**待查（结算、参与方与商业）**

- 包裹 `SELL` 客户费用的全链：发起、请求内容、商业依据固定了哪些格、预估与确认、ADR-0343 的转扣费、归属日。
- 运输收费发生项 `BUY` 一路的信封与请求形成（ADR-0208），发生项更正怎样成为成本更正。
- 确认依据是不是封闭集、`settlement-moment` 册登什么；各本采用册的键与格；计价范围在结算一侧的来处。
- 参与方与商业的解析键登记行、商业范围与费用范围；能不能为（货主客户账户，费用范围，业务时点）解出合同、结算政策与价格政策。
- 没有接受前冻结的费用确认时怎么记、余额不足怎么办；周期费用执行器与逐笔费用的关系；`输入不可得`有没有续办触发。
