# 06 仓储作业费的计价与结算

Category: docs
Status: ready-for-agent
Blocked by: 无

依据：ADR-0368 决定七把仓租按持有期计价留给「另立 ADR」；CONTEXT-MAP「关系约束」`warehouse-fulfillment → parcel-pricing / settlement-accounting` 一条写着「同一份 ADR 还要定结算怎样为它发起 SELL 请求、它的商业依据在哪一刻由谁固定、用什么确认依据确认。」；UC-SA-002「给开发的交接」仓储那一行的承接格写「计价评价对象与结算发起、商业依据、确认依据的 ADR 先行」。这份 ADR 还没有。

## 要做的

按 /grill-with-docs 写一份 ADR，定下面各格，并同笔改小包计价 CONTEXT、结算与经营核算 CONTEXT、CONTEXT-MAP 那一条、UC-SA-002 与 UC-PP-001「给开发的交接」。

- **计价的评价对象**：仓储作业收费发生项进小包计价 CONTEXT「评价对象」。各作业种类按哪些计量与作业属性判条件（两词见仓配履约 CONTEXT「收费发生项」）。
- **仓租**：库龄段、免租期、淡旺季、按体积或按库位计，怎样落进价卡结构；库龄口径两种怎样进评价输入；要不要换规范化版本，换的话过 ADR-0352 的部署门。
- **未测量**：仓测尺寸重量缺席时，评价能不能用货主声明的那一份（仓配履约 CONTEXT 把这一格留给计价）。
- **结算怎样发起 SELL 评价请求**：时点与触发面（发生项已形成的信封，还是别的）。
- **商业依据**：发生项不带接受时的商业解析。责任法人、结算相对方、结算账户、合同或责任依据与主要计费范围在哪一刻、由谁固定。
- **确认依据**：内置的确认依据只有包裹的`有效交付已终局`，仓储费用项目用什么确认。
- **更正**：发生项的更正版本怎样成为费用调整。
- **BUY 侧**：代理仓与外包仓向租户收的费，UC-SA-002 已记首版不做；本票只确认这一格不动。

参照出处同票 01 裁决 23、24（领星 OMP 报价的公开帮助文档）；外部页面会变，以落进票面的要点为准。

不动 `internal/**`。

- 部分停用照 `docs/adr/README.md` 顶部的写法挂指针；ADR-0368 越权风险点 4 由本 ADR 回答，注记里写明。
- 小包计价 CONTEXT 与结算 CONTEXT 的新规则能回指 ADR 的某个决定；UC 交接行写明规则与实现的差距。
- 只改 `.md`；进 main 前一份非作者评审，并代 PP 与 SA owner 各看一遍。
