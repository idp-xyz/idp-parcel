# 11 首方客户面、一线作业端与接入词表

Category: docs
Status: ready-for-agent
Blocked by: 07、08、09、10

依据：ADR-0368 Consequences「首方渠道要为货主新开入库预报、出库请求与库存查询这些客户面口」，决定六把一线作业端扩到仓内作业；ADR-0375 决定五「进仓配各面要有授予」。票 07 至 10 的用例各自点名了要哪个接入面，本票把它们收成对外契约。

## 要做的

- [首方客户 API 契约](../../../docs/api/first-party-api-contract.md)：补仓配各口（入库预报、告知更新与撤回、出库请求、出库截单、自备面单补交、退货预报、加工与商品换标指令、库存与出库请求查询），重放与问题详情照该契约既有各节。
- [一线扫描离线与冲突决策简报](../../../docs/design/frontline-scan-offline-and-conflict-decision-brief.md)：仓内作业的离线动作集合、出库确认放行条件的下发与有效区间。
- 接入词表：客户面能力、运营决定种类、作业范围种类各加哪些词，写成一份 ADR（它们进 `internal/accessidentity`，归接入身份 owner）。同一份 ADR 要明说仓、库区与库位的登记走哪一族：登记册配置写与运营查阅读两族不分上下文，持有它们的操作者就能登记仓（ADR-0375 越权风险点 5），要不要为仓配另开能力面在这里定。
- ADR-0375 决定四留下的那一格：开关关着时仓配端点怎么答。本票写出两种做法各自动到 ADR-0055、ADR-0222 的哪一句，交第一张落端点的实施票定。

票 07 的用例点了名、要在本票收成契约与词表的（都是暂名，出处在各用例「给开发的交接」的接入词一行）：

- 客户面能力：「商品维护」「入库预报提交」「入库预报告知更新」「入库预报撤回」「收货差异确认」「仓配查阅」。
- 运营决定种类：「商品代录」「入库预报代录」「收货差异结论代录」「入库预报完结」「待认领到货认领」「待认领到货处置」「建账导入提交」。票 08 至 10 还会加；这个封闭集由 `migrations/access_identity` 里 `operator_grant_decision_kind_decided` 那道 CHECK 守，每加一种都要重建它，收齐之后一次进词表与迁移，不分批。
- 作业范围种类「仓」；作业事实类型「收货确认」「仓测登记」「待认领到货登记」。`internal/accessidentity` 的 `WorkScopeKind` 今天是封闭的两种（节点、场外），一台设备只登记在一个作业范围上，请求的范围与设备登记的不同即答 `ErrDeviceNotInUse`；节点与仓同址、共用手持机时同一台设备进不了两个范围。词表的 ADR 先答这一格。
- 客户面的读：仓，商品与仓测，入库预报（含现行的告知、累计实收与单据号），逐次收货，收货差异，库存与流水。待认领到货与建账导入单首版不上客户面（`BD-WF-012`、`BD-WF-014`）。
- 货主读口上的代录标记：每个商品修订，预报的提交、各版告知与撤回，每个差异结论，各带途径；代录的另带依据引用，不带录入的操作者；被取代的代录结论照留、货主读得到。逐次收货带逐行结果，未入账的行带原因（UC-WF-002、UC-WF-003、UC-WF-004）。
- 从载荷收货主客户账户的几口：商品代录（UC-WF-002）、入库预报的代录提交（UC-WF-003）、待认领到货的认领（UC-WF-005）、建账导入的提交（UC-WF-006）。ADR-0151 决定二写「身份格只从信封与授权答复来，逐口照现有契约取，不从请求体收。」这几口是新建对象，或给还没有货主的对象指名货主，没有在册的对象可以取，货主客户账户在用例里写成业务内容；词表的 ADR 写明这几口照哪一种读。指名在册对象的代录（预报的告知更新与撤回、差异的结论）货主已经取自所指的对象。
- 登记册配置写不分上下文：持有它的操作者能登记、也能停用任何一个仓，停用会挡住新的入库预报与建账导入。票 07 的评审里代接入身份 owner 看的意见是任何生产部署打开开关之前要有答案（UC-WF-001 的交接）。
- 由收货事实转来的待认领到货，要不要在原预报的读口上标出「另有到货待认领」（`BD-WF-012`，UC-WF-005 的交接）。
- 货主口各写命令的来源请求键各取命令前缀，进首方族的保留前缀表（ADR-0310 决定一）；加前缀之前先核已存的提交标识（同一份 ADR 的越权风险点 1）。
- 各写口判准入范围用的能力词与事实类型词（ADR-0180）。
- 一线作业端的下发与离线边界：库区与库位，商品、别名与包装层级，可收货的入库预报与它现行那一版告知（仓按到货线索找预报；离线时手里是哪一版），收货暂存库位。
- 离线记下的收货到达时可能整条答收货内容不合（计量单位与跟踪属性按入账那一刻的当前修订判，UC-WF-004）：设备怎样把这一格呈现给作业人员、怎样补齐重交。
- 建账导入的提交与演示种子要不要一个受控批量口：「运营决定」面今天有没有批量口，票 07 没查。

不动 `internal/**`。

## 完成判据

- 每个口能回指一个 `UC-WF-*`；契约里不出现 UC 没有的行为。
- 词表只加有来源的词：每个词指得到用它的那个用例。
- 只改 `.md`；进 main 前一份非作者评审，并代接入身份 owner 看一遍。
