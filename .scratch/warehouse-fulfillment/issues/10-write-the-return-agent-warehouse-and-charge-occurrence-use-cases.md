# 10 写 `UC-WF`：退货、代理仓与收费发生项

Category: docs
Status: ready-for-agent
Blocked by: 05、06、07、08、09（收费发生项挂在票 07 至 09 写成的作业事实上，并要回填它们的指针）

依据：[仓配履约 CONTEXT](../../../docs/domain/warehouse-fulfillment/CONTEXT.md) 的「退货」「代理仓」「收费发生项」词条与规则，「退货入库」「代理仓库存声明」两条生命周期；ADR-0370 决定三；[ADR-0377](../../../docs/adr/0377-warehouse-charge-occurrences-are-a-fifth-evaluation-subject-priced-by-measure-fee-rules-and-settlement-requests-a-sell-evaluation-on-the-occurrence-formed-envelope.md)（收费发生项怎样被计价与结算消费，决定十二是它替仓配履约定下的几条）。

## 要做的

在 `docs/application/warehouse-fulfillment/` 下写用例。建议的切法，以写成的为准：

- 退货预报、退货入库与回库处置。
- 代理仓库存声明的接收、过期与被取代；代理仓出库经连接器转出与结果保全。
- 形成仓储作业收费发生项：各作业种类在哪个作业事实上形成，仓租按（货主，仓，计费日）每日形成，重放与更正。

CONTEXT 没写、要在本票定下的：

- 代理仓连接器的形态（照公开规范或模拟源；接哪家、协议细节与凭据是租户取值）。
- 仓租日结由什么触发，日终取数的时点与补算。
- 发生项交给计价与结算的信封与读口，照 ADR-0377 决定八、十二：形成发生项与追加更正版本同笔交「仓储作业收费发生项已形成」信封，只带（租户，发生项，版本）；只读口按（发生项，版本）答，结算读货主客户账户、仓、作业种类、业务时间与更正关系，计价读计量、作业属性与明细行。
- 各作业种类的计量单位、作业属性名与明细行种类的词表，逐种类列全（ADR-0377 决定五把词表判给仓配履约，计价的特征词表照它扩充）；同一层面一个计量单位至多一个计量。
- 重量与体积类计量的单位按仓登记：登记口，没登记时要带这类计量的发生项不形成、答未配置。
- 更正版本的两种（重述、作废）各由哪些来源事实的更正触发；未测量的计量日后补测，对此前带着未测量的各份发生项追加重述版本。
- 仓租发生项的两种明细行（入库批次行、库位行），以及它带出所用的库龄口径。
- 发生项的业务时间逐作业种类写明取哪一刻（ADR-0377 决定十二：仓租取计费日在仓的业务时区里的起始时刻，别的取作业事实发生的时刻）。
- 词表里的作业属性每份发生项（每一行）都带，没有那样东西的带产品内置的「无」；计量与属性逐个写明取自哪个作业事实。
- 版本链是线性的：更正版本指名被更正的那一版，一版至多被更正一次；作废之后可以再重述。
- 库龄口径没选、仓的计量单位没登记期间没形成的发生项，登记之后怎样补形成（ADR-0377 没有定，留给本票）；仓的计量单位登记追加新一版之后只作用于此后形成的发生项。

票 07 写成之后留给本票的（各格的现状写在所指用例的「给开发的交接」，本票写成之后回填指针）：

- 入库作业发生项以收货确认这一作业事实为来源（UC-WF-004）。收货行上带了实点箱数，托数与柜型没带；到仓方式在入库预报上。
- 到仓方式在入库预报受理之后不改（UC-WF-003）；实际到仓的方式与预报声明的不同时，入库作业发生项上到仓方式那一格取哪一个。
- 离线迟到的收货，入库时间取入账那一刻，库龄从入账那天起算（UC-WF-004）；写仓租时核一遍这是不是要的口径。
- 已有一版仓测之后再测一版，要不要更正此前已形成的发生项（UC-WF-002）；CONTEXT 只写了未测量日后补测的那一种。
- 仓测照测得的单位保存、不折算；发生项里重量与体积类计量按仓登记的单位给，两者不同时怎么给（UC-WF-002）。
- 库位可以不带库位类型（UC-WF-001）；仓租库位行上的库位类型这时怎么带，照 CONTEXT「作业属性」词条核一遍。
- 建账导入不形成入库作业发生项；声明的入库时间早于入账那一天时，入账之前的那些天补不补仓租（UC-WF-006）。
- 以库存调整更正一笔收错的收货，算不算入库作业发生项的来源事实被更正。
- 退件的认领之后按退货入库入账，入账怎样引用那件待认领到货；退货入库登记时认不出货主的怎样转成待认领到货（UC-WF-005）。停用的仓不受理新的退货预报（CONTEXT「主数据登记」）。
- 待认领到货的处置只记决定：实物怎么办、要不要形成收费发生项（UC-WF-005）。
- 收货差异的结论带途径（货主本人或代录）。代录的「已确认」可以被货主本人此后的结论取代，改成有异议，没有期限（UC-WF-004「一致性、幂等与并发」）：本票的用例与交给对账的读口凡带出收货差异结论的，一并带出途径，不把代录的「已确认」等同货主本人确认，也不把它当不会回退的终态（票 07 第二轮评审代仓配履约 owner 与代产品 owner 看的条件）。

票 08 写成之后留给本票的（各格的现状写在所指用例的「给开发的交接」，本票写成之后回填指针）：

- 加工发生项的来源事实是加工或拆解入账的那一笔（UC-WF-008 的「加工已入账」）。商品换标是增值服务项目，来源事实是「换标已入账」；CONTEXT「商品换标」词条写租户可以把贴标与换标分开计费，从没贴贴上、换成另一个与去掉三种怎样分，本票写。开箱要不要作增值服务项目，UC-WF-008 没有写。
- 销毁发生项「在销毁入账时形成」，来源事实是 UC-WF-011 批准成立、以销毁流水出账的那一笔；计量、明细行与作业属性没有写。回库处置的销毁走不走 UC-WF-011 的库存调整，本票定。
- 移库、拣选位补货、形态转换、次品转良品与盘点要不要作增值服务项目计费（UC-WF-007、UC-WF-010）。上架不另形成发生项，入库作业发生项在收货确认时形成。
- 不关联库存的增值服务（CONTEXT「增值服务项目」词条举的拍照、质检、加固之类）由谁提出、「服务完成」记成哪一种事实，票 08 没有写：UC-WF-008 只有加工与商品换标的指令。领星是客户在 OMS 下不关联库存的工单、仓库处理完成之后结算（出处在票 08「参照的出处」）；这里要不要有货主提交的口，随本票写增值服务发生项时定。
- 以库存调整更正收错的收货：UC-WF-011 的库存调整可以带所更正的作业事实，只作指名与留痕。它算不算入库作业发生项的来源事实被更正、要不要追加更正版本，本票定；上面票 07 留的那一条在这里有了落点。
- 回库处置与库内作业事实的先后。UC-WF-007 的口照记从退货暂存库区上架、移库与状态转换的事实，不看有没有回库处置；没处置就移走的怎么办，回库处置的「良品上架」「转次品入次品库区」与这些事实怎样对上，本票写。次品转回良品只在收货暂存与退货暂存库区、由运营决定作出（UC-WF-007），退货的质检结果要改时走它。
- 仓租与入库批次。盘盈与调增不另起入库批次，记入已有的那一个，库龄随它（CONTEXT「库存账与守恒」，UC-WF-011 的 `AT-WF-164`）；加工、拆解的产出形成新的入库批次，库龄从入账那一刻起算；开箱转入的沿用该箱的入库批次（UC-WF-008）。入账之前的那些天补不补仓租，与建账导入那一条一并定。
- 冻结不改在库量，冻结着的货照在库计；仓租发生项要不要带出冻结没有写（UC-WF-009）。
- 开箱形成的收货差异与收货确认、完结形成的是同一种对象，结论照 UC-WF-004 的差异结论口作（UC-WF-008）；本票的用例与交给对账的读口带出收货差异时，开箱那一种一并带出，途径的写法同上面票 07 留的那一条。
- 库存调整引用收货差异时记下那一刻的结论与途径，不以结论为前提；代录的「已确认」此后被货主本人改成有异议，已入账的调整不回退（UC-WF-011 的 `AT-WF-175`）。本票凡据库存调整形成或更正发生项的，照这一条：不把所引的结论当作调整成立的依据。

同笔改：UC-SA-002「给开发的交接」仓储那一行改指到写成的用例；票 07 至 09 写成的用例里，各作业事实形成哪种收费发生项的指针在这里回填。

## 完成判据

同票 07「完成判据」。另加一条：发生项不带金额，库龄段、免租期、淡旺季与单价不出现在 UC-WF 里。
