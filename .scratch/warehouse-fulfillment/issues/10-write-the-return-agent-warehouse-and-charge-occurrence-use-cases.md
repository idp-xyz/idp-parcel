# 10 写 `UC-WF`：退货、代理仓与收费发生项

Category: docs
Status: ready-for-agent
Blocked by: 05、06

依据：[仓配履约 CONTEXT](../../../docs/domain/warehouse-fulfillment/CONTEXT.md) 的「退货」「代理仓」「收费发生项」词条与规则，「退货入库」「代理仓库存声明」两条生命周期；ADR-0370 决定三；票 06 的 ADR（收费发生项怎样被计价与结算消费）。

## 要做的

在 `docs/application/warehouse-fulfillment/` 下写用例。建议的切法，以写成的为准：

- 退货预报、退货入库与回库处置。
- 代理仓库存声明的接收、过期与被取代；代理仓出库经连接器转出与结果保全。
- 形成仓储作业收费发生项：各作业种类在哪个作业事实上形成，仓租按（货主，仓，计费日）每日形成，重放与更正。

CONTEXT 没写、要在本票定下的：

- 代理仓连接器的形态（照公开规范或模拟源；接哪家、协议细节与凭据是租户取值）。
- 仓租日结由什么触发，日终取数的时点与补算。
- 发生项交给计价与结算的信封与读口，照票 06 的 ADR。

同笔改：UC-SA-002「给开发的交接」仓储那一行改指到写成的用例。

## 完成判据

同票 07「完成判据」。另加一条：发生项不带金额，库龄段、免租期、淡旺季与单价不出现在 UC-WF 里。
