# 07 共用面：状态胶囊带图标、工作台指标标签中文样式、标题旁插槽放册签

Category: enhancement
Status: in-progress
父票：[spec](../spec.md)
Blocked by: 无——可直接开始

## 要做的

- 状态胶囊（全站共用件）在词前按语气加一枚图标，替代今天只有颜色的圆点：已生效一类打勾、待生效一类时钟、停用与撤销一类禁止符、中性一类短横；词表与色调判读不动。色不再是唯一载体（原型的状态胶囊是色 + 图标 + 文字三重编码）；图标是非文字，对比门槛 3:1。
- 工作台模板的指标标签去掉大写与字距样式：它是给拉丁字母设计的，对中文无效，拉丁字母也不必再大写。
- 工作台模板加一个标题旁的插槽，往来单位页把册签条（往来单位 N | 合作关系 N）放进去，命令头少一层；不传插槽的页渲染逐字节同（模板纪律）。

## 完成判据

- 三道门退 0；状态胶囊的 node:test 快照随图标更新。
- 浏览器：往来单位、合作关系、公司主体、客户与合同各看一处状态胶囊带图标；工作台指标标签不再大写字距；往来单位命令头标题行右侧是册签、上面不再有独立一条；公司主体页（不传插槽）命令头不变。深色主题看一次。
