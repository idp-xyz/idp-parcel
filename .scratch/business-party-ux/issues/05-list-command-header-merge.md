# 05 列表命令头：指标行只按类型分格，类型下拉去掉

Category: enhancement
Status: in-progress
父票：[spec](../spec.md)
Blocked by: 无——可直接开始

## 要做的

- 身份册的命令头指标行只留按类型分格的那几格：我方公司、持有各角色的、暂无合作关系（都是可点即筛，筛选判据不动）。「待生效」「已停用」两格去掉——状态芯片已带计数、可筛，一个筛选器不开两个入口。
- 工具条上的「类型」下拉去掉：指标格就是类型筛选；「清除筛选」照旧把类型复位。没有单位持有的角色不出格（今天就是这样），也就不再有一个筛出来必然为空的选项。
- 合作关系册的命令头不在本票内（它的「待查」「待确认」「已生效」三格与状态芯片不是同一组事实）。

## 完成判据

- 三道门退 0；计数与筛选的纯逻辑若有改动钉 node:test。
- 浏览器（演示租户，1440 与 1280 宽）：指标行没有「待生效」「已停用」；点「我方公司」格筛出四家、再点取消；点「暂无合作关系」格与此前类型下拉选同项结果一致；状态芯片「待生效」仍能筛且计数与列表一致；「清除筛选」复位全部。只读，零写请求。
