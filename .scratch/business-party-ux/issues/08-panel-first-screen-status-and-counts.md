# 08 右栏首屏：随状态的提示、关联计数一行、主动作随状态

Category: enhancement
Status: ready-for-agent
父票：[spec](../spec.md)
Blocked by: 无——可直接开始

## 要做的

不含图示、不含类型图标（spec「原型的做法怎么取」已裁不做）；也不写「当前已建立 X 关系」那种结论句（头部角色标签已说）。做的是三件：

- 头区下随身份状态的提示，`info` 语气，照票 02 空状态那种「给下一步」的写法：待生效——「计划于 X 生效，生效前不能登记合作关系」（CONTEXT「参与方身份」：生效时点未到的登记不支持新的商业决定）；已生效、不是我方公司、没有在用的合作关系——「还没有合作关系」带「登记合作关系」入口，打开「关联」签里已有的内联表单。已停用沿用现在的横幅。我方公司不摆「没有关系」那条：它多半是关系的相对方，持有的角色本来就少。
- 事实行下一行关联计数：「合作关系 n · 客户账户 n · 公司主体 n · 供应商协议 n · 结算政策 n」，点击切到「关联」签；哪一册没答出那一格显「…」。判读复用全景签已有的那一份；「关联」签里原来那行计数去掉——一个事实首屏只出现一处。
- 主动作随状态：已生效、不是我方公司、没有在用关系且有写授予时，主动作是「登记合作关系」（与关联块那枚同一张表单），「更新资料」退成描边；其余情形照旧。

## 完成判据

- 三道门退 0；提示与主动作的选择钉 node:test。
- 浏览器（演示租户）：待生效单位显待生效提示、无「登记合作关系」入口；没有关系的单位显「还没有合作关系」提示，主动作「登记合作关系」点开内联表单、取消不写；货主一号无提示、主动作「更新资料」、计数行可点切到「关联」签且签内不再有那行计数；我方公司无「没有关系」提示；查看者无写入口。零写请求。
