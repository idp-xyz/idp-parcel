# 05 跨境主体资料扩展：海关备案、银行收款账户、多语言开票抬头

Category: enhancement
Status: needs-info——待用户决定要不要开领域票（改 CONTEXT「法人资料」与 ADR-0350 系列）
父票：[spec](../spec.md)
Blocked by: 用户决定
出处：评估「四、国际小包视角」。

## 缺什么

跨境小包运营集团的公司主体真正要印在发票、对账单、报关单上的，今天资料里没有的：

1. **海关主体**：进出口经营权备案 / 海关编码、AEO 等级。报关单与清关资料要用。
2. **银行收款账户**：对账单与发票要印；今天结算这边没有地方挂到公司主体上。
3. **多语言开票抬头**：HK / US 主体给中国客户与海外客户开票用不同抬头；今天只有一个 `invoiceTitle`。

税务身份（VAT / IOSS / EORI）**不在本票**：注册号类型目录已有资料层，票 04 把类型格改成从目录选即可，租户按注册地配置类型。

## 为什么要用户决定

三项都是领域新格：`party-commercial` CONTEXT「法人资料」要加语言、ADR-0350 要扩（或新 ADR）、读写口与迁移随之改。按 AGENTS「改文档」与「开工顺序」，这不是管理台能自己决定的；而且银行账户是否归法人资料还是结算账户（`settlement-accounting`）要先裁所有权。

- CONTEXT / GLOSSARY / UC-PC-001 同步；后端迁移只增；管理台表单与读出跟上。
